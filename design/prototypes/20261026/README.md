# 物料间：三款前端视觉与交互原型

2026-10-26。根据产品经理给出的 LIBTV、OiiOii 和 Refero 参考，制作三套可选择方案；每套均有深色与浅色主题，以及项目首页、快捷工作台、导演台三个代表页面。

## 打开与评审

- 比较页：http://127.0.0.1:5191/
- A 画布导演台：http://127.0.0.1:5191/a-canvas.html?view=director&theme=dark
- B 轻量向导：http://127.0.0.1:5191/b-guide.html?view=director&theme=light
- C 项目工作室：http://127.0.0.1:5191/c-studio.html?view=home&theme=light

若本机预览服务已停止，在项目根目录运行：

```sh
python3 -m http.server 5191 --bind 127.0.0.1 --directory design/prototypes/20261026
```

也可直接打开本目录的 index.html。通过 file:// 打开时，请使用各方案页面内的主题按钮；浏览器对嵌入页的访问限制可能影响比较页外层控制。

1. 比较页切换“导演台 / 项目首页 / 快捷工作台”，对照三套同一页面。
2. 切换浅色、深色，查看文字与操作区的清晰程度。
3. 点击方案进入可操作原型，从需求走到脚本、分镜审核、视频确认、交付。
4. 分镜报价确认后才出现示例分镜；两张均审核后才进入视频。
5. 分别选择“完整视频”和“独立片段”；独立片段各自可播放和下载，另行确认后查看合成示例。
6. 试试返回修改、可选提示词润色，以及完成后回看制作记录。

## 三套取舍

| 方案 | 视觉 | 操作组织 | 适合判断什么 |
| --- | --- | --- | --- |
| A 画布导演台 | 石墨黑 / 灰白，苔绿强调 | 左侧导演助手，右侧当前工作卡，点阵背景 | 是否符合用户所说的导演台与渐进画布 |
| B 轻量向导 | 暖白 / 炭黑，陶土强调 | 中心单步骤卡，右侧轻量助手；窄屏抽屉 | 是否更容易上手、是否足够简洁 |
| C 项目工作室 | 纯白 / 墨色，钴蓝强调 | 新建与最近项目入口，作品网格，步骤内双栏 | 是否方便持续管理创作项目 |

推荐组合是 A 的导演台组织 + C 的项目首页；最终颜色、字体、标识与组件会统一，不把三个原型的视觉系统拼成三个不一致的产品。

## 已保留的产品决定

- 快捷工作台独立可用，助手只按需润色；复杂创作进入导演台。
- 当前步骤与已到达内容逐步显示，未来步骤的表单/节点不预先铺开。
- 需求、脚本、分镜均由用户确认；模型生成前单独确认范围与报价。
- 分镜确认后一次生成全部视频；完整视频与独立片段平级。
- 已完成流程可以回看；返回修改时下游需重新确认。
- 不增加会员支付、协作、配音配乐、任意节点编排、额外模型等范围。

## 原型边界

本轮交付的是可运行的独立设计原型，不是正式前端接入完成。产品 `frontend/`、后端、配置及业务库未被这些原型修改。

所有对话、报价和状态由本地演示逻辑驱动，页面明确标注“交互原型 / 示例数据 / 不产生费用”。不请求 API，不调用模型，不消耗此前真实测算预算。输入只在当前页面内存中；刷新或切换方案会重置，不能当作产品持久化验收。模型、规格与报价展示是界面示例，正式版须继续使用后端能力和报价。

图片、镜头片段与成片复用本项目 `docs/evidence/真实验收-20261026/media/` 已有材料，不是本轮新生成。独立样片每段 5.04 秒，完整样片 10.08 秒；播放器实际素材与用户修改后的示例参数可能不同。

原型使用原生 HTML/CSS/JS，无新增依赖。正式产品继续沿用 React / TypeScript / Vite，在用户选定视觉方向后将设计落实到现有组件和真实接口；不迁移产品技术栈。
