## 1. 定位与目标

### 1.1 定位【已确认】

> 在**画布**中生成、编辑、组合素材的电商 AIGC 视觉工作台；工作台、任务、素材、草稿与**模型推理**全部在本机运行。

### 1.2 目标

| 编号 | 目标 | 怎样算做成 |
| --- | --- | --- |
| G1 | 一个商品 → 一套可投放素材 | 图片（商品图/主图/场景图）与视频均可在平台内产出 |
| G2 | 两条产线共用素材、画布与任务体系 | 画布中的素材可直接进入图片批次或视频任务，素材只维护一份 |
| G3 | 多任务可无人值守跑完，且不中断编辑 | 批量提交后画布可继续编辑；任务中心可见排队/运行/失败/完成 |
| G4 | 全本地、可断网复现 | 权重就位后断网仍能完成生成（§13 验证项） |
| G5 | 效果可评测、代价可度量 | 每次生成记录模型版本、参数、耗时、内存峰值、种子、产出 |

### 1.3 红线

| # | 红线 |
| --- | --- |
| N1 | 不做短剧；视频只围绕商品素材做电商用途 |
| N2 | 运行时不得发起任何远程模型调用（含火山、DeepSeek、任何推理 API） |
| N3 | 不得用运镜动效或模板合成**替代**模型视频生成，也不得混称（§3） |
| N4 | 不编造评测数据、速度、成功率；未跑写「未执行」 |
| N5 | 不静默降标准、不静默删功能；未完成项必须列出 |
| N6 | 不关闭内存保护（MPS 高水位限制），不无限重试 |

## 3. 能力定义：三种「视频」严格区分

| 维度 | ① 生成式视频（本地模型） | ② 运镜动效 | ③ 模板合成 |
| --- | --- | --- | --- |
| 实现 | 本地视频扩散模型推理（I2V/T2V） | 静态图缩放/平移（确定性代码） | FFmpeg 拼接/字幕/音乐 |
| 是否可称「AI 视频生成」 | 是 | **否**（叫「图片动效」） | **否**（叫「模板合成」） |
| 本产品定位 | **场景 B 的唯一合法能力** | 后续可选附加，**不得替代 ①** | 后续可选后处理，**不得替代 ①** |

**本次视频的具体模式（消除矛盾，以此为准）**

| 模式 | 本次定位 | 说明 |
| --- | --- | --- |
| **I2V（图生视频）** | **必须验收** | 输入商品图（首帧）+ 文字；电商主路径 |
| **T2V（文生视频）** | **不作为本次必验项** | **当前候选路径未验证，本次不优先投入**（不写“均超预算/不可行”这类未经实测的结论）；本次集中完成 I2V |
| ②/③ | 不实现 | 若实现也必须独立命名与独立成本记录，且不算 ① 的证据 |

**失败处理**：任一模型跑不通 → 记录实际错误（OOM/算子不支持/超时）→ 提出本机范围内的调整建议（降分辨率、降帧数、减步数、换更小模型）→ **由你决定**是否采用；不得自动改用云端，不得用 ②/③ 冒充。

## 4. 场景 A：电商图片

### 4.1 输入

| 项 | 内容 | 状态 |
| --- | --- | --- |
| 商品原图 | PNG/JPG/WebP，单张上限 20MB | 【建议】 |
| 提示词 | 风格/场景/卖点；支持负向提示词 | 【建议】 |
| 参考图（可选） | 图生图 / 参考图条件控制（能力与内存相关【待验证】） | 【建议】 |
| 尺寸 | 1:1 / 3:4 / 4:3 / 9:16 / 16:9；批量尺寸矩阵 | 【已确认】 |
| SKU 组 | 同款不同色标记同组，用于一致性检查 | 【已确认】 |

### 4.2 流程与人工确认点

```
上传商品图 → 素材库(asset_id) → ① 选模型/风格/尺寸/步数/种子【确认点 C1：点提交才占算力】
   → ② 任务入队（单并发默认）→ 本地推理 → ③ 产物落盘 + 元数据
   → ④ 回填画布【确认点 C2：保留/淘汰/重生成】→ ⑤ 编辑(重绘/扩图，逐步启用) → ⑥ 批量导出
```

| 确认点 | 人判断 | 系统不得自动做 |
| --- | --- | --- |
| C1 | 参数、张数、是否值得排队 | 自动扩量、自动重跑全批 |
| C2 | 采用哪张、哪张重生成 | 自动删除旧版本 |
| C3 | 覆盖还是新增版本 | 静默覆盖 |

### 4.3 输出

图片文件（本地）＋元数据（模型 ID/版本、提示词、负向词、尺寸、步数、CFG、种子、耗时、内存峰值、版本号）。长期保留：原图、结果、元数据、草稿。

### 4.4 多 SKU 一致性路线

提示词模板 + 固定种子 + 固定参数 → 参考图/图生图条件控制 →（可选）商品级 LoRA（训练可行性【待验证】）。一致性为人工评分项（§9.2），阈值待首批样例打分后确定。

## 5. 场景 B：电商视频（本地 I2V）

### 5.1 输入 / 流程 / 输出

**输入**

| 项 | 内容 | 状态 |
| --- | --- | --- |
| 首帧图 | 素材库中已确认的商品图 | 【已确认】 |
| 文字描述 | 镜头/运动/场景描述 | 【已确认】 |
| 规格 | 分辨率、帧数、时长、帧率、步数、种子 | 档位由模型能力与本机内存决定【待验证】 |
| 批量 | 多商品 × 多片段 | 【已确认】需支持 |

**流程**

```
选素材 → 填文字/规格【确认点 V1：提交才占算力】 → 任务入队
   → 本地推理（逐帧/逐段）→ 产物落盘 → 素材库【确认点 V2：预览后保留/重跑】
   → 画布片段序列 → 拼接导出（后续切片）
```

**输出**：MP4（或图像序列 + 编码）＋元数据（模型、参数、实际分辨率/帧数/时长/fps、耗时、内存峰值、种子）。**实际规格必须如实记录**：低分辨率短片段用于探针时必须标注「探针规格，非最终规格」。

### 5.2 成片规格

| 项 | 目标 | 下限（探针可接受，需标注） |
| --- | --- | --- |
| 时长 | 3–10s（Q4 裁决上限 10s） | 1–2s（仅探针） |
| 分辨率 | 640×960 / 720×1280（9:16） | 320×512（非 9:16） |
| 帧率 | 8–24fps（按模型能力） | 4–8fps |
| 音轨 | 本期无音频（模型无音轨输出时直接说明） | — |

> **探针口径（已裁决）**：320×512 / 8 帧 / 8fps ≈ **1 秒、非 9:16**，只能证明「本地视频推理链路可跑」，**不得算作最终视频验收通过**。探针成功后须再尝试目标时长、画幅与分辨率。
> **禁止凑片**：不得用重复帧、降帧率、模板动效等方式把不足的成片凑到目标时长或画幅。
> 若最终只能交付下限规格，验收结论写「视频链路跑通，成片规格未达目标」，不得写成「视频功能完成」。

### 5.3 风险（风险判断，非断言）

1. 本地视频扩散在 16GB 统一内存下可能 OOM 或极慢；MPS 后端算子覆盖不全可能导致回退 CPU。
2. 单条视频耗时可从数分钟到数十分钟（未实测），会挤压批量与恢复能力的验证时间。
3. 视频模型权重体积大，需按 §8.4 先算磁盘预算再下载。

## 10. 多任务、取消、失败、恢复、不丢稿（本地语义）

### 10.1 概念区分

| 概念 | 本机做法 |
| --- | --- |
| 多任务提交 | ✅ 持久化队列，可一次提交多个 |
| 排队 | ✅ 默认单并发（`concurrency=1`，可配）；**区分「多任务提交」与「多推理并发」**，后者默认不开 |
| 同时推理 | 受 11.45GB MPS 预算约束，默认 1；若开启多并发，必须实测内存后由你决定 |
| 取消 | 见 §10.3，**协作式**，不夸大 |
| 失败恢复 | 有限次自动重试（默认 1 次）+ 手动重试；失败不阻塞队列 |
| 重启恢复 | 排队任务继续；运行中任务标 `interrupted`，**需从头重试**（不承诺断点续跑） |
| 不丢稿 | 草稿自动保存 + 版本快照；任务执行期间编辑不受影响 |

### 10.2 状态机

```
queued → loading(模型加载/复用) → running → postprocess → succeeded
   │            │                    │            │
   │            └→ failed(错误码)      ├→ cancel_requested → canceled
   └→ canceled                        └→ interrupted（进程退出）→ 需重试
```

### 10.3 取消语义（如实说明能力边界）

| 情形 | 实现方式 | 用户可见 |
| --- | --- | --- |
| 排队中取消 | 直接从队列移除 | 已取消（未占算力） |
| 运行中取消 | 设置取消标志，在**采样步回调**或**帧间**检查并停止，随后释放模型/缓存 | 「已请求停止，将在当前步/当前帧结束后停止」 |
| 正在模型加载 | 加载不可中断，标记待取消，加载后立即停止 | 「正在加载模型，加载完成后停止」 |
| 已完成 | 不可取消，可删除产物（需确认） | 已完成 |

> 说明：Python + MPS 的单次前向计算**不能**被强制中断，因此「运行中取消」最多延迟一个采样步/一帧。此限制写入《多任务并发说明》，不承诺毫秒级中断。

### 10.4 失败与重试

- 可重试：进程内瞬时错误（下载校验失败、文件写入失败）。
- **不自动重试**：OOM、算子不支持、权重缺失、显存/内存不足——这些重试也不会成功，必须降档或修环境。
- 重试上限：自动 1 次；手动不限次数但每次都记录尝试历史。
- 每次失败记录：错误码、原始异常摘要（前 20 行）、当时的参数与内存占用。

### 10.5 重启恢复

- 启动时扫描：`queued` → 继续执行；`loading/running/postprocess` → 标 `interrupted` 并在 UI 提示「上次异常退出，N 个任务需重新执行」；**不自动静默重跑**（避免重复占用算力与磁盘）。
- 草稿、素材、任务历史全部保留；产物若已完整落盘则登记为成功（按文件校验结果判定）。

### 10.6 不丢稿

- 草稿 JSON（含素材引用）+ 版本快照存本地库；自动保存（防抖 ~2s）+ 手动保存。
- 生成过程中保存草稿不影响任务（任务持参数快照）。
