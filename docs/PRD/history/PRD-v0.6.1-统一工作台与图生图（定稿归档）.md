## 1. 一级生成能力（仅两类）

```
生图（image）
生视频（video）
```

除这两类外的能力（运镜动效、模板合成、排版导出）都不是"生成能力"，不得并列描述。

## 2. 生图的分类（两个正交维度）

### 2.1 维度一：输入方式（决定调用方式与参数）

| 输入方式    | 含义              | `generation_mode`   | 参考图                      |
| ------- | --------------- | ------------------- | ------------------------ |
| **文生图** | 只用文字描述生成        | `text_to_image`（默认） | 不需要                      |
| **图生图** | 以一张已有图片为参考/底图生成 | `image_to_image`    | **必须**（`input_asset_id`） |

### 2.2 维度二：使用用途（决定提示词预设，不创建独立后端流程）

| 用途        | 说明              |
| --------- | --------------- |
| **白底商品图** | 纯色/白底棚拍、留白、可做主图 |
| **氛围场景图** | 商品置于场景/环境中的氛围图  |
| **自定义**   | 用户自由描述          |

**实现约定**：用途只是**提示词预设与 UI 入口**，后端**不新建三套生成流程**，也不新增三套接口。同一个 `POST /api/tasks` 完成。

### 2.3 SKU 的定位（概念纠正）

- SKU = **商品规格或管理分组**（颜色/容量/款式），用于素材归类与批量挑选。
- 白底/氛围/自定义 = **呈现方式（用途）**。
- 两者不是同一层概念，**不得混写**为"白底 SKU""氛围 SKU"。
- **SKU 分组不提供模型侧一致性保证**：把同一 SKU 的图归组，只代表管理关系；模型是否保持一致需要单独评测（参考图/固定种子等），当前**未实现一致性保证**，文档与 UI 不得暗示。

## 3. 工作台与创作空间合并（目标交互）

**一个主创作页面内闭环**：

```
选择生成类型（生图/生视频）
  → 输入：文字描述 / 选择参考图（图生图或视频首帧）
  → 用途预设（白底 / 氛围 / 自定义）与参数（尺寸、时长、画幅等）
  → 提交生成（此时才发生付费调用）
  → 查看结果（预览、用量、费用）
  → 继续创作（基于结果再生成 / 加入画布 / 保存草稿）
```

要求：

1. **不再有**"首页填完描述 → 跳到另一个页面重新设置一遍"的重复流程。
2. 素材库（含 SKU 分组）与任务中心**保留**，作为并列区域，不是主流程的必经跳转。
3. 上传参考图**只创建素材**，不产生费用；只有"提交生成"才调用云端。
4. 上述页面结构由 **Codex** 实现并单独验收；本轮后端只保证接口支持这套流程。

## 4. 两种画布（严格区分，不得混写）

### 4.1 固定尺寸排版编辑器（已存在，属当前能力）

- 用途：在固定画幅内组合**图片 / 文字 / 色块图层**，拖动、缩放、旋转、透明度、层级、复制、删除、撤销，PNG 导出。
- 状态：由 Codex 实现并已给出证据（PNG 导出、390px 小屏检查、ZIP 素材打包等，详见 `docs/evidence/前端/`）。
- 局限：它是**排版工具**，不表达"创作流程"。

### 4.2 无限节点创作画布（后续阶段，**本轮未实现**）

用户期待的形态：

```
[素材节点] → [图片生成节点] → [视频生成节点]
```

- 节点可**独立运行**、查看状态、重试；
- 节点保存**输入、输出与连接关系**；
- 节点之间可串联：素材 → 生图 → 生视频。

**本轮明确不做**：节点图数据结构、节点执行引擎、连线交互。  
**写作纪律**：任何文档、UI、汇报**不得**把节点画布写成"已实现/已完成"。它只以"后续阶段设计目标"出现。  
**不阻塞关系**：节点执行引擎不阻塞本轮交付（本轮交付统一工作台 + 真实图生图链路）。

### 6.2 费用：估算 ≠ 账单

| 项      | 口径                                                                   |
| ------ | -------------------------------------------------------------------- |
| 图片     | 官方单价 0.12 元/张（flash）；**按张计价，估算≈实际**                                  |

| 系统记录   | `cost_cny` 为**估算值**（按单价 × 用量计算），不是账单                                 |
| 历史修正   | v0.5 期间按 15.0 元/百万 token 估算，视频费用被高估约 3.6 倍；**旧记录保留不篡改**，在评测报告中注明口径变更 |
| 官方计费规则 | 仅对成功生成的视频计费；审核/失败不计费（官方价格页）                                          |

### 6.3 时间

- 旧"16:30 冻结新增功能"**不再适用**；本轮不设自行猜测的截止时间。
- 交付按"真实链路 + 接口交接"优先，其余按实际完成度登记。

## 7. 本轮验收标准（新增/保留）

| #  | 验收项                | 判定方式                                                                                                    |
| -- | ------------------ | ------------------------------------------------------------------------------------------------------- |
| V1 | **文生图仍能正常执行**      | 真实调用 1 次成功（回归）                                                                                          |
| V2 | **图生图的参考图实际传入模型**  | 请求体含参考图（base64 data URL，MIME 正确）+ 产物与参考图相关；**已知**：提示词与图不符时会凭空新增商品（实测单瓶→三件），故"保持一致"需提示词与图一致，且**未实现数量校验** |
| V3 | **缺失/无效参考图返回明确错误** | 4xx + 具体 code（不静默退化为文生图）                                                                                |
| V4 | **图生图结果落盘并能预览**    | 素材登记 + `/api/assets/{id}/file` 可看                                                                       |
| V5 | **任务、批量、重试、草稿兼容**  | 旧请求不传新字段行为不变；批量/重试各自保留参考图与参数（不串图）                                                                       |
| V6 | 页面分类与工作台合并         | **由 Codex 完成并单独验收**，本轮不对其背书                                                                             |

## 8. 接口原则（详细见 `docs/接口/接口契约.md`）

1. 不新建平行任务系统，复用 `POST /api/tasks`、`/api/batches`、查询/取消/重试、素材与草稿接口。
2. 参考图沿用**顶层 `input_asset_id`**；在 `params` 增加 `generation_mode`（`text_to_image` 默认 / `image_to_image`）。
3. **兼容规则**：不传 `generation_mode` → 按文生图处理（旧行为不变）。
4. 冲突处理：`image_to_image` 却无参考图、参考图不是图片、素材不存在 → 明确报错。
5. 用途（白底/氛围/自定义）只影响提示词预设，**不新增接口**。
