## 修订记录 v0.7 → v0.7.1（2026-10-24）

本轮为**已确认功能的缺陷修复**，不重新讨论产品定位，不扩大 MVP 范围。依据 Codex《后端进度核对-20261024》五项。

| # | 修复项 | 修正规则（本次写入 PRD，后续以此为准） | 类型 |
| --- | --- | --- | --- |
| 1 | 提交前费用预估未真正前置 | 「生成前确认」必须使用**无副作用**的 `POST /api/tasks/estimate`；`POST /api/tasks` 响应中的 `estimated_cost_cny` 仅为**提交后**的任务级估算，**不得**作为提交前确认依据。预估与提交必须复用同一解析/校验/计价逻辑。 | 缺陷修复 |
| 2 | 模板自定义字段被清洗 | 由 `allow_custom`/`custom_key` 声明的字段（`scene_custom`/`motion_custom`/`theme_custom`）**必须保留**；选中「自定义」但为空 → 明确字段错误；未选中「自定义」时不得把无关自定义值写入提示词与任务快照。 | 缺陷修复 |
| 3 | 视频模板时长/比例未生效 | 参数优先级固定为：**调用方显式 `params` > 模板字段映射（`field_params`）> 模板默认值**。对**最终生效参数**执行模型能力校验；表单回显、费用预估、任务保存、供应商请求必须一致；**禁止**选 10 秒却静默用 5 秒。 | 缺陷修复 |
| 4 | 概念图路径被图生图校验阻断 | 季节主题模板的 `generation_mode` 由**参考图存在性派生**：有图 → `image_to_image`；无图且商品名合法 → `text_to_image` + `concept_mode=true`；缺少必要商品描述 → 提交前报错。兼容性校验使用**最终解析出的**生成模式。 | 缺陷修复 |
| 5 | 模型到期未在服务端拦截 | 未到期（`eos_scheduled`）：**允许使用**，返回下线时间与迁移目标供前端提示；到达 EOS 时刻起（`now >= eos_at`）：在**入队前**返回 `MODEL_EOS`，覆盖普通提交、模板提交、批量与重试；**不自动替换模型、不改写历史任务**。时间以官方公告记录为准，可用可注入时钟测试。 | 缺陷修复 |

### 费用口径纠正（本版同步）

- `cost_cny` 是**应用侧估算**（单价 × 用量），**不得**称为「已核对的供应商账单」。
- 失败任务的 `cost_cny = null` 表示**未产生应用侧估算记录**，**不能**直接解释为「账单金额为零」；官方「仅成功生成计费」是规则说明，不等同于本项目已完成对账。
- 预算 `BUDGET_CNY` 与 `spent_today_cny` 均为本机估算闸门，不是服务商余额或发票口径。

## 1. 完成边界

### 1.1 目标闭环

```
选择模板/自由创作 → 准备商品素材 → 选择模型 → 确认参数与费用
   → 生成 → 原图对比 → 修改再生成 → 保存下载
```

### 1.2 纳入本版

| 项 | 说明 |
| --- | --- |
| 轻量商品信息 | 商品名/品类/需保留特征/禁用元素等字段，随任务与草稿持久化；不是完整商品库 |
| 原图对比 | 产物与原图并排人工对比，记录采纳/驳回与原因 |
| 输入与参数恢复 | 草稿与任务可恢复模板、字段、模型、参数、参考图 |
| 生成记录追溯 | 产物关联模型/模板版本/原图/参数/任务 |
| 模板入口 | 4 个首版模板 |
| 多模型选择 | 兼容过滤 + 切换保留可复用输入 |

### 1.3 暂缓

完整商品库、团队审批、复杂批次交付（按批次审核/命名/清单/自动交付包）、多 worker 并发、Webhook、无限节点画布。

### 1.4 保留

素材库、素材 ZIP 打包、固定尺寸排版、草稿、任务中心、单 worker 队列。

### 1.5 非目标

多步骤任务编排、自动抓取热点、文生视频、局部重绘/扩图、多 SKU 一致性保证、视频剪辑拼接、两个项目真实联通。

## 2. 主流程

| 步骤 | 行为 | 规则 |
| --- | --- | --- |
| 1 选模板/自由创作 | 模板列表或直接创作 | 浏览模板**不产生费用** |
| 2 准备商品素材 | 上传/选择商品图，填字段 | 上传只创建素材，不产生费用 |
| 3 选择模型 | 从兼容模型中选 | 未开通置灰；EOS 模型标注下线时间 |
| 4 确认参数与费用 | 展示**最终生效参数**与费用估算 | **必须**调 `POST /api/tasks/estimate`（无副作用）；确认后才调 `POST /api/tasks` |
| 5 生成 | 提交→排队→轮询 | 提交即付费 |
| 6 原图对比 | 并排对比 | 人工判断，记录采纳/驳回；自动一致性校验未实现 |
| 7 修改再生成 | 复用输入与参数 | 重试即重新生成、再次计费；保留历史版本 |
| 8 保存下载 | 入素材库/导出 | 可追溯模型、模板版本、原图、参数 |

## 3. 失败与修改流程

| 场景 | 错误码 | 行为 |
| --- | --- | --- |
| 参数校验失败 | `VALIDATION_FAILED` | 提交前拦截，不计费 |
| 模板字段缺失/非法 | `TEMPLATE_FIELD_REQUIRED` / `TEMPLATE_FIELD_INVALID` | 提交前拦截 |
| 模板不存在/版本不存在 | `TEMPLATE_NOT_FOUND` / `TEMPLATE_VERSION_NOT_FOUND` | 404 |
| 模板与模型不兼容 | `MODEL_TEMPLATE_INCOMPATIBLE` | 400，给出可用模型列表 |
| 模型未开通 | `MODEL_NOT_OPENED` | 前端置灰；已提交则提示去控制台开通（**实测不计费**） |
| 预算不足 | `BUDGET_NOT_APPROVED` / `BUDGET_EXCEEDED` | 402，不发起付费请求 |
| 生成失败 | `failed` | 显示错误码与下一步 |
| 创建结果不明 | `CREATE_RESULT_UNKNOWN` | 禁止直接重试，先人工对账 |
| 一致性不通过 | — | 记录驳回原因→修改再生成；不改写历史任务 |
| 云端运行中取消 | — | 明确"云端可能仍在执行并计费" |
| 草稿冲突 | `DRAFT_VERSION_CONFLICT` | 停止覆盖，另存新草稿 |
| 模型已到 EOS | `MODEL_EOS` | 新任务不可选，提示迁移目标；历史任务照常可查 |

## 6. Seedance 1.0 Pro Fast 迁移

### 6.1 官方依据（已核实原文）

来源：火山方舟《模型下线公告》第十批模型下线说明 `https://www.volcengine.com/docs/82379/1350667`

| 节点 | 时间（UTC+8） | 动作 |
| --- | --- | --- |
| 启动/通知 | 2026-09-22 10:00 | 逐步下调配额 |
| EOM | 2026-09-24 10:00 | 模型停止新购 |
| **EOS** | **2026-11-24 14:00** | 模型服务下线，残留接入点自动替换或关停 |

公告表格明确：`doubao-seedance-1-0-pro-fast-251015` → 建议迁移 `doubao-seedance-2-0-mini-260615`，动作 **关停**。
公告并明确：**"生图生视频模型不会自动迁移到新模型。请提前使用新模型进行接入点进行使用，避免影响业务。"**

> 结论：本项目"不静默替换"与官方规则一致；且**必须主动迁移**，否则 EOS 后直接不可用。

### 6.2 迁移原则

1. 先验证替代模型，再切换默认；2. 不自动切换；3. 历史任务/模型记录/费用不改写；
4. 下线后模型标记 `eos`，不再出现在新任务可选列表，历史任务仍可查。

### 6.3 门禁

## 7. 单次创作模板

### 7.1 通用结构与版本规则

```
template_id（语义稳定 ID） + template_version（整数递增）
category: work | hot      kind: image | video
name / description / effect_sample
required_assets           必填素材
fields（key/label/type/required/options/allow_custom）
default_params            默认生成参数
compatible_models         kind + input_modes
status: active | deprecated
```

**硬规则**：模板发布后不可原地修改，任何变更新增版本；`template_versions.snapshot_json` 永久保留；
任务只记 `template_id + template_version`，历史展示按快照还原，不随升版变化。

### 7.2 首版四个模板

| ID | 名称 | 类别 | 必填素材 | 关键字段 | 默认参数 |
| --- | --- | --- | --- | --- | --- |
| `tpl_white_bg` | 商品白底背景 | work/image | 商品图 1 张 | 商品名、品类、需保留特征、禁用元素、补充描述 | image_to_image / 2048×2048 |
| `tpl_scene_bg` | 商品场景换背景 | work/image | 商品图 1 张 | 商品名、目标场景（必填）、需保留特征、禁用元素 | image_to_image / 2048×2048 |
| `tpl_product_motion_5s` | 5 秒商品动态展示 | work/video | 商品首帧图 1 张 | 商品名、动态方式（必填）、时长（默认 5，可选 10）、比例、需保留特征、禁用元素 | image_to_video / 720p |

> **版本说明**：`tpl_product_motion_5s` 修复「字段未生效」后以 **v2** 发布（新增 `field_params: {duration, ratio}`）；
v1 快照**未被修改**，引用 v1 的历史任务继续按 v1 读取。
| `tpl_season_theme` | 季节上新主题 | hot/image | 商品图**建议提供** | 商品名、主题（必填）、主题文案、需保留特征、禁用元素 | 默认 image_to_image / 2048×2048 |

**已确认补充字段**：可选「需保留特征」与「禁用元素」（见各模板 `keep_features` / `forbidden_elements`）。

### 7.3 季节模板的两条路径

| 路径 | 条件 | 行为 |
| --- | --- | --- |
| 默认 | 提供商品参考图 | `image_to_image` + 商品保真基座提示词 |
| 概念图 | 未提供参考图 | 转 `text_to_image`，任务写 `concept_mode=true`，提示词与 UI 均标注"**创意概念图，不代表真实商品外观**"；且**必须填商品名称**，否则 `TEMPLATE_FIELD_REQUIRED` |

### 7.4 维护

首版人工维护，不自动抓取热点，不升级为多步骤编排。模板更新走"新增版本"。

## 8. 跨项目 API 预留

定位：运营工作台尚未开发。首版只做**契约 + 本机测试调用方**；不做真实联通、不做团队额度系统、不做 Webhook。

### 8.1 契约增量（复用现有接口）

| 能力 | 接口 | 增量 |
| --- | --- | --- |
| 能力发现 | `GET /api/models` | `capabilities` + `pricing` + `lifecycle` |
