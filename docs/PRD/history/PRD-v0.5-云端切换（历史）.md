## 1. 目标与红线

**定位**：在画布中生成、编辑、组合素材的电商 AIGC 视觉工作台；工作台与数据在本机，**图片/视频推理在云端**。

| # | 红线 |
| --- | --- |
| N1 | 不做短剧；视频只围绕商品素材 |
| N2 | 界面与文档必须写明「本地工作台 + 云端推理」 |
| N3 | 不得用运镜动效/模板合成替代模型视频生成 |
| N4 | 不编造数据；未执行写「未执行」；模拟测试不得当真实模型验证 |
| N5 | Key 只从 `.env` 读取；不记录、不回显、不进前端产物 |
| N6 | **未经预算批准不得调用付费接口**（后端硬闸门 `BUDGET_NOT_APPROVED`） |
| N7 | 创建超时不得盲目重发（避免重复生成与计费） |

## 6. 数据流与隐私

```
素材上传(本地) → 任务队列(SQLite) → 云端调用(图片同步/视频异步)
  → 视频任务 ID 立即落库 → 轮询 → 结果下载到本地素材库 → 预览接口
```

- **商品图会上传到火山云端**（接口要求）；这是本版与 v0.4.2 的隐私差异，必须写在界面与文档。
- 日志不记 Key、不记图片内容；`remote_task_id`、`usage`、`cost_cny`、耗时入库可追溯。

## 7. 多任务、取消、恢复（云端语义）

| 概念 | 实现 |
| --- | --- |
| 多任务提交/排队 | 本地持久化队列，单 worker（并发度可配，默认 1） |
| 云端任务 ID | 创建成功**立即写库**，重启后继续查询（不重建） |
| 创建超时 | 返回 `CREATE_RESULT_UNKNOWN`，**不自动重发**；保留 `safety_identifier=本地 task_id` 供人工对账 |
| 取消（排队中） | 调官方 `DELETE` → 真取消 → `canceled` |
| 取消（云端运行中） | **无官方能力**：停止本地轮询与下载，状态 `cancel_requested` → `canceled`，并明确提示「云端可能仍在执行并计费」 |
| 失败重试 | 手动重试（可改参数）；自动重试仅限网络类瞬时错误 |
| 重启恢复 | `remote_queued/remote_running` → 保留 `remote_task_id` 重新入队续查；本地 `running` → `interrupted` |
| 断点续跑 | **不实现**，不承诺 |
