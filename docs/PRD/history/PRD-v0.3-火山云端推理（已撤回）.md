## 0. 本版最重要的变更（必读）

### 0.1 运行形态变更【已确认】

### 0.2 对原作业要求的偏离（必须如实记录，不得淡化）

原始要求为「产品运行时全部推理在本地完成，没有云端模型兜底」。**本版改为云端推理，明确偏离该要求。**

由此产生的强约束：

1. **不得宣称本产品满足「端侧 / 本地推理」验收。**任何文档、演示、评测报告都必须写明「推理发生在火山引擎云端」。
2. **不得把「本地」写成产品卖点。**本产品的本地属性只剩：数据与草稿存储、任务编排、界面。
3. **商品图会离开本机**：调用云端接口时必须上传图片内容（URL 或 base64）。这与 v0.2 的隐私前提（商品图不出本机）冲突，**隐私边界已变更**，见 §13 与状态台账 D7。
4. 原「M1 16GB 能否跑模型」的全部结论作废，本机约束只剩磁盘、内存占用（浏览器 + 服务）与网络。

## 1. 产品目标与定位

### 1.1 定位【已确认】

> 在画布中生成、编辑、组合素材的**电商 AIGC 视觉工作台**。工作台、素材与草稿数据、任务队列在**本机**；图片与视频的模型推理**调用火山引擎方舟**。

### 1.2 目标

| 编号 | 目标 | 怎样算做成 |
| --- | --- | --- |
| G1 | 一个商品 → 一套可投放素材，在平台内完成 | 同一素材可在平台内产出多尺寸图片与视频，不需切到其它工具做基础处理 |
| G2 | 图片与视频两条产线共用素材、画布、任务体系 | 画布中的同一素材可直接进入图片批次或视频任务，素材只维护一份 |
| G3 | 批量生产可无人值守跑完，过程中可继续编辑 | 提交 ≥5 个任务后画布编辑不被阻塞；任务中心可见排队/运行/失败/完成 |
| G4 | 云端调用的代价可控、可追溯 | 每次调用记录模型 ID、参数、用量（token/张数）、耗时、估算费用；有预算上限硬约束 |
| G5 | 失败与中断不丢工作 | 云端任务 ID 落库，重启后继续查询；草稿自动保存；失败可读可重试 |

## 3. 能力定义：三种「视频」必须分开命名

| 维度 | ① 生成式视频（模型推理） | ② 运镜动效 | ③ 模板合成 |
| --- | --- | --- | --- |
| 实现 | 云端视频生成模型（本产品使用火山方舟 Seedance 系列） | 静态图缩放/平移（确定性代码） | FFmpeg 拼接素材/字幕/音乐 |
| 输入 | 图片 + 文字描述（I2V）或纯文字（T2V） | 静态图 + 运镜参数 | 多段素材 + 模板 + 文案 |
| 成本 | 按 token 计费（见 §8.3） | 0 | 0（CPU 时间） |
| 是否可称「AI 视频生成」 | 是 | **否**，叫「图片动效」 | **否**，叫「模板合成/剪辑」 |
| 本产品定位 | **场景 B 的唯一合法能力** | 后续可选附加能力，**不得替代 ①** | 后续可选后处理，**不得替代 ①** |

**硬性要求**

1. 若 ① 未跑通，场景 B 记为【未通过】并如实上报；**不得**用 ②/③ 顶上，**不得**把 ②/③ 的结果当 ① 的证据。
2. UI 与文档中，② 只能命名为「图片动效」，③ 只能命名为「模板合成」。v0.3 **已删除** v0.2 中「用动效兜底」的表述，仅保留命名区分要求。

## 4. 场景 A：电商图片生产

### 4.1 输入【建议】

| 项 | 内容 |
| --- | --- |
| 商品原图 | PNG/JPG/WebP，单张上限【建议 20MB，按官方限制核对】 |
| 提示词 | 风格/场景/卖点描述；可使用官方提示词优化参数 |
| 参考图（可选） | 图生图/多图融合输入（云端接口支持字符串或数组） |
| 尺寸 | 目标宽高或官方预设（官方示例含 `2K`、`2048x2048`、`1273x265` 等写法） |
| SKU 组 | 同款不同色的图片可标记为同组，用于一致性检查 |

### 4.2 流程与人工确认点

```
上传商品图 → 本地素材库(asset_id)
   → ① 选参数(风格/尺寸/参考图/SKU组)【人工确认点 C1：点击提交才花钱】
   → ② 本地任务入队 → 调用云端图片生成 → 结果落本地（下载/解码）
   → ③ 回填任务中心与素材库，进入画布【人工确认点 C2：保留/淘汰/重生成】
   → ④ 编辑（后续能力）→ ⑤ 批量导出（后续能力）
```

| 确认点 | 人工判断 | 系统不得自动做 |
| --- | --- | --- |
| C1 | 参数、张数、是否值得花这笔钱 | 自动重跑、自动扩量（每次重跑需显式点击） |
| C2 | 采用哪张、哪张重生成 | 自动删除旧版本 |

### 4.3 输出

图片文件（本地存储）＋ 元数据：模型 ID、提示词、尺寸、张数、用量、估算费用、耗时、响应 request_id。长期保留：原图、生成结果、元数据、草稿。

### 4.4 多 SKU 一致性

路线优先级：**提示词模板 + 参考图（图生图/多图融合）→ 组图模式（官方支持 sequential_image_generation，按生成张数计费）→ 一致性人工评分**。不使用本地微调（运行形态已改为云端）。一致性判定为人工评分项（§9.2）。

## 5. 场景 B：电商视频批量生产

### 5.1 技术含义【已确认】

「电商视频生成」＝ **① 生成式视频**：由云端视频生成模型根据**上传的图片 + 文字描述**生成视频。产品形态为 I2V（图生视频）与 T2V（文生视频）两种任务类型。

### 5.2 I2V / T2V 本次各自的验收要求（明确，不再含糊）

| 任务类型 | 本次（2026-10-22）是否必须验收 | 说明 |
| --- | --- | --- |
| **I2V 图生视频** | **必须** | 输入 = 商品图（首帧）+ 文字描述；这是电商场景主路径 |
| **T2V 文生视频** | **不作为本次验收项** | 接口层面同时支持（同一创建接口，仅 content 不同）；若时间允许跑通则记录，未跑通**不影响**本次视频验收结论，但必须在报告中标注「T2V 未验收」 |

> 判定依据：本产品以商品素材为中心，I2V 是主路径；T2V 不构成独立验收目标，避免把「跑通一个 T2V」当作「场景 B 完成」。
> 若你要求 T2V 也必须在今天验收，请在 Q6 中说明，这会增加当天调用次数与预算。

### 5.3 输入 / 流程 / 输出

**输入【已确认 + 待核对】**

| 项 | 内容 |
| --- | --- |
| 首帧图 | 上传图或素材库中已确认的商品图（I2V 必需；T2V 为空） |
| 文字描述 | 场景/镜头/运动描述（I2V 可选、T2V 必需） |
| 规格 | 分辨率（官方参数 `resolution`）、宽高比（`ratio`）、时长（`duration`，秒）、是否生成音频（`generate_audio`，默认 true）、水印（`watermark`，默认 false） |
| 内容形式 | 官方 `content` 数组，元素类型含 `text` / `image_url`（支持 base64 编码方式），元素可带 `role` |

> 【待核对】官方创建接口的 `content[].role` 具体取值（示例中见到 `reference_image`、`reference_video`；首帧/尾帧的 role 名称需在实现前再次核对文档，不猜）。

**流程**

```
选素材(I2V) → 填文字/规格 → ① 提交【人工确认点 V1：提交即产生费用】
   → ② 本地任务 queued → 创建云端任务，保存 remote_task_id
   → ③ 轮询云端任务状态（remote_queued / remote_running）
   → ④ 成功后 24 小时内下载到本地（官方：URL 有效期 24 小时，2.5 模型下载次数上限 100）
   → ⑤ 任务完成，视频入素材库【人工确认点 V2：预览后保留/重跑】
   → ⑥ 画布编排/拼接/导出（后续能力）
```

**输出**：MP4 本地文件 + 元数据（模型、参数、时长、分辨率、宽高比、fps、token 用量、估算费用、remote_task_id、request_id）+ 失败原因。

### 5.4 成片与时长

| 项 | 值 | 状态 |
| --- | --- | --- |
| 时长 | **3–10s**（Q4 裁决） | 【已确认】；官方接口 `duration` 单位与允许取值【待核对】 |
| 宽高比 | 9:16 主，1:1 / 16:9 次 | 【建议】 |
| 分辨率 | 目标 720p；官方存在 480p/1080p 档位 | 【建议】；具体档位【待核对】 |
| 音轨 | 本次以 `generate_audio=false` 为主（成本与可控性），有声视频作为可选开关 | 【建议】 |

### 5.5 关键风险（风险判断，非断言）

1. 视频单价按 token 计费，单条 5s 720p 的 token 用量在官方示例中为 10.89 万（Seedance 2.0），按单价估算约 ¥5/条量级——**批量生产会快速放大成本**，需预算闸门（§10.7）。
2. 云端视频任务生成耗时可能数十秒到数分钟，若当天网络或配额受限，链路的端到端验证可能被压缩。
3. 视频 URL 24 小时有效、2.5 模型下载上限 100 次——**必须一次下载并本地保存**，否则结果丢失。

## 6. 工作台协作关系

| 模块 | 职责 | 不负责 |
| --- | --- | --- |
| 素材库 | 原件与产物唯一来源（本地存储 + 元数据 + 版本） | 不做推理 |
| 画布 | 空间编排与草稿（本次仅后端草稿接口 + 最简展示） | 不直接调用模型 |
| 生成面板 | 参数 → 提交任务 | 不保存编辑态 |
| 任务中心 | 统一队列：排队/执行/轮询/取消/重试/历史/用量与费用 | 不判断质量 |
| 批量导出 | 后续能力 | — |

**协作规则【已确认】**

- R1 生成中可继续编辑（任务后台执行，不阻塞界面）。
- R2 任务是提交时刻的参数快照，画布后续改动不影响已提交任务。
- R3 产物回填不覆盖用户编辑（新增版本）。
- R4 一切模型调用必经任务中心（禁止旁路调用，否则无法统计费用、无法取消/恢复）。
- R5 素材只存一份（画布引用 asset_id）。

## 10. 多任务、取消、失败与重启恢复（需求层）

### 10.1 概念区分

| 概念 | 本产品做法 |
| --- | --- |
| 多任务提交 | ✅ 本地队列，可一次提交多个 |
| 排队执行 | ✅ 本地工作线程按队列执行；并发度可配置（默认 1，可提高以缩短总时长，但受账号限流约束） |
| 同时推理 | **由云端承担**；本地不再是推理瓶颈，但**并发会放大费用与限流风险**，默认保守 |
| 取消 | 见 §10.3（区分云端排队 / 云端运行两态） |
| 失败恢复 | 有限次自动重试 + 手动重试；失败不阻塞队列 |
| 重启恢复 | 云端任务 ID 落库，重启后继续查询（7 天窗口内） |
| 草稿持久化 | 本地 SQLite + 自动保存；任务执行期间编辑不受影响 |

### 10.2 状态机（本地视角）

```
queued → dispatching → remote_queued → remote_running → downloading → succeeded
   │           │              │              │               │
   │           └→ failed(错误码)  └→ cancel_requested → canceled_local
   └→ canceled            remote_unknown（创建请求超时等）→ needs_reconcile → ...
```

### 10.3 取消语义（按官方能力实现，不夸大）

| 情形 | 官方能力 | 本产品行为 | 用户可见提示 |
| --- | --- | --- | --- |
| 本地 queued（尚未创建云端任务） | — | 直接取消，不产生费用 | 「已取消」 |
| 云端 remote_queued | `DELETE /tasks/{id}` 可取消 | 调用 DELETE，本地置 canceled | 「云端任务已取消」 |
| 云端 remote_running | **官方无取消运行中任务的接口** | 本地置 `cancel_requested`，停止轮询、不下载、不计成功 | 「已停止等待；云端任务可能仍在执行并计费」 |
| 已 succeeded | — | 不可取消；可删除本地产物 | 「已完成」 |

### 10.4 超时与重试（关键约束）

1. **创建请求超时不得盲目重建**：创建接口无幂等键，重发可能产生**重复计费任务**。
   - 处理：创建超时 → 任务置 `remote_unknown`，**不自动重发**；先在本地记录并进入 `needs_reconcile`。
   - 对账手段：使用创建参数 `safety_identifier` 写入本地任务 ID（官方参数存在），随后用「查询视频生成任务列表」接口按时间窗比对；若匹配到则接管该云端任务，若确认不存在则由你决定是否重建。
   - 【待核对】列表接口是否支持按 `safety_identifier` 过滤、返回字段是否包含该值；不支持则退化为「时间窗 + 参数指纹」人工对账，并在文档中写明限制。
2. **轮询**：指数退避（如 3s → 5s → 10s → 20s，上限 30s），不超过本地超时预算；连续网络失败计为「等待中」，不计失败。
3. **重试**：仅对可重试错误（网络、5xx、429）重试；`SensitiveContentDetected`（内容审核）、`InvalidParameter`（参数非法）、`AuthenticationError` **不重试**。
4. **结果下载**：成功后在 24 小时内立即下载并校验（大小/可解码），落本地后才算 succeeded；下载失败可重试下载，**不重新生成**。

### 10.5 重启恢复

- 启动时扫描非终态任务：`remote_running`/`remote_queued` → 继续轮询（依赖持久化的 `remote_task_id`）；`dispatching` → 置 `needs_reconcile`；`downloading` → 重新下载。
- 若云端任务已超出 7 天查询窗口 → 如实标记 `expired_unknown`，提示「云端任务记录已过期，无法查询，需重新生成」。
- 恢复过程在 UI 上提示数量与结果，不静默。

### 10.6 草稿持久化

- 草稿（画布内容 JSON + 引用 asset_id）存本地 SQLite；本地变更短延时自动保存 + 手动保存。
- 版本：保存时生成快照，历史上限可配置；不回写覆盖旧版本。
- 任务执行中编辑保存不受影响（任务持参数快照）。

### 10.7 预算与用量闸门

- 每任务提交时计算**预估费用上限**（图片按张单价；视频按「时长档位 × token 估算系数」保守估算），累计入当日用量。
- 超限 → `BUDGET_EXCEEDED`，不调用云端。
- 每次真实调用后回写实际用量（图片张数 / 视频 tokens + usage），形成用量台账；估算与实际并列显示，便于校准。
