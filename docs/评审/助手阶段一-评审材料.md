### 方式 A：一键复跑（推荐）

```bash
cd /Users/niannian/Documents/VScode/电商工作平台

```

输出会同时写入 `docs/evidence/助手阶段一-20261024/评审演示输出.txt`，可直接对照。
脚本会明确分两段：

- **PART 1【真实】**：只读 GET `/api/health`、`/api/assistant/status`，并故意 POST `/api/assistant/chat` 展示 503 拒绝
- **PART 2【替身】**：临时库副本 + 固定回复，演示 12 个业务段落

### 方式 B：现场看真实服务（只读，免费）

```bash
curl -s http://127.0.0.1:8100/api/assistant/status
curl -s -X POST http://127.0.0.1:8100/api/assistant/chat \
  -H 'Content-Type: application/json' -d '{"message":"帮我润色"}'
```

预期：`available=false / provider=none / vision=false`；chat 返回 **503 ASSISTANT_UNAVAILABLE**。
→ 这证明的是"**没有假装已接通**"，不是"不可用是缺陷"。
