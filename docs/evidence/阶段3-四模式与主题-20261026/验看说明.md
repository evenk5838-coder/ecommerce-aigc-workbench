# 四模式与导演台前端验看

日期：2026-10-26。范围：A 导演台 + C 项目首页、四种生成模式、深浅主题。

## 已核对

- 四模式入口、引用图片显隐、文生视频未接通提示及禁止提交。
- 工作台 1440/768/390 宽度无页面横向溢出；主题切换。
- 导演台使用明确标注的隔离演示数据：需求 → 脚本 → 分镜渐进展示；未来视频/交付表单隐藏。
- 422 项离线测试、typecheck、lint、build、diff 与选定密钥模式扫描通过。构建仍有大包提示。

## 用户验看路径

1. 打开 http://127.0.0.1:5184/，从首页分别进入四种方式。
2. 工作台先选择图片/视频，再选择文生/图生。图生方式需商品原图，文生方式不会暗带参考图。
3. 右上角切换主题，确认描述和模式保留。
4. 导演台打开自己的项目；一次只处理当前步骤，已完成步骤可回看。最终总览依赖服务端交付完成状态。

## 证据边界

`*-mock.png` 为隔离模拟状态，不能作为后端确认链、真实 AI 对话或生成质量证据。`director-browser-mock.js` 在 QA 端口拦截全部 API，禁止写入。工作台截图的素材与任务也隔离为空，避免触发业务数据变更。

本轮没有真实模型调用、没有执行业务写入、没有清理原有草稿或生产页面 localStorage。此前测试过程中已阻止一次草稿自动保存请求。截图中的模拟或失败提示不代表业务数据库被修改。

文生视频后端仍强制首帧，因此前端仅开放入口与描述保存，禁止提交。后端确认链与执行闸门、模板/历史等缺口见 `../../接口/前端-后端待补-四模式与导演台-20261026.md`。当前是前端验看版本，不能宣称完整内测验收通过。
