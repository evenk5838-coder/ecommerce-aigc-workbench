# 本地验收步骤

1. 打开 <http://127.0.0.1:8100/> 并刷新。进入导演台列表，打开已有项目；项目列表仍先于画布出现。
2. 在对话框输入一句话但不发送，返回导演台，再进入项目，草稿应保留。
3. 在实际发送尚未结束时离开应有提醒；点取消留在原项目，不会重复发送。此步骤会产生文本调用，需在用户自己的预算内主动发起；本批自动验收用固定回复完成。
4. 打开结构模板，保存后关闭再返回，不应再提示未保存；继续编辑未保存时仍应提醒。
5. 六节点验收画布可在固定供应商预览 <http://127.0.0.1:52663/> 查看。点“适配”或“重置布局”，节点应避开右侧及底部工具条；选中节点后放大，设置框与节点同步放大。
6. 抓取、框选、单删、批删、撤销保留。验证删除建议用新建的空白文本节点，确认撤销后恢复，避免改动自己的作品。

正式服务未运行时，在项目目录双击 `start.command`。正式入口是 8100；52663 是固定素材验收环境，不能当作真实模型结果。

查看完整本批记录：`docs/阶段文档/前端收尾-20261028.md`。本批没有新增真实付费调用；前批真实媒体质量仍需最终验收。
