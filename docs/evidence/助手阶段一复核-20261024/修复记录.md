# 助手阶段一：四项复核问题修复记录（2026-10-24）

依据：`docs/evidence/助手阶段一复核-20261024/复核记录.md`（Codex 独立复现 4 项缺口）
范围：仅修复这 4 项，未扩大（不涉积分/支付/会员/多 Agent/无限画布）。

## 1. 逐项修复

### A. 连续对话与前端所需数据

| 项 | 修复 |
| --- | --- |
| 多轮上下文 | 新增 `assistant_messages` 表；每轮保存 user/assistant 消息与 `structured_json`；`messages_for_model()` 按 `ASSISTANT_HISTORY_MAX_MESSAGES=8` / `HISTORY_MAX_CHARS=4000` 裁剪 |
| 本轮消息重复 | 先构建历史再落库，保证当前 user 消息只出现一次（测试断言 `count==1`） |
| 刷新恢复 | 新增 `GET /api/assistant/session?project_id=` → 返回最近会话 + 历史 + brief；`find_session_by_project()` 按 `project_id + updated_at` |
| 结构化返回 | `reply_type`（7 种）/ `options` / `optimized_prompt` / `missing_fields` / `quote` / `manual_params` / `submit_payload`；前端不解析自然语言 |
| 工具结果回传 | `provider.chat(..., tool_results=)`；`service.chat` 最多 `ASSISTANT_MAX_TOOL_ROUNDS=3` 轮"调用→观察→继续/停止"，累计工具调用受 `MAX_TOOL_CALLS=3` 约束 |
| 刷新恢复声明 | 契约明确：只实现"按项目恢复最近会话+历史+brief"，未实现跨设备同步/会话分叉 |

### B. 仅优化模式的权限

| 项 | 修复 |
| --- | --- |
| 权限来源 | `service.quote()` 读 `assistant_sessions.intent`；**移除**请求级 `intent` 参与判定（`QuoteIn.intent` 保留但忽略） |
| 工具层二次校验 | `tools._quote` 不再传递请求 intent；`service.quote` 再查会话 |
| 副作用阻断 | `optimize_only` 会话：报价 → `QUOTE_NOT_ALLOWED`；确认 → `CONFIRM_NOT_ALLOWED`；`cancel_task` → `TOOL_FORBIDDEN`（并限制只能取消本会话任务） |
| 意图切换 | 新增 `PUT /api/assistant/intent`；切换写 `assistant_usage(kind=intent_change)` 留痕 |
| 手动路径 | 未改 `POST /api/tasks` 手动分支、`cancel`、`retry` |

### C. 批准重放校验

| 项 | 修复 |
| --- | --- |
| 校验顺序 | `submit_with_approval()` **先算方案哈希并比对**，再做幂等回放；改方案 → `APPROVAL_PLAN_MISMATCH` |
| 同方案重放 | 返回原任务 + `idempotent_replay=true`，不新建 |
| 事务一致性 | 条件更新 `used_count=0` + `INSERT tasks` 在同一 `BEGIN IMMEDIATE` 事务 |
| confirm 边界 | 仍不在工具白名单；`FORBIDDEN_TOOLS={confirm,submit,approve,pay,set_quota}` |

### D. 冻结报价方案（模板版本漂移）

| 项 | 修复 |
| --- | --- |
| 冻结内容 | `assistant_quotes.frozen_json` 存 `submit_payload`（含补全的 `template_version`）+ `resolved`（含最终 prompt/effective/concept_mode）+ 价格/生命周期 |
| 批准继承 | `assistant_approvals.frozen_json` 复制报价冻结内容 |
| 提交执行 | 用 `frozen.resolved.params` 执行，**不重新解析模板**；模型 EOS / 能力校验仍对冻结参数执行 |
| 版本补全 | 请求省略 `template_version` → 用冻结值补全（不算改方案）；显式传不同版本 → 409 |
| 前端交付 | `quote`/`confirm` 返回 `submit_payload`、`resolved_params`、`manual_params`；契约 §5 明确映射，前端不重建提示词 |

## 2. 数据库变更（增量，未重建）

- 新表 `assistant_messages(id, session_id, role, content, reply_type, structured_json, created_at)`。
- `MIGRATIONS` 新增：`assistant_quotes.frozen_json`、`assistant_approvals.frozen_json`、
  `assistant_messages.reply_type/structured_json`（`ALTER TABLE ADD COLUMN`，已存在则跳过）。
- 索引：`idx_assistant_messages`、`idx_assistant_sessions_project`。
- 未改动既有表结构语义；未删除或重写历史任务、素材、草稿、费用记录。
