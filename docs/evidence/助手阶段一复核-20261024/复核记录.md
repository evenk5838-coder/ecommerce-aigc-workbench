## 建议直接修复代码及契约

1. quote 与工具执行按服务端会话意图控制权限，不信任请求传入或省略的 intent。仅优化路径不允许报价、确认、生成或取消任务等副作用。
2. 幂等回放前仍须校验请求与批准绑定的方案；相同方案返回原任务，改变方案明确拒绝。
3. 报价冻结实际模板版本及完整有效方案；确认和提交均依据该快照，模板升版不改变已报价内容。前端取得的提交字段必须完整，不自行重建提示词。
4. 保存并加载必要的连续对话与当前方案，补充前端可直接消费的选项、优化结果、报价引用及转手动参数；不要让前端解析自然语言猜参数。刷新恢复声明限定为真实已实现范围。

当前 provider 的 tool_results 参数尚未在 service.chat 中用于工具结果回传与后续模型处理。真实适配层接入时，应补有限轮的“调用工具→观察结果→回复/下一步”验证；只在前端展示原始工具 JSON 不代表助手已经根据结果完成判断。
