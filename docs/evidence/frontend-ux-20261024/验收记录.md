## 已实现

1. 创作内容与生成设置分组，默认折叠参数并展示当前比例/规格/数量；桌面表单底部保留生成操作区。
2. 参考图按文件名/ID/描述搜索，按上传原图/生成成果筛选；展示尺寸、来源、时间与选中状态；超 10MB 禁用，完整显示图片。
3. 成果卡完整显示图片和视频，展示已有真实描述或素材 ID、创建时间；整理为预览与继续创作，保留参考生图/生视频/排版。
4. 描述与参考图缺失就地提示；素材、任务、模型、费用分别记录读取失败；草稿失败与冲突持续提示。
5. 手机设置/成果快速定位，改善字号与点击区域；窄窗口属性/图层面板可展开。
