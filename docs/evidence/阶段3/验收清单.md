## C. 现场验收步骤（3 分钟）

1. 打开 `http://127.0.0.1:5173`（或 `http://127.0.0.1:8100/`）→ 确认「本地工作台 + 云端推理」标识
2. 生成 1 张图（选 Seedream flash / 1024×1024，约 15s，¥0.12）→ 点「查看」预览
3. 用这张图生成 1 条视频（Seedance 1.0 pro fast / 5s / 9:16 / 720p，约 42s，¥1.56）→ 播放
4. 打开 `http://127.0.0.1:8100/api/usage` → 核对费用
5. 关掉后端 → 重启 → 任务历史与草稿仍在（云端任务会续查，不会重复扣费）
