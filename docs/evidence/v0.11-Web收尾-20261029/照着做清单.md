# 本轮复验

1. 运行 `APP_PYTHON=backend/.venv/bin/python bash verify.sh web-closing`，查看 verify-输出.txt。
2. 发布后刷新本地 8100，项目首页、快捷工作台、素材库、素材预览和任务中心不应出现排版编辑／加入排版入口。
3. 导演台仍可创建项目、打开无限画布；图片生成、视频生成、图生图和图生视频不受本轮隐藏影响。
4. 选中 WebP／JPEG／PNG／MP4 素材后打包，ZIP 扩展名与原文件相符，保留素材记录与 SKU；失败时不能下载不完整 ZIP。
5. 本轮不验收排版 PNG、手机端或新模型质量，不消耗新的真实生成预算。
