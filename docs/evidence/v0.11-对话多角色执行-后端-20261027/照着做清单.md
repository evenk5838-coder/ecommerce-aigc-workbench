# 对话多角色执行后端：复现与下一步

在项目根目录运行：

```bash
APP_PYTHON=/private/tmp/ecom-v011-backend-20261027/bin/python bash verify.sh director-workflow-backend
```

命令创建新时间戳日志和独立临时数据库，不读取真实凭据或接触业务数据。HTTP 检查会短暂启动随机 localhost 端口，停止并重启自己的测试进程；供应商传输被阻断，图片／视频 runner 固定输出，只有本地 FFmpeg 实际合成。不覆盖原 `frontend/dist`。

如执行环境限制 localhost 绑定或 `ps` 读取，应申请运行上述隔离验收所需的权限，保留实际失败和重跑记录，不能跳过检查后标成功。

单独复现两种交付方式（目录必须是新的，脚本拒绝覆盖旧证据）：

```bash
/private/tmp/ecom-v011-backend-20261027/bin/python scripts/check-director-workflow-http.py \
  --evidence-dir /private/tmp/director-http-clips-new
/private/tmp/ecom-v011-backend-20261027/bin/python scripts/check-director-workflow-http.py \
  --film --evidence-dir /private/tmp/director-http-film-new
```

检查 JSON 中的 `passed`、HTTP 原始结果、真实成片时长／顺序和重启前后计数；固定媒体的计划配置与实际 400ms／600ms 时长分别记录，不能包装成真实 5 秒模型输出。

下一批前端：移除旧“讨论／生成脚本”切换，将导演台接到新 conversation API；在同一对话显示职责、脚本／生成／合成确认及进度；按真实 ID 定位画布节点；film 确认明确显示当前镜头顺序和无裁切合成范围。保留节点草稿、手型／选取、删除撤销和独立节点生成。

前端开始前告知用户切换模型。真实模型验收仍须核对具体测试范围与现有预算，保存供应商真实回执及可读取媒体，不能使用本目录的固定红蓝成片替代。
