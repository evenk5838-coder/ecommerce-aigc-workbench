# 自动检查命令与范围

统一入口 `verify.sh director-workflow-backend`，每次生成独立 `verify-<Asia/Shanghai时间戳>-<进程号>.txt`，过程日志不覆盖。

1. 全后端 unittest 与原保留导演回归。临时 SQLite，供应商固定回复／传输拦截，无真实模型调用。
2. 凭据模式扫描：生产源码、现有构建文本、`.env` 忽略规则；不是完整 Git 历史审计。
3. 两次真实 HTTP 进程验证：clips 与 film 各自独立数据库及端口。固定 LLM／图片／视频，真实队列、worker、存储和 FFmpeg；重启同请求与动作回放不重复入队。
4. 前端：本批无前端源码改动；新对话 UI 尚未接入，不标前端验收通过。前序 C 版／画布证据独立保留。
5. 技术文件、`git diff --check` 以及原 `frontend/dist` 指纹。检查不更新正式服务或业务数据库。

两场景的真实红蓝 MP4 仅证明固定输入按顺序被本地合成。真实生成质量、自然语言理解稳定性、完整观看和用户验收仍待后续。

最终执行编号、测试数量和可点击日志由本批阶段文档及项目状态引用，不能把多轮重复测试相加。
