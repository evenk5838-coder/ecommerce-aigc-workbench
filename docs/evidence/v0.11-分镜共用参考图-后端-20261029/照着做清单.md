# 本批复验

1. 运行 `APP_PYTHON=backend/.venv/bin/python bash verify.sh director-reference`。
2. HTTP 结果 `shared_reference_fixture=true`，两张分镜的 `config.input_asset_id` 相同；图片 worker 事件的参考图 SHA 与上传图相同，重启后仍相同，旧确认重放不新增工作。
3. 本批单测验证一镜换图／取消继承只影响该镜，旧组报价不能继续确认，新报价只提交目标镜头。图片供应商方法的两次实际入参均为相同 PNG 的 data URL；供应商本身为固定替身，没有真实联网。
4. 本地 8100 更新后，可在导演台导入商品图片，告诉 Agent“这张是商品参考图，接下来这组分镜都以它为参考”。节点设置可检查引用，随后仅按用户已有预算授权决定是否实际生成。
5. 本批不追加真实模型调用；真实画质和模型能否正确理解引用，另行验证。
