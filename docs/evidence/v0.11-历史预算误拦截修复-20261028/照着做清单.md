# 历史预算误拦截修复复验

1. 在项目根目录运行 `APP_PYTHON=backend/.venv/bin/python bash verify.sh budget-reservation-fix`。
2. 输出应包含后端完整测试、保留导演回归、固定媒体 HTTP 两种交付及重启通过；正式前端文件指纹不变。
3. HTTP 证据的 `legacy_reservation_fixture=true`；重启前后 `legacy_task` 完全相同。共 5 个任务为 1 条旧未知视频 + 4 条新固定媒体任务，媒体替身调用仍为 4，不会执行或重试旧视频。
4. 8100 更新后，刷新页面并打开原项目。生成方案过期时，让 Agent 重新准备当前分镜报价，然后确认。实际付费生成只按用户预算授权执行；本批没有追加付费验收授权。

固定 PNG／MP4、真实 HTTP／SQLite／worker／FFmpeg 与真实模型质量分别记录。本批验收不证明新生成图片的质量。
