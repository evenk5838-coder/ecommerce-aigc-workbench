# 接口契约 v3（本地工作台 + 云端推理；含云端图生图）

> 2026-10-22｜后端 `http://127.0.0.1:8100`（正式前端由后端同源提供，旧页 `/legacy`）
> 本版新增：`generation_mode`（文生图 / 图生图）；其余接口保持不变，**纯增量兼容**。
> 已验证模型：图片 `doubao-seedream-5-0-flash-260915`｜视频 `doubao-seedance-1-0-pro-fast-251015`

## 0. 本轮变更速览

| 项 | 变化 |
| --- | --- |
| 图片任务 | 新增 `params.generation_mode`：`text_to_image`（默认）/ `image_to_image` |
| 参考图 | 沿用顶层 `input_asset_id`；**仅 `image_to_image` 时传给模型** |
| 校验 | 新增 3 个错误码：`REFERENCE_IMAGE_REQUIRED`、`ASSET_NOT_IMAGE`、`INVALID_REFERENCE_IMAGE` |
| 兼容 | 不传 `generation_mode` → 行为与旧版完全一致 |
| 视频 | 不变（首帧图走 `input_asset_id`） |

## 1. 健康与系统

### GET /api/health

```json
{"status":"ok","version":"0.1.0","uptime_s":10,"recovery":{"interrupted":0,"queued":0},"tasks":{"succeeded":3}}
```
### GET /api/system/status
```json
{"memory":{...},"loaded_model":null,"queue":{"queued":0,"active":0},"concurrency":1}
```
### GET /api/models
```json
{"items":[{"id":"doubao-seedream-5-0-flash-260915","provider":"ark","kind":"image",
  "downloaded":true,"loaded":false,"note":"更便宜（0.12 元/张）"}]}
```
> `provider="ark"` 表示云端；`downloaded=true` 仅表示"登记为可用"，真实可用性以调用结果为准。
> 未开通模型（`seedream-5-0-pro`、`seedance 2.0/2.0-fast/2.0-mini/2.5`）应置灰，调用会返回 `MODEL_NOT_OPENED`。

## 2. 素材

### POST /api/assets（multipart，字段 `file`）
```json
{"asset_id":"asset_d73231ab405540b68eb6","sha256":"…","width":1024,"height":1024}
```
- 支持 JPG/PNG/WebP/GIF，≤ `APP_MAX_UPLOAD_MB`（默认 20MB）。
- **只创建素材，不产生任何云端费用**；费用只发生在提交生成任务时。

### GET /api/assets?kind=image&limit=50 ｜ GET /api/assets/{id} ｜ GET /api/assets/{id}/file
`/file` 支持 Range，图片可 `<img>`、视频可 `<video>`。

## 3. 任务（含图生图）

### 3.1 文生图（旧请求，行为不变）

```json
POST /api/tasks
{
  "kind": "image",
  "model_id": "doubao-seedream-5-0-flash-260915",
  "params": {
    "prompt": "白色背景护肤品主图，柔和棚光，留白，电商产品摄影",
    "size": "1024x1024"
  }
}
```
响应：`{"task_id":"task_…","status":"queued","queue_position":1,"estimated_memory_mb":10307}`

> `generation_mode` 缺省 = `text_to_image`。
> 若旧调用带了 `input_asset_id` 但没写 `generation_mode`：**仍按文生图执行，不传参考图**，任务 `params` 会回显 `ignored_reference: true` 供前端提示。

### 3.2 图生图（新增）

```json
POST /api/tasks
{
  "kind": "image",
  "model_id": "doubao-seedream-5-0-flash-260915",
  "input_asset_id": "asset_d73231ab405540b68eb6",
  "params": {
    "generation_mode": "image_to_image",
    "prompt": "以参考图为基础：保留图中的白色瓶子（瓶身形状、瓶盖比例、液滴图标、空白标签区域），仅把背景替换为浅灰白大理石台面，柔和自然光，构图留白不变",
    "size": "1024x1024"
  }
}
```

**实测结果**（真实调用，本文档落盘时已跑通）：

| 项 | 结果 |
| --- | --- |
| 参考图传入方式 | `image` 字段，`data:image/jpeg;base64,…`（**官方示例用 URL，实测 base64 data URL 亦可被接受**） |
| 耗时 | 11.66s / 12.56s（两次） |
| 费用 | ¥0.12/次（估算） |
| 产出 | 1024×1024 JPEG，本地落盘可预览 |
| 一致性 | 见 §3.4（提示词是否枚举主体影响很大） |

### 3.3 校验矩阵（提交时即拦截，不产生费用）

| generation_mode | input_asset_id | 结果 |
| --- | --- | --- |
| 缺省 / `text_to_image` | 无 | ✅ 文生图 |
| 缺省 / `text_to_image` | 有 | ✅ 文生图（忽略参考图，回显 `ignored_reference:true`） |
| `image_to_image` | 无 | ❌ 400 `REFERENCE_IMAGE_REQUIRED` |
| `image_to_image` | 素材不存在 | ❌ 404 `ASSET_NOT_FOUND` |
| `image_to_image` | 素材不是图片 | ❌ 400 `ASSET_NOT_IMAGE` |
| `image_to_image` | 文件缺失/不可解码/超 10MB | ❌ 400 `INVALID_REFERENCE_IMAGE` |
| 其他枚举值 | — | ❌ 400 `VALIDATION_FAILED`（`detail.allowed` 给出允许值） |

实测响应示例：
```json
{"error":{"code":"REFERENCE_IMAGE_REQUIRED","message":"图生图必须提供 input_asset_id（参考图素材 ID）","detail":{"generation_mode":"image_to_image"}}}
{"error":{"code":"ASSET_NOT_IMAGE","message":"参考素材不是图片（kind=video）"}}
{"error":{"code":"VALIDATION_FAILED","message":"generation_mode 只能为 text_to_image 或 image_to_image","detail":{"allowed":["text_to_image","image_to_image"],"got":"img2img"}}}
```

### 3.4 一致性：提示词是否枚举主体，差异很大（实测）

参考图实际为**单个白色瓶子**（`reference_input.jpg`），两次对照实验：

| 尝试 | 提示词 | 结果 |
| --- | --- | --- |
| #1 | 与参考图一致：保留瓶身/瓶盖/标签，仅换背景为大理石台面 | ✅ **1 件 → 1 件**，主体保留、背景替换成功 → 一致性基本通过 |
| #2 | 谎称"保留图中三件产品（罐/泵瓶/软管）" | ❌ 模型**凭空多出罐子与软管**（参考图中不存在）→ 一致性不通过，且属电商高风险 |

> 结论：图生图**会参考原图**；但**提示词会覆盖图中事实**，写错会生成不存在的商品。
> 契约层面不提供"数量一致性校验"（未实现）；SKU 分组不等于一致性保证。

### 3.5 任务查询 / 取消 / 重试

`GET /api/tasks?status=&kind=&batch_id=&limit=`｜`GET /api/tasks/{id}`（含 `params`、`attempts_log`、`remote_task_id`、`usage_json`、`cost_cny`）

`POST /api/tasks/{id}/cancel`

| 情况 | 响应 |
| --- | --- |
| 本地排队 | `{"result":"canceled","phase":"queued"}` |
| 云端排队 | `{"result":"canceled","phase":"cloud_queued","cloud_canceled":true}` |
| 云端运行中 | `{"result":"cancel_requested","phase":"cloud_running","cloud_canceled":false,"message":"…云端可能仍在执行并计费"}` |
| 终态 | `409 CANCEL_REJECTED_PHASE` |

`POST /api/tasks/{id}/retry`（body 可选 `{"params":{...}}` 覆盖参数）

- **重试会保留原任务的 `input_asset_id` 与 `params`**（含 `generation_mode`），实测 `same_ref=true`。
- 重试改 `generation_mode: text_to_image` 时，参考图字段仍保留但不会传给模型。
- 断点续跑未实现，重试即从头重新生成（再次计费）。

## 4. 批量

```json
POST /api/batches
{
  "name": "白底图批量-3尺寸",
  "items": [
    {"kind":"image","model_id":"doubao-seedream-5-0-flash-260915","params":{"prompt":"白底商品图","size":"1024x1024"}},
    {"kind":"image","model_id":"doubao-seedream-5-0-flash-260915","input_asset_id":"asset_…",
     "params":{"generation_mode":"image_to_image","prompt":"换背景为大理石台面","size":"1024x1024"}}
  ]
}
```
响应：`{"batch_id":"batch_…","task_ids":["task_…","task_…"]}`

- 每个 item 独立任务行（各自 `input_asset_id` + `params` 快照）→ **不会串图**（已用两张不同参考图验证：请求体 base64 不同）。
- `GET /api/batches/{id}` 返回 `tasks[]` 状态摘要。

## 6. 用量与费用

`GET /api/usage`
```json
{"budget_cny":20.0,"spent_today_cny":9.3,
 "items":[{"id":"task_…","kind":"image","model_id":"doubao-seedream-5-0-flash-260915",
           "status":"succeeded","cost_cny":0.12,"usage_json":"{…}","latency_ms":11656}]}
```
**口径说明（重要）**：
- 图片 0.12 元/张；视频 **4.20 元/百万 token**（官方核实，不含输入视频）。
- `cost_cny` 是**估算**（单价 × 用量），**不等于账单**。
- 历史视频记录按旧口径 15.0 元/百万 token 记录，偏高约 3.6 倍，**不重算、不篡改**。

## 7. 状态枚举

```
queued → running → succeeded                         (图片)
queued → remote_queued → remote_running → succeeded   (视频)
       ├→ cancel_requested → canceled
       └→ failed
重启：带 remote_task_id 的非终态 → queued(stage=resume_poll) 续查
```

## 8. 错误结构

```json
{"error":{"code":"MODEL_NOT_OPENED","message":"…","detail":{},"task_id":"task_…"}}
```

| code | HTTP | 可重试 | 说明 |
| --- | --- | --- | --- |
| `VALIDATION_FAILED` | 400 | 否 | 参数非法（含 `generation_mode` 枚举） |
| `REFERENCE_IMAGE_REQUIRED` | 400 | 否 | 图生图缺参考图 |
| `ASSET_NOT_IMAGE` | 400 | 否 | 参考素材不是图片 |
| `INVALID_REFERENCE_IMAGE` | 400 | 否 | 参考图损坏/超大/文件缺失 |
| `ASSET_NOT_FOUND` / `TASK_NOT_FOUND` / `DRAFT_NOT_FOUND` | 404 | 否 | 资源不存在 |
| `DRAFT_VERSION_CONFLICT` | 409 | 否 | 草稿版本冲突 |
| `MODEL_NOT_OPENED` | 502 | 否 | 账号未开通该模型 |
| `AUTH_MISSING` / `AUTH_FAILED` | 400/502 | 否 | Key 未配置/无效 |
| `BUDGET_NOT_APPROVED` / `BUDGET_EXCEEDED` | 402 | 否 | 预算未批/超限 |
| `CONTENT_REJECTED` | 422 | 否 | 内容审核 |
| `PROVIDER_BAD_REQUEST` | 400 | 否 | 云端参数不合法 |
| `PROVIDER_RATE_LIMITED` | 429 | 是 | 限流 |
| `PROVIDER_UNAVAILABLE` | 502 | 是 | 云端 5xx/网络 |
| `CREATE_RESULT_UNKNOWN` | 202 | **否** | 创建超时，可能已计费，人工对账 |
| `DOWNLOAD_FAILED` | 502 | 是 | 仅重试下载 |
| `RESULT_URL_EXPIRED` | 409 | 否 | 结果 URL 过期（需重新生成） |
