## 已接接口和行为

models / system/status / usage / assets / tasks / batches / drafts / cancel / retry；2.5 秒轮询。图片结果和视频 MP4 使用 `/api/assets/{id}/file`。云端生成素材 source 为 cloud_generated，已纳入正式素材展示。

画布：图片、文字、色块图层；拖动、尺寸、旋转、不透明度、顺序、复制、删除、撤销；不同画布比例；PNG 导出。素材库可管理 SKU 标签并导出真实文件 ZIP + 元数据。SKU 标签仅管理分组，不代表模型保持商品一致性。

草稿通过 base_version 保存，浏览器恢复副本不含密钥；编辑与生成互不覆盖。版本冲突停止自动覆盖，需核对并恢复副本，尚无合并冲突 UI。前端不提供 API Key 输入框。

CREATE_RESULT_UNKNOWN 隐藏直接重试按钮，先人工对账。其他失败任务从头重试会新建任务；云端调用和重试会提示费用。费用展示来自后端记录，当前为估算，不代表最终账单。
