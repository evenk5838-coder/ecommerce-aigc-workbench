# 节点执行与删除撤销：后端契约 v0.11

日期：2026-10-27。范围：收口计划第 1 步的后端共同执行能力，以及用户新增的单／批量删除撤销。前端按钮、快捷键和 Agent 新工具仍待接入；不能据本文宣称界面或完整创作流程已完成。

## 1. 删除及撤销

保留 `PATCH /api/projects/{project_id}/canvas` 的 `delete_node_ids`，单节点为单元素数组，框选批量为多个 ID。只移除画布表示及关联连线，原素材、脚本版本和任务保留。删除与快照记录处于同一数据库事务。

成功回执新增 `deletion_operation_id`；无实际删除为 `null`。回执仍有 `canvas`、`layout_revision`、`nodes_deleted` 等旧字段。

```json
{"expected_layout_revision":5,"delete_node_ids":["image-1","video-2"]}
```

- `GET /api/projects/{project_id}/canvas/deletions`：返回 `{project_id,operations:[...]}`，最多 100 条最新记录。每条包含 `operation_id/status/node_ids/node_count/delete_layout_revision/created_at/restored_at/restore_layout_revision`。刷新或重开后可找回撤销入口。
- `POST /api/projects/{project_id}/canvas/deletions/{operation_id}/undo`：请求仅接受 `{expected_layout_revision:当前布局修订号}`，返回 `{project_id,operation_id,already_restored,restored_node_ids,layout_revision,canvas}`。

撤销恢复原节点记录身份、位置、类型、正文／配置、绑定以及相关连线；恢复后的配置修订号递增，避免删除前旧编辑覆盖。视口和其他节点的后续编辑保留，不新建媒体任务或费用。

同一次删除的批量恢复原子执行；不允许部分恢复后报成功。已恢复操作重复请求返回 `already_restored=true`，不再增加修订。节点 ID 被新内容占用、较新删除身份冲突、最新脚本已变化、连线端点缺失／新连线冲突／会成环时，返回 `CANVAS_REVISION_CONFLICT`，不静默覆盖。

`CANVAS_DELETION_NOT_FOUND` 为 404，其他项目操作 ID 不可恢复。已删项目继续返回 410。旧 `prune` 验证规则保持兼容；新前端采用显式 `delete_node_ids`。

前端后续：单节点选中删除、框选批删共用上述流程；工具条撤销及画布 Ctrl／⌘+Z 使用删除操作 ID。文字输入中快捷键优先处理文字。撤销删除不是撤销已发生的模型调用，删除节点也不是取消远端任务。

## 2. 独立节点生成

本批支持 `type=image|video` 独立生成节点；不要求先存在脚本或镜头。沿用既有已开通云端模型与真实 worker，不新增模型服务。

生成输入来自服务端保存的节点配置：`generation_mode/model_id/prompt/input_asset_id/params`。模式为文生图、图生图、文生视频、图生视频；图生模式必须有真实可解码的图片，文生模式不能夹带参考图。

- 图片参数：`size/ratio/watermark`。ratio 使用现有比例档，与 size 对应；实际生图尺寸仍以 size 为准。
- 视频参数：`duration/ratio/resolution/generate_audio/watermark/seed`，按模型实际能力校验。
- 当前一次执行为一项媒体任务，不接入多个结果数量；批量方案后续调用统一执行能力组织。

### 报价与冻结输入

`POST /api/projects/{project_id}/canvas/nodes/{node_id}/quote`

```json
{"expected_config_revision":2}
```

body 可省略；带修订号时须与当前配置相符。返回 `quote_id/project_id/node_id/config_revision/input_hash/estimated_cost_cny/expires_at/input/side_effects`。`input` 是实际解析后的 kind、model、参数、输入素材及其 SHA 摘要。报价保留十分钟，不创建任务、不调用模型、不扣费。

按生成实质输入冻结，不因节点位置、视口或标题变化使报价失效。模型、模式、提示词、规格、参考图内容或估算费用改变后，旧报价不能提交。节点被删除后同名新建使用不同内部记录身份，不能沿用旧报价或自动继承旧结果。

### 明确确认并提交

`POST /api/projects/{project_id}/canvas/nodes/{node_id}/generate`

```json
{"quote_id":"nquote_...","client_request_id":"由界面为本次动作生成","user_action":"confirm_generate"}
```

只接受上述字段。用户确认边界，不作为无约束 LLM 工具开放；后续对话确认也必须通过受约束的同一领域服务。一次确认消费报价、创建普通持久化 tasks、写节点执行关联在同一事务内完成。

幂等规则：同项目同请求 ID 和相同内容返回原 execution，带 `idempotent_replay=true`；同请求不同内容返回 409；同报价换新请求号不能再生成。正在生成或远端受理未知时，同节点不能新增第二个任务。重新生成需新报价和新请求，旧产物历史保留。

提交返回 execution 视图，`status=queued` 仅表示已建立任务。服务端检查已记录用量和在途预留，未知远端继续预留；云端已成功而下载失败、费用尚未结算时仍保留估算。停止本地等待不能释放正在远端执行的任务。

## 3. 查询、回写与历史

- `GET .../canvas/nodes/{node_id}/executions` → `{project_id,node_id,executions:[...]}`，最新 100 项历史。
- `GET .../canvas/nodes/{node_id}/executions/{execution_id}` → 单项实时 execution。
- `GET .../canvas` 每节点 `last_execution` 关联其实际任务，并提供 `last_successful_execution`。失败／重生中保留上次成功素材用于展示；任务和产物保留独立身份。

execution 包含 `execution_id/quote_id/client_request_id/task_id/status/stage/progress/active/output_asset_id/asset_id/asset/error/estimated_cost_cny/cost_cny/created_at/finished_at/config_revision/input_hash/input`。状态实时读普通 tasks，不从聊天内容推断完成。`asset` 仅为媒体元数据摘要，不回传文件路径或内部凭据。

节点删除后依旧可查询原 execution；撤销恢复相同内部记录身份，执行关联随之恢复。同名新建节点的 `last_execution` 不继承被删旧节点的任务。

旧 `/api/tasks/{id}/retry` 对有节点执行关联的任务返回 `NODE_EXECUTION_CONFLICT`，引导回节点重新报价，避免绕过统一确认和丢失结果关联。项目删除也拦截本地停止等待但远端未终结的任务。worker 首次提交节点任务前检查排队期间参考图是否改变；已有远端任务续查无需重读本地参考图，不重新提交。

## 4. 错误与恢复

| 错误 | HTTP | 客户端处理 |
| --- | --- | --- |
| CANVAS_NODE_NOT_FOUND | 404 | 刷新画布，不能虚构节点 |
| NODE_NOT_EXECUTABLE | 409 | 选择图片／视频节点及已接入云端模型 |
| NODE_QUOTE_NOT_FOUND | 404 | 重新报价 |
| NODE_QUOTE_EXPIRED／NODE_QUOTE_STALE | 409 | 展示当前参数，重新确认 |
| NODE_QUOTE_CONSUMED | 409 | 查看原任务，不静默换请求重发 |
| NODE_EXECUTION_CONFLICT | 409 | 请求内容冲突或旧重试入口被拒，核对原执行 |
| NODE_EXECUTION_ACTIVE | 409 | 等待／恢复当前任务 |
| NODE_EXECUTION_NOT_FOUND | 404 | 核对项目、节点与执行号 |
| CANVAS_REVISION_CONFLICT | 409 | 保留草稿，重新读取，明确恢复冲突 |
| CANVAS_DELETION_NOT_FOUND | 404 | 操作不存在或不属于此项目 |

沿用已有模型、素材、预算、参数错误。受理结果未知时用原请求号重放或查询 execution，不生成新的请求号自动重发。本轮本地单用户形态沿用，新增多用户鉴权不在本批范围。
