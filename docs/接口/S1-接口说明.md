## 1. 本轮唯一对外新增内容：`GET /api/models` 增加时长策略

### 响应片段（video 模型）

```json
{
  "id": "doubao-seedance-1-0-pro-fast-251015",
  "kind": "video",
  "activation": "verified",
  "lifecycle": {"status": "eos_scheduled", "eos_at": "2026-11-24T14:00:00+08:00"},
  "capabilities": {
    "ratios": ["9:16", "16:9", "1:1"],
    "resolutions": ["480p", "720p", "1080p"],
    "duration_s": [5, 10],
    "duration_range_s": [2, 12],
    "duration_step_s": 1,
    "duration_policy": {"kind": "range", "min": 2, "max": 12, "step": 1, "allowed": null}
  }
}
```

### `duration_policy` 语义（**前端唯一的时长依据**）

| `kind` | 含义 | 前端渲染 |
| --- | --- | --- |
| `range` | 完整有效的 `range + step`（**优先**） | `min..max` 按 `step` 递进的整数秒 |
| `enum` | 缺 range/step 时退回服务端枚举 | 只渲染 `allowed` |
| `unavailable` | 两者都缺/配置非法 | **该模型时长不可选**，显示"时长能力未配置" |
| `null` | 图片模型（不适用） | — |

**前端禁止**：自行猜范围/步长、自行取整、把 `duration_s` 当作唯一依据（它现在只是兼容字段）。

### 当前实读值（2026-10-25）

| 模型 | policy |
| --- | --- |
| `doubao-seedance-1-0-pro-fast-251015` | `range 2–12 step 1` |
| `doubao-seedance-2-0-mini-260615` | `range 4–15 step 1`（**未开通，不可选**） |
| `doubao-seedance-2-0-*` / `2-5` | `unavailable`（未核对/未开通，**不猜**） |

## 2. 时长校验规则（旧任务接口，**兼容不变**）

`POST /api/tasks` 与 `POST /api/tasks/estimate` 仍返回 `MODEL_CAPABILITY_MISMATCH`（HTTP 400），
但 `detail` 结构明确化：

```json
{"error": {"code": "MODEL_CAPABILITY_MISMATCH",
  "message": "模型 doubao-seedance-1-0-pro-fast-251015 的时长不合法：got=5.5（not_integer）",
  "detail": {
    "field": "duration",
    "policy": {"kind": "range", "min": 2, "max": 12, "step": 1, "allowed": null},
    "reason": "not_integer",
    "got": 5.5,
    "got_type": "float"
  }}}
```

| `reason` | 触发 | 示例 |
| --- | --- | --- |
| `not_integer` | 非整数类型（**`5.0` 也算**） | `5.5`、`5.0`、`"5"`、`true`、`[5]` |
| `out_of_range` | 小于 min / 大于 max | `1`、`13`（1.0 pro fast） |
| `step_mismatch` | 不符合步长 | 若 step=2，则 `3` |
| `policy_unavailable` | 模型无可用时长策略 | `doubao-seedance-2-0-260128` |
| `missing` | 未提供且模型默认值非法 | — |

**行为承诺**
1. **绝不** `int()`/`round()` 截断、不夹取、不静默改值（`5.9` → 拒绝，`13` → 拒绝）；
2. 校验通过后，**落库 / 估价 / 供应商请求使用同一个有效整数**（`main.resolve_task` 写回 `params.duration`）；
3. 未提供 `duration` → 使用模型默认 5 秒（并校验默认值是否合法）；
4. **历史任务与历史报价不改写、不重解释**；旧 `5/10` 仍合法。

## 3. 前端接入要点（S1 范围）

| # | 要做 | 依据 |
| --- | --- | --- |
| 1 | 视频比例只渲染模型 `capabilities.ratios`（去掉 3:4/4:3） | 本文件 §1 |
| 2 | 清晰度渲染 `resolutions`；模型不支持则不显示 | 同上 |
| 3 | **时长按 `duration_policy` 渲染**；`unavailable` 时禁用并提示 | 同上 |
| 4 | 切换模型时重建全部选项；保留不兼容值需用户重选（不静默替换） | 同上 |
