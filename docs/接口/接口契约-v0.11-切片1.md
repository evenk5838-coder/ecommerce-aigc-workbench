# v0.11 切片 1 接口增量

日期：2026-10-27。状态：后端实现与隔离测试；前端待接入，真实模型待验。沿用既有接口和错误结构。本文仅冻结本批增量，不能作为媒体节点已可独立执行的证明。

## 1. 对话脚本

`POST /api/projects/{project_id}/director/chat` 保留原字段。新增明确起稿意图 `intent=script`，默认 `auto`；兼容旧值 `generate`／`optimize_only`，但不赋予媒体生成权限。

```json
{"message":"请写一段水杯旋转的脚本","client_request_id":"由客户端为本次动作生成唯一ID","intent":"script","expected_workflow_revision":123}
```

`expected_workflow_revision` 为服务端给出的相等性校验令牌，不自行计算或递增。`session_id`、`selected_asset_ids` 沿用旧契约。已经受理但结果未知时查回执，不用新请求号自动重发。

成功返回保留旧字段，并增加：

```json
{
  "request_status":"completed",
  "reply_type":"proposal_ready",
  "outcome":{"status":"saved","goal":"script","node_ids":["script"]},
  "artifacts":[{"type":"script","proposal_id":"prop_...","proposal_version":1,"target_id":"scr_...","target_version":1,"node_id":"script","persistence":"saved","confirmed":false}],
  "rounds":[{"round":1,"finish_reason":"tool_calls","input_tokens":100,"output_tokens":200}]
}
```

| outcome.status | 含义／前端行为 |
| --- | --- |
| saved | 有真实已保存产物；按 artifacts.node_id 定位画布，从 target_id 读取完整脚本 |
| clarify | 无保存产物的澄清回复；仍留在对话，不显示“脚本已生成” |
| message | 普通对话；不创建空脚本节点，不认定任务完成 |
| failed | 本次执行未完成；展示真实错误，可修改后用新请求号再发 |
| partial | 已有产物成功，后续操作失败；保留成功产物，展示未完成原因 |

失败／部分完成还含 `outcome.error={code,message}`。`goal` 为 `auto|script`；`node_ids` 可为空。显式 script 目标未产生实际保存回执时不会宣称保存成功；普通 auto 澄清仍允许无产物。不要解析自然语言决定是否成功。

`GET /api/projects/{project_id}/director/requests/{client_request_id}` 返回持久化回执：外层 `status=pending|completed|failed`。预算／供应商等硬错误继续返回原 HTTP 错误；其失败回执中 `response.request_status=failed`。HTTP 200 且 `request_status=completed` 仅表示处理有最终结果，仍必须看 outcome。相同请求号和相同内容返回原结果并带 `idempotent_replay=true`，包括已处理的明确失败 outcome；不再花费一次模型调用。

脚本正文 schema 与工具声明同源：`summary` 必填非空字符串，`shots` 可选数组；每条 `hint` 必填非空，`seq` 为正整数（缺省按顺序赋值），`duration_s` 如提供须为正整数。无效字段、截断输出和非法工具参数不会作为草案执行。

脚本版本、提案和稳定 script 节点同事务保存。模型输出不等于确认；现有一次保存并确认接口继续沿用，确认脚本不批准图片／视频费用。

## 2. 自由节点和画布

`GET /api/projects/{project_id}/canvas` 保留 `schema_version=1`、`layout_revision`、`viewport`、`nodes`、`edges`，增加顶层 `project_id` 和节点 `asset` 摘要。

```json
{"node_id":"note-unique-id","type":"text","position":{"x":100,"y":120},"config":{"title":"脚本旁的笔记","text":"第一幕\n第二幕"},"binding":{},"config_revision":1,"last_execution":null,"asset":null}
```

`PATCH /api/projects/{project_id}/canvas`：

```json
{
  "expected_layout_revision":5,
  "nodes":[
    {"node_id":"note-unique-id","type":"text","position":{"x":100,"y":120},"config":{"title":"笔记","text":"正文"}},
    {"node_id":"image-unique-id","type":"image","config":{"generation_mode":"text_to_image","prompt":"描述画面"}},
    {"node_id":"import-unique-id","type":"asset","binding":{"asset_id":"asset_..."}}
  ],
  "viewport":{"x":0,"y":0,"zoom":0.65},
  "edges":[{"from":"note-unique-id","to":"image-unique-id"}]
}
```

| 字段 | 规则 |
| --- | --- |
| type | `text|image|video|storyboard|shot|asset|script`；`script` ID 保留给项目脚本 |
| node_id | 客户端生成不重复的稳定 ID，非空，最长 200 字符 |
| position／viewport | 有限数字；zoom 必须大于 0；拖动只提交 node_id 和 position |
| config | **显式提供时替换整个 config**，省略则保留；编辑单字段先与当前完整配置合并 |
| 文本 | `title`≤200，`text`≤100000 字符，仅 text 节点存正文；项目脚本正文通过脚本版本接口读取／编辑，不复制进 config |
| 媒体 | `generation_mode,model_id,prompt,input_asset_id,params`；prompt≤20000；类型／模式／模型／参数须匹配，图生模式需有效图片引用 |
| binding | `script_id,script_version,shot_id,asset_id`；脚本／镜头须属于项目，脚本版本必须匹配；asset 复用本地全局素材库 |
| asset | 只读 `{id,kind,mime,width,height,duration_ms}`，无路径或完整元数据；无绑定为 null |
| last_execution | 只读真实镜头任务／产物，不接受客户端伪造 |
| expected_config_revision | 节点配置乐观校验，可选；新节点初始配置版本为 0 |
| edges | 暂为组织连线，无自动执行语义；拒绝缺失节点引用、自环和循环 |

不提供 nodes／viewport／edges 不修改对应内容。所有节点和边在一个事务中验证并写入；任一错误整批回滚。布局修改不使生成范围失效；配置／绑定变更会增加配置修订，使旧 scope 确认失效。历史模型当前不可提交时，仍允许仅拖动保存位置。

删除节点：`{"delete_node_ids":["note-unique-id"]}`，可与其他节点更新同次提交；省略 edges 自动移除关联连线，显式 edges 仍引用被删节点则整批拒绝。只删除节点元数据，不删除素材、脚本、任务和成功产物。保留兼容旧 `prune=true` 全量同步，但不得同 delete_node_ids 使用；新前端优先增量提交，避免旧视图误删新节点。

响应保留布局字段，新增 `nodes_deleted` 并带最新 `canvas`。节点创建、配置保存、连线、上传都不创建付费生成任务。

## 3. 图片／视频上传

`POST /api/assets`：`multipart/form-data`，字段 `file`。请求格式不变。保留图片旧返回字段，增加：

```json
{"asset_id":"asset_...","sha256":"...","kind":"video","mime":"video/mp4","width":64,"height":48,"duration_ms":400}
```

真实内容识别，不信任扩展名和客户端 MIME。支持可解码 JPG／PNG／WebP／GIF、MP4／MOV／WebM；沿用 APP_MAX_UPLOAD_MB（默认 20MB）。图片完整解码，视频在临时目录完整解码，最多 30 秒，失败在持久化前拒绝。视频保留真实容器和 MIME，不强制标为 MP4。同一内容复用既有 asset_id，无媒体任务或模型费用。

导入过程为上传→获取 asset_id→PATCH 画布创建 asset 节点。上传成功而节点保存失败时，素材仍在素材库，允许重绑，不重复上传或生成。当前不承诺已有视频已可通过独立节点触发合成，见后续切片。

## 4. 错误与兼容

沿用 `{"error":{"code":"...","message":"...","detail":{}}}`，detail 可选；不向用户渲染堆栈或内部 SQL。

常用错误：`VALIDATION_FAILED`、`CANVAS_REVISION_CONFLICT`、`CANVAS_INVALID_REFERENCE`、`CANVAS_CYCLE`、`GENERATION_MODE_CONFLICT`、`REFERENCE_IMAGE_REQUIRED`、`MODEL_NOT_OPENED`、`MODEL_CAPABILITY_MISMATCH`、`UPLOAD_REJECTED`、`WORKFLOW_REVISION_CONFLICT`、`IDEMPOTENCY_CONFLICT`、`DIRECTOR_REQUEST_PENDING`、`DIRECTOR_REQUEST_FAILED`、预算与已有供应商错误。工具执行错误也会以 outcome.error 和持久化历史反映；HTTP 错误与业务未完成不得混淆。

新 schema／outcome 为增量。旧客户端尚可读取旧字段，但没有新 outcome 逻辑时不能作为 v0.11 验收入口。服务端 note／usage 等调试或计价字段不直接渲染到产品主界面。前端接入前需提前通知用户并等模型切换。
