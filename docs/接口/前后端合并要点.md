> 2026-10-22 16:48｜后端已就绪，形态：**本地工作台 + 火山方舟云端推理**
> 合并目标：`frontend/`（Vite + React，5173）连接后端（FastAPI，8100），完成画布与生成/任务中心闭环。

## 1. 启动与端口

| 服务 | 命令 | 地址 |
| --- | --- | --- |
| 后端 | `cd backend && <venv>/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8100` | `http://127.0.0.1:8100` |
| 前端 | `cd frontend && npm run dev` | `http://127.0.0.1:5173` |

- 后端已配置 **CORS**：允许 `http://127.0.0.1:5173`、`http://localhost:5173`、`http://127.0.0.1:8100`（实测响应头 `access-control-allow-origin` 正确）。
- 前端建议用 Vite 代理 `/api → http://127.0.0.1:8100`（`vite.config.ts`），可避免 CORS 与硬编码端口。
- 后端 `.env` 必须存在（`ARK_API_KEY`、`APP_BUDGET_CNY`）。**前端绝不读 `.env`，也绝不接触 Key。**

## 4. 契约要点（完整见 `docs/接口/接口契约.md`）

- 模型列表：`GET /api/models` → `provider: "local" | "ark"`；云端 `downloaded=true`、`loaded=false`
- 提交任务：`POST /api/tasks`，图片 `params.size`；视频需 `input_asset_id` + `params.{duration,ratio,resolution,generate_audio}`
- 任务状态新增：`remote_queued`、`remote_running`
- 任务详情新增：`remote_task_id`、`remote_status`、`usage_json`、`cost_cny`
- 取消：`POST /api/tasks/{id}/cancel` → `phase: queued | cloud_queued | cloud_running`，`cloud_canceled` 布尔
  **运行中取消必须提示「云端可能仍在执行并计费」**，不得显示"已取消云端任务"
- 费用：`GET /api/usage`
- 预览：`GET /api/assets/{id}/file`（支持 Range，视频可直接 `<video>`）
- SSE：**未实现**，请用轮询（建议 2s）

## 5. 错误码 → UI 文案（建议）

| code | HTTP | 建议文案 |
| --- | --- | --- |
| `AUTH_MISSING` / `AUTH_FAILED` | 400/502 | 请在后端 `.env` 配置有效的 ARK_API_KEY |
| `MODEL_NOT_OPENED` | 502 | 该模型未开通，请到火山方舟控制台开通 |
| `BUDGET_NOT_APPROVED` / `BUDGET_EXCEEDED` | 402 | 预算未设置/已用完，见 `.env` 的 APP_BUDGET_CNY |
| `CONTENT_REJECTED` | 422 | 内容审核未通过，请调整提示词 |
| `CREATE_RESULT_UNKNOWN` | 202 | 创建结果未知，不会自动重试，请核对任务记录 |
| `PROVIDER_RATE_LIMITED` | 429 | 云端限流，稍后自动重试 |
| `MODEL_OOM` / `MEMORY_PREDICTED_OVER` | 507 | 仅本地模型形态出现，云端形态一般不会遇到 |
