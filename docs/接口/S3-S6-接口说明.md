# S3–S6 后端接口说明（镜头 / 分镜 / 整组生成 / 成片 / 结构模板 / 导出）

日期：2026-10-26｜对应 PRD **v0.10 定稿**、导演台路线 20261026｜状态：**已实现 + 免费验收通过**
前端（Codex）可按本文接入；`frontend/` 未改动。

> 单 worker 顺序执行：所有"整组"接口在响应里显式返回 `sequential: true`，前端**不得**展示为并行。

## 0. 导演台就绪度（前端驱动"逐步出现"的唯一依据）

### GET /api/projects/{id}/director

```json
{
  "project_id": "prj_…",
  "current": {"stage": "storyboard",
              "script": {"script_id":"scr_…","version":1,"confirmed_at":1792…},
              "confirmation": {"confirmed":true,"valid":true,"status":"active","object_version":1}},
  "stages": [
    {"key":"requirements","label":"需求","status":"done","visible":true,"actions":[]},
    {"key":"script","label":"脚本与镜头计划","status":"done","visible":true,"actions":[]},
    {"key":"storyboard","label":"分镜画面与审核","status":"current","visible":true,"actions":["generate_storyboard","review_storyboard"]},
    {"key":"video","label":"视频生成","status":"locked","visible":false,"actions":[]},
    {"key":"delivery","label":"成片交付","status":"locked","visible":false,"actions":[]}
  ],
  "allowed_actions": ["edit_shot_plan","add_shots","generate_storyboard","review_storyboard"],
  "warnings": [],
  "counts": {"scripts":1,"shots":0,"takes":0,"films":0}
}
```

- `visible=false` 的步骤**不要预铺**空卡/表单；只有当前及已完成步骤可见。
- `current.confirmation.valid=false` 时**不能**继续下一步，展示 `warnings[].message`（含失效原因）。
- **本接口不调用模型**，可随意刷新/切换步骤。

确认相关错误码：`SCRIPT_NOT_CONFIRMED`(409)、`SCOPE_REQUIRED`(409)、`SCOPE_EXPIRED`(409)、`SCOPE_STALE`(409)。

## 1. 镜头（S3）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/projects/{id}/shots` | `{script_id, shots:[{seq?,description,duration_s,motion?}], model_id?}` |
| GET | `/api/projects/{id}/shots` | 列表（含分镜摘要） |
| PATCH | `/api/shots/{id}` | `{description?,duration_s?,motion?,expected_revision?}` |
| DELETE | `/api/shots/{id}` | 删除（其余镜头保留） |
| POST | `/api/projects/{id}/shots/reorder` | `{order:[shot_id…]}` |

规则：
- 需**脚本确认有效**，否则 409 `SCRIPT_NOT_CONFIRMED`；
- `duration_s` 必须是**模型原生区间内整数秒**（1.0 pro fast 2–12），小数/越界 → 400；
- 编辑带 `expected_revision`，不一致 → 409 `SHOT_REVISION_CONFLICT`；
- **重排只影响成片顺序**，不使分镜/镜头产物失效，不触发生成。

## 2. 分镜（S3）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/storyboards/quote` | `{shot_ids, model_id, size}` → 只报价，不建任务 |
| POST | `/api/shots/{id}/storyboard` | `{model_id, confirm, size?, prompt?, input_asset_id?}`；`confirm=false` 只报价 |
| GET | `/api/storyboards/{id}` | 版本/状态/素材 |
| POST | `/api/storyboards/{id}/review` | `{approve:true}` 或 `{approve:false, reason}` |

- `confirm=true` 才建**图片任务**（复用现有任务系统，费用按张）；
- 审核通过 → 写 `confirmations`（绑定 `storyboard_id+version`）；**新版本不继承批准**；
- 驳回必须给 `reason`，该镜回到 `draft`（单镜重做）。

## 3. 整组生成（S4）

### POST /api/projects/{id}/scope

```json
{"mode":"full","shot_ids":["shot_1","shot_2"],
 "specs":{"model_id":"doubao-seedance-1-0-pro-fast-251015","ratio":"9:16","resolution":"720p"}}
```

```json
{"scope_id":"scp_…","mode":"full",
 "shots":[{"shot_id":"shot_1","duration_s":5,"estimate_cny":0.4536}],
 "total_estimate_cny":0.9072,"planned_film_duration_s":10,
 "scope_hash":"sha256:…","expires_at":1792…,
 "side_effects":{"tasks_created":0,"model_called":false}}
```

- `mode`: `full`（生成完整视频，成功后自动拼接）| `clips`（只交付独立片段）；
- **冻结每镜完整输入**（描述/提示词/分镜 id+版本/素材/规格/时长）；
- 任一变化 → 提交时 409 `SCOPE_STALE`（必须重新报价+确认）；
- 未确认 → 409 `SCOPE_REQUIRED`；过期（600s）→ 409 `SCOPE_EXPIRED`。

### POST /api/scopes/{id}/confirm  → `{confirm:true}`

### POST /api/projects/{id}/generate  → `{scope_id}`

```json
{"batch_id":"batch_…","mode":"full",
 "tasks":[{"shot_id":"shot_1","task_id":"task_…","take_id":"take_…"}],
 "auto_film":true,"sequential":true}
```

- 单事务：消费 scope + batch + N tasks + N takes + 收据；失败**整组回滚**；
- 重复提交 → **返回原 batch**（`idempotent_replay=true`）。

### GET /api/projects/{id}/status

逐镜状态 + take + 成片（**刷新恢复唯一入口**）：

```json
{"current_stage":"video","shots":[
  {"shot_id":"shot_1","seq":1,"duration_s":5,
   "storyboard":{"storyboard_id":"sb_…","version":1,"asset_id":"asset_…","approved":true},
   "take":{"take_id":"take_…","task_id":"task_…","status":"succeeded",
           "asset_id":"asset_…","actual_duration_ms":5042},"takes":1}],
 "films":[],"allowed_actions":["compose_film"],"warnings":[]}
```

### POST /api/takes/{id}/retry

- **只重做该失败镜**；成功镜返回 400（需新建范围）；历史 take 保留。

## 4. 成片（S5）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/projects/{id}/films` | `{take_ids?, confirm_partial?}` |
| GET | `/api/films/{id}` | 详情 |
| GET | `/api/projects/{id}/films` | 版本列表（历史保留） |

```json
{"film_id":"flm_…","version":2,"status":"ready|partial","partial":false,
 "planned_duration_s":10,"actual_duration_ms":10084,
 "items":[{"shot_id":"shot_1","take_id":"take_…","actual_duration_ms":5042}],
 "clip_count":2,"note":"纯拼接，不裁剪/变速/补帧"}
```

- **缺镜默认 409 `FILM_MISSING_SHOTS`**（返回 `missing_shots`）；
- 只有显式 `confirm_partial=true` 才产出 `status="partial"` 的**部分成片**；
- **计划时长与实测时长分字段**，不得混用；版本只增不覆盖。

## 5. 结构模板（S6）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/structure-templates` | `{name, snapshot:[{seq,role,duration_s,motion,rhythm}]}` |
| POST | `/api/projects/{id}/structure-templates` | 从项目另存 `{name}` |
| GET | `/api/structure-templates/{id}?version=` | 查看（含版本） |
| POST | `/api/projects/{id}/apply-structure` | `{template_id, version?}` |

- 模板**只含结构**，不含商品事实/素材；
- 时长同样严格校验（5.5 / 99 拒绝）；
- 套用生成**镜头骨架**，需重填 brief/素材并**重新校验模型**；项目记录模板版本，**升级不自动跟随**。

## 6. 导出（S6）

POST `/api/projects/{id}/export` → `{export_id, file_name, path, bytes, includes}`
zip 内含 `manifest.json` + 成片/片段/分镜图；**导出不重新生成**。
