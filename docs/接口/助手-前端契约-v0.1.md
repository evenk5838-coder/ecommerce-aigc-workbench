# 助手前端契约 v0.1（阶段一，已实现，可并行接入）

日期：2026-10-24｜后端已实现并跑通隔离测试（27/27，零付费）
对应：`docs/接口/助手-阶段一模块与接口约定.md`

> **重要前提**
> - **未配置 LLM**：`GET /api/assistant/status` 返回 `available=false`。此时前端必须显示
>   「助手暂不可用，可直接使用工作台生成」，**不得**用假回复模拟已接通。
> - `ASSISTANT_PROVIDER=fixed` 仅是**自动化测试替身**，正式页面不得配置成 fixed。
> - 助手**不改变**任何现有页面行为；不打开助手也能完成全部操作。
> - 助手**没有**提交/确认能力：提交由前端在用户点击确认后调用 `POST /api/tasks`。

---

## 1. 接口总览

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/assistant/status` | 可用性（未配置时 `available=false`） |
| POST | `/api/assistant/chat` | 对话（非流式） |
| GET | `/api/assistant/brief?project_id=` | 读 brief |
| PUT | `/api/assistant/brief?project_id=` | 存 brief（合并） |
| POST | `/api/assistant/quote` | 助手报价（不建任务、不扣费） |
| POST | `/api/assistant/confirm` | **用户点击确认** → 一次性批准 |
| GET | `/api/assistant/quote/{quote_id}` | 查报价单（含 payload/effective） |
| GET | `/api/assistant/usage?session_id=` | 助手用量（与生成用量分开） |
| GET | `/api/assistant/session/{session_id}` | 会话状态与限额 |
| POST | `/api/tasks` | 增量：带 `approval_id` 提交（手动路径不传） |

## 2. 状态与对话

### GET /api/assistant/status

```json
{"available": false, "provider": "none", "model": "", "vision": false,
 "streaming": false,
 "note": "助手未配置语言模型，暂不可用；可直接使用工作台手动生成"}
```

前端：`available=false` → 助手入口可展示但点击后显示该提示；**不要**隐藏错误或伪造回复。

### POST /api/assistant/chat

请求：

```json
{
  "session_id": null,
  "project_id": "draft_ab12",
  "message": "帮我润色这句：白瓶 大理石 2K 方图",
  "intent": "optimize_only",
  "brief": {"subject": "单瓶精华液"},
  "context": {"selected_asset_id": "asset_d73231ab405540b68eb6", "kind": "image"}
}
```

- `intent`：`optimize_only` | `generate` | `auto`（默认 `auto`）
  - **`optimize_only` 时后端拒绝任何报价**（`QUOTE_NOT_ALLOWED`），前端不要显示"确认生成"按钮。
- `session_id` 为 null → 后端新建会话并返回 id，前端保存。
- `brief`：可选，传入即合并保存（只存用户确认过的信息）。

响应：

```json
{
  "session_id": "asst_9f1c…",
  "reply": "优化后：以参考图中的商品为准，保留外形与标签……",
  "intent": "optimize_only",
  "brief": {"subject": "单瓶精华液"},
  "tool_calls": [
    {"tool": "list_templates", "ok": true, "result": {"items": []}}
  ],
  "awaiting_facts": null,
  "session": {
    "session_id": "asst_9f1c…", "project_id": "draft_ab12",
    "intent": "optimize_only", "status": "active",
    "limits": {"turns_used": 1, "turns_max": 12,
               "questions_used": 0, "questions_max": 4,
               "tool_calls_used": 1, "tool_calls_per_turn_max": 3},
    "usage": {"input_tokens": 0, "output_tokens": 0}
  },
  "provider": {"name": "fixed", "model": "fixed-test", "stub": true},
  "note": "当前为测试替身回复，不代表真实模型能力"
}
```

- `awaiting_facts != null` → 表示提问已达上限，进入**待补充**：
  ```json
  {"reason": "questions_limit_reached", "questions_used": 4, "questions_max": 4,
   "hint": "请补充缺失的商品事实或素材；助手不会用假设补齐后生成"}
  ```
  前端应显示"请补充：商品名称/数量/素材"，**不要**给提交按钮。
- `note` / `provider.stub=true` → 必须显著标注"测试替身"，不得当作已接通。
- `tool_calls[].ok=false` 时带 `error.code`（如 `QUOTE_NOT_ALLOWED`、`TOOL_FORBIDDEN`）。

## 3. brief

### GET /api/assistant/brief?project_id=draft_ab12

```json
{"project_id": "draft_ab12", "version": 2,
 "brief": {"subject": "单瓶精华液", "forbidden_elements": "不要人物", "style": "简约"}}
```

### PUT /api/assistant/brief?project_id=draft_ab12

```json
{"brief": {"spec_preference": "5 秒 · 9:16"}}
```

- 合并语义：只覆盖传入字段；`version` 递增。
- 允许字段：`subject`、`key_selling_points`、`keep_features`、`forbidden_elements`、
  `audience`、`style`、`spec_preference`、`assumptions`。未知字段 → 400 `VALIDATION_FAILED`。
- `assumptions` 只放"待用户确认的建议"，**不得**当作商品事实展示。

## 4. 报价 → 确认 → 提交（三段式，必须按此顺序）

```
① POST /api/assistant/quote    → quote_id + effective + 费用（报价，不是批准）
② 用户在界面点「确认生成」        → POST /api/assistant/confirm → approval_id
③ POST /api/tasks + approval_id → 真正入队（只有这一步会产生生成费用）
```

### ① 报价

```json
POST /api/assistant/quote
{
  "session_id": "asst_9f1c…",
  "project_id": "draft_ab12",
  "payload": {
    "kind": "video",
    "model_id": "doubao-seedance-1-0-pro-fast-251015",
    "input_asset_id": "asset_cd91e2f9dda14123a622",
    "template_id": "tpl_product_motion_5s",
    "template_version": 2,
    "template_fields": {"motion": "推近特写", "duration": 5, "ratio": "9:16"}
  }
}
```

响应：

```json
{
  "quote_id": "q_5b0e…", "plan_hash": "sha256:70658e…",
  "expires_at": 1792690000.0, "cost_cny": 0.4536,
  "estimated_cost_cny": 0.4536,
  "effective": {"duration": 5, "ratio": "9:16", "resolution": "720p", "generate_audio": false},
  "kind": "video", "model_id": "doubao-seedance-1-0-pro-fast-251015",
  "template_id": "tpl_product_motion_5s", "template_version": 2,
  "template_name": "5 秒商品动态展示", "concept_mode": false,
  "warnings": [],
  "model_lifecycle": {"status": "eos_scheduled", "eos_at": "2026-11-24T14:00:00+08:00",
                      "migrate_to": "doubao-seedance-2-0-mini-260615",
                      "migrate_to_activation": "not_opened"},
  "side_effects": {"task_created": false, "queued": false, "model_called": false, "budget_deducted": false},
  "next_step": "用户确认后调用 POST /api/assistant/confirm，再用 approval_id 提交"
}
```

前端展示：模板名 + `effective` + 费用（标注"估算，非账单"）+ `model_lifecycle` 提示。
**报价有效期默认 600 秒**；过期需重新报价。

### ② 用户确认

```json
POST /api/assistant/confirm
{"session_id": "asst_9f1c…", "quote_id": "q_5b0e…",
 "project_id": "draft_ab12", "user_action": "confirm_generate"}
```

响应：

```json
{"approval_id": "ap_3c08…", "quote_id": "q_5b0e…", "plan_hash": "sha256:70658e…",
 "expires_at": 1792690000.0, "max_uses": 1,
 "session_id": "asst_9f1c…", "project_id": "draft_ab12",
 "cost_cny": 0.4536,
 "effective": {"duration": 5, "ratio": "9:16", "resolution": "720p", "generate_audio": false},
 "next_step": "POST /api/tasks 携带 approval_id 提交"}
```

- **只能由用户点击触发**；`user_action` 固定为 `confirm_generate`。
- 批准**一次性**（`max_uses=1`），有效期默认 600 秒。
- 前端不得缓存批准跨方案复用；任何参数改动后需重新报价 + 重新确认。

### ③ 提交

```json
POST /api/tasks
{
  "kind": "video", "model_id": "doubao-seedance-1-0-pro-fast-251015",
  "input_asset_id": "asset_cd91e2f9dda14123a622",
  "template_id": "tpl_product_motion_5s", "template_version": 2,
  "template_fields": {"motion": "推近特写", "duration": 5, "ratio": "9:16"},
  "approval_id": "ap_3c08…"
}
```

响应（新增字段）：

```json
{"task_id": "task_9a2f…", "status": "queued", "queue_position": 1,
 "estimated_cost_cny": 0.4536, "origin": "assistant",
 "caller_id": "assistant", "approval_id": "ap_3c08…",
 "idempotent_replay": false}
```

- 提交的 `kind/model_id/input_asset_id/template_id/template_version/template_fields/params`
  必须与报价时**完全一致**，否则 `APPROVAL_PLAN_MISMATCH`。
- 重复提交同一批准 → 返回**同一任务** `idempotent_replay=true`，不重复生成。
- `origin` 与 `caller_id` 由后端确定，前端传 `caller_id` 无效。

## 5. 错误码

| code | HTTP | 前端处理 |
| --- | --- | --- |
| `ASSISTANT_UNAVAILABLE` | 503 | 显示"助手暂不可用，可直接使用工作台"，不重试 |
| `ASSISTANT_SESSION_NOT_FOUND` | 404 | 清空本地 session_id，开新会话 |
| `ASSISTANT_TURN_LIMIT` | 429 | 提示"本次会话轮次已达上限，请新建会话" |
| `ASSISTANT_BUDGET_EXCEEDED` | 429 | 提示会话消耗达上限 |
| `TOOL_FORBIDDEN` | 400 | 内部错误（不应出现），记录日志 |
| `QUOTE_NOT_ALLOWED` | 400 | 仅优化会话不可报价；隐藏生成入口 |
| `QUOTE_NOT_FOUND` / `QUOTE_EXPIRED` | 404 / 409 | 重新报价 |
| `QUOTE_SESSION_MISMATCH` | 400 | 清空会话，重新报价 |
| `APPROVAL_NOT_FOUND` | 404 | 回到报价步骤 |
| `APPROVAL_EXPIRED` | 409 | 重新报价 + 重新确认 |
| `APPROVAL_PLAN_MISMATCH` | 409 | 参数已变：**重新报价 + 重新确认** |
| `APPROVAL_ALREADY_USED` | 409 | 一般说明幂等未命中；重新报价 |

参数/模型类错误沿用 `docs/接口/接口契约.md`（`MODEL_EOS`、`MODEL_CAPABILITY_MISMATCH`、
`TEMPLATE_FIELD_REQUIRED` 等）。

## 6. 「转为直接操作」参数映射

用户在助手侧确认好 brief/字段后，切换到普通创作页时按下表填充（**不重新询问**）：

| 创作页字段 | 来源 |
| --- | --- |
| 生成类型（生图/生视频） | `quote.payload.kind` 或 `brief` 的意图 |
| 模板 | `quote.payload.template_id` + `template_version` |
| 模板字段 | `quote.payload.template_fields`（含 `*_custom`） |
| 参考图 / 首帧图 | `quote.payload.input_asset_id`（`context.selected_asset_id`） |
| 模型 | `quote.payload.model_id` |
| 比例 / 尺寸 / 时长 | `quote.effective.ratio` / `effective.size` / `effective.duration` |
| 提示词 | `quote` 响应不含 prompt；如需展示，用 `GET /api/assistant/quote/{id}` 的 `payload` 或在创作页用同一模板字段重建 |
| 生成方式 | `effective.generation_mode`（概念图时 `concept_mode=true`，需显著标注） |

注意：转入直接操作后**不再受助手批准约束**，属于手动路径（用户自己点确认生成）。

## 7. 会话与限额

- 限额（仅助手，不影响手动）：
  - 提问上限 4（达到且仍在追问 → `awaiting_facts`，不生成）
  - 轮次上限 12 → 429
  - 单轮工具 ≤3
  - 单会话消耗上限默认不限（`ASSISTANT_MAX_SESSION_COST_CNY=0`）
- 新会话只重置**会话级**计数，不清零工作区消耗与预算。
- 会话/报价/批准/用量均落 SQLite，**刷新页面不丢**（重启后仍在）。

```

```

```json
{"session_id": "asst_9f1c…",
 "assistant": {"by_kind": [{"kind": "llm", "n": 2, "ti": 1200, "to_": 300, "tc": 1, "c": 0}],
               "input_tokens": 1200, "output_tokens": 300, "tool_calls": 1,
               "estimated_cost_cny": 0.0},
 "generation": {"tasks": 1, "estimated_cost_cny": 0.0,
                "note": "与助手用量分开记录；均为估算，非账单"},
 "disclaimer": "助手用量为 LLM token 记录；未实现积分账本/余额/支付。"}
```

前端要求：
- 助手用量与生成费用**分开展示**；
- **不得**显示虚构的可消费余额（账本/支付未实现）；
- 所有金额标注"估算，非账单"。

## 9. 前端接入顺序建议

1. `status` → 决定助手入口可用态。
2. `chat` + `brief`（先接"仅优化"路径，无费用、无风险）。
3. `quote` → 展示费用与 `effective`。
4. `confirm`（用户点按钮）→ `POST /api/tasks` 带 `approval_id`。
5. 「转为直接操作」按 §6 映射填充。
6. `usage` 分开展示。
