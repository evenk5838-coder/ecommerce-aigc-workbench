## 1. 能力发现（增量字段）

### GET /api/models

```json
{
  "id": "doubao-seedance-1-0-pro-fast-251015",
  "kind": "video", "activation": "verified",
  "capabilities": {
    "ratios": ["9:16", "16:9", "1:1"],
    "resolutions": ["480p", "720p", "1080p"],
    "duration_s": [5, 10],
    "duration_range_s": [2, 12],
    "duration_step_s": 1
  },
  "lifecycle": {"status": "eos_scheduled", "eos_at": "2026-11-24T14:00:00+08:00"}
}
```

**前端规则（B10）**
- 时长选项 = `duration_range_s[0]..[1]` 按 `duration_step_s` 递进的**整数秒**；
- `activation != "verified"` 的模型**不可选**；
- **禁止**前端自行取整/夹取；提交越界或小数秒会被后端拒绝。

## 3. 脚本

### POST /api/projects/{id}/scripts

```json
{"source": "assistant", "instruction": "偏简洁，突出质地", "target_duration_s": 20}
```

```json
{"script_id": "scr_…", "version": 3, "content": {"summary": "…", "shots": [{"seq": 1, "hint": "瓶身特写"}]},
 "source": "assistant", "llm_usage": {"input_tokens": 900, "output_tokens": 210},

```

- **用户主动触发**；每次调用生成**新版本**（`version` 递增，不覆盖旧版）。
- 助手不可用时：`assistant_unavailable: true` + `hint`，**不报 5xx**，前端引导手工编写。

### GET /api/projects/{id}/scripts ｜ GET /api/scripts/{script_id}

### PATCH /api/scripts/{script_id}

手工编辑 → **新建版本**（`content` 变更不允许原地改历史版本）。

### POST /api/scripts/{script_id}/confirm

```json
{"confirm": true}
```

```json
{"script_id": "scr_…", "version": 3, "confirmed_at": 1792…, "unlocked": ["storyboard_plan"]}
```

- 确认绑定 `script_id + version`；**不自动触发生成**。

## 5. 生成范围（整组确认）

### POST /api/projects/{id}/scope

```json
{"mode": "full",                                  // full=模式1 生成完整视频；clips=模式2 生成分镜视频
 "shot_ids": ["shot_1", "shot_2", "shot_3"],
 "specs": {"model_id": "doubao-seedance-1-0-pro-fast-251015",
           "ratio": "9:16", "resolution": "720p"},
 "overrides": {"shot_2": {"duration_s": 5}}}
```

```json
{
  "scope_id": "scp_…", "mode": "full",
  "shots": [
    {"shot_id": "shot_1", "duration_s": 6, "estimate_cny": 0.53},
    {"shot_id": "shot_2", "duration_s": 5, "estimate_cny": 0.44},
    {"shot_id": "shot_3", "duration_s": 4, "estimate_cny": 0.36}
  ],
  "total_estimate_cny": 1.33,
  "planned_film_duration_s": 15,
  "scope_hash": "sha256:…",
  "expires_at": 1792…,
  "side_effects": {"tasks_created": 0, "model_called": false}
}
```

- **只报价，不建任务、不调模型**。
- `planned_film_duration_s` = 各镜时长之和（**计划值，不是实测**）。
- 任一镜头不可用（模型未开通/EOS/时长不支持）→ 400/409，**整组拒绝**（不部分报价）。

### POST /api/scopes/{scope_id}/confirm

```json
{"confirm": true}
```

```json
{"scope_id": "scp_…", "approved": true, "expires_in_s": 600, "max_uses": 1}
```

- **只能由用户界面点击**；成功后 10 分钟内一次性可用。

### POST /api/projects/{id}/generate

```json
{"scope_id": "scp_…"}
```

```json
{"batch_id": "batch_…", "mode": "full",
 "tasks": [{"shot_id": "shot_1", "task_id": "task_…"}, {"shot_id": "shot_2", "task_id": "task_…"}],
 "auto_film": true}
```

- 校验：scope 未过期、已批准、未使用、`scope_hash` 与当前镜头集合/规格一致。
- 一次创建 N 个任务进**同一 batch**；**单 worker 顺序执行**（响应含 `sequential: true`）。
- 重复提交同一 scope → 返回**原 batch**（幂等）。

### GET /api/projects/{id}/status

```json
{"project_id": "prj_…",
 "mode": "full",
 "shots": [{"shot_id": "shot_1", "status": "succeeded", "take_id": "tk_…", "asset_id": "asset_…", "actual_duration_ms": 6042},
           {"shot_id": "shot_2", "status": "failed", "error_code": "PROVIDER_UNAVAILABLE"}],
 "batch": {"batch_id": "batch_…", "queued": 0, "running": 1, "succeeded": 1, "failed": 1},
 "film": null}
```

- **刷新恢复的唯一入口**：项目/镜头/take/成片状态一次取回。
- `actual_duration_ms` 来自产物探测，**不是**计划值。

## 6. 成片

### POST /api/projects/{id}/films

```json
{"take_ids": ["tk_1", "tk_2", "tk_3"], "confirm_partial": false}
```

```json
{"film_id": "flm_…", "version": 1, "status": "composing"}
```

- 缺镜且 `confirm_partial=false` → 409 `FILM_MISSING_SHOTS` + `missing_shot_ids`；
- 用户显式 `confirm_partial=true` 才允许"部分合成"，响应标注 `partial: true` 与缺失列表；
- **不裁剪**：纯拼接；`version` 递增，旧版本保留。
- 模式1（`mode=full`）在整组成功后由系统自动调用本接口（`auto_film`）。

### GET /api/films/{film_id} ｜ GET /api/films/{film_id}/file

```json
{"film_id": "flm_…", "status": "ready",
 "planned_duration_s": 15, "actual_duration_ms": 15086,
 "items": [{"shot_id": "shot_1", "take_id": "tk_1", "actual_duration_ms": 6042}],
 "partial": false, "asset_id": "asset_…"}
```

- **计划时长与实际时长分别返回**，不得混用。

## 9. 新增错误码

| code | HTTP | 触发 | 前端处理 |
| --- | --- | --- | --- |
| `DURATION_NOT_SUPPORTED` | 400 | 时长越界/小数/不符合步长 | 高亮时长输入，提示可选范围（不自动改值） |
| `SCOPE_REQUIRED` | 409 | 未先创建范围就提交 | 回到"整组确认" |
| `SCOPE_EXPIRED` | 409 | 超过有效期 | 重新创建范围（重新报价） |
| `SCOPE_STALE` | 409 | 镜头集合/规格/模式已变 | 重新报价并确认 |
| `SCOPE_ALREADY_USED` | 409 | 范围已提交过且非幂等命中 | 显示原 batch 或重新创建 |
| `SHOT_NOT_READY` | 409 | 缺分镜图/未审核 | 跳回该镜分镜步骤 |
| `FILM_MISSING_SHOTS` | 409 | 成片缺镜 | 展示缺失镜头；二选一：重试失败镜 / 显式部分合成 |
| `ASSEMBLY_FAILED` | 502 | 拼接失败 | 指出涉事镜头，可只重合成 |
| `STRUCTURE_TEMPLATE_VERSION_NOT_FOUND` | 404 | 版本不存在 | 回退到最新版本 |
| `PROJECT_NOT_FOUND` / `SHOT_NOT_FOUND` / `FILM_NOT_FOUND` | 404 | 资源不存在 | 刷新列表 |

沿用既有：`MODEL_CAPABILITY_MISMATCH`、`MODEL_EOS`、`MODEL_NOT_OPENED`、`BUDGET_*`、`TASK_*`、
`APPROVAL_*`（助手侧不变）。

## 10. 一致性与历史数据

| 规则 | 说明 |
| --- | --- |
| 时长四处一致 | 前端选项 / 后端校验 / 报价 / 供应商请求使用同一值 |
| 报价与提交一致 | scope 的 `specs + shot_ids + mode` 决定哈希；变更即失效 |
| 计划 vs 实际 | `planned_film_duration_s` 与 `actual_duration_ms` 分字段 |
| 历史不改写 | 旧任务/旧报价保留原参数与费用口径；新逻辑不回溯解释 |
| 幂等 | 同一 scope 重复提交返回原 batch；`client_request_id` 机制沿用 |
| 单 worker | 响应显式标注 `sequential: true`；**不得**展示为并行 |
