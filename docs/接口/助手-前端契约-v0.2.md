# 助手前端契约 v0.3（增量：推荐模板 / 提示词纯度 / 类型降级标记）

> **v0.3 为纯增量**：新增可选字段，**原有字段语义不变**，旧前端不受影响。
> 本轮同时**清理了 v0.2 附录 A 的矛盾说明**（原「可在前端截取首段」与「不得截断」冲突，已删除截取建议）。

## v0.2 → v0.3 变更（新增字段，全部可选）

| 字段 | 位置 | 说明 |
| --- | --- | --- |
| `recommended_templates[]` | `chat` 响应 / 会话恢复 `structured` | 结构化的模板推荐，**来自真实工具结果并校验存在**；无可信推荐时为 `[]` |
| `explanation` | `chat` 响应 / 会话恢复 | 模型的说明文字（与提示词分离）；可能为 `null` |
| `optimized_prompt` | 同上（**语义收紧**） | **只有通过纯度校验的提示词**才放这里；无法解析/被截断/混入说明 → `null`。**旧行为（回退为整段 reply）已废弃** |
| `structured_ok` | `chat` 响应 | `true`＝类型来自模型结构化输出；`false`＝后端降级推断 |
| `degraded` | `chat` 响应 | `true`＝本轮发生降级（结构化缺失/解析失败/类型被纠正），前端可弱提示 |
| `refusal` | `chat` 响应 | `{"detected": bool, "structured": bool}`：正文拒答 与 模型自报拒答 **分开** |

**兼容性**：以上均为新增或收紧语义；前端若忽略新字段，仍可正常展示（`optimized_prompt` 为 `null` 时只显示 `reply`）。

# 助手前端契约 v0.2（阶段一手册，保留）

日期：2026-10-24｜状态：后端已实现，隔离测试 **36/36** 通过（零付费、零真实 LLM）
上一版：v0.1 → 本版修复四项：**连续对话 / 仅优化权限 / 批准重放校验 / 报价冻结模板版本**

> **前提**
> - 未配置 LLM 时 `GET /api/assistant/status` → `available=false`，`chat` 返回 503
>   `ASSISTANT_UNAVAILABLE`。前端显示「助手暂不可用，可直接使用工作台生成」，**不得**用假回复模拟接通。
> - `ASSISTANT_PROVIDER=fixed` 是**测试替身**，正式页面不得配置。
> - 助手不改变任何现有页面行为；不打开助手也能完成全部操作。
> - 助手**没有** confirm/submit 工具：提交由前端在用户点击确认后调用 `POST /api/tasks`。

## 0. v0.1 → v0.2 变更

| # | 变更 | 前端影响 |
| --- | --- | --- |
| 1 | 新增 `assistant_messages`，多轮上下文由服务端保存并限长 | 刷新后可恢复对话；无需前端拼历史 |
| 2 | 新增 `GET /api/assistant/session?project_id=` | 刷新恢复用，返回会话+历史+brief |
| 3 | 新增 `PUT /api/assistant/intent` | 仅优化 ↔ 生成 需**显式切换** |
| 4 | `chat` 响应新增结构化字段 | 前端不再解析自然语言猜参数 |
| 5 | `quote` 不再接受可信 `intent`（忽略） | 权限只看服务端会话意图 |
| 6 | `quote` 返回 `submit_payload` / `resolved_params` / `manual_params` | 前端直接提交，不重建提示词 |
| 7 | `quote` 冻结 `template_version` | 模板升版不改变已报价内容 |
| 8 | 同批准改方案 → `APPROVAL_PLAN_MISMATCH` | 改参数后必须重新报价+确认 |
| 9 | 新增错误码 `CONFIRM_NOT_ALLOWED` / `APPROVAL_INVALID` | 见 §6 |

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/assistant/status` | 可用性 |
| POST | `/api/assistant/chat` | 对话（非流式，含结构化字段） |
| **GET** | **`/api/assistant/session?project_id=`** | **刷新恢复：会话 + 历史 + brief** |
| GET | `/api/assistant/session/{session_id}` | 会话状态与限额 |
| **PUT** | **`/api/assistant/intent`** | **显式切换意图** |
| GET / PUT | `/api/assistant/brief?project_id=` | brief 读取/保存 |
| POST | `/api/assistant/quote` | 报价（冻结方案，不建任务） |
| POST | `/api/assistant/confirm` | **用户点击确认** → 一次性批准 |
| GET | `/api/assistant/quote/{quote_id}` | 查报价单（含冻结方案与是否过期） |
| GET | `/api/assistant/usage?session_id=` | 助手用量（与生成用量分开） |
| POST | `/api/tasks` | 增量：带 `approval_id` 提交（手动路径不传） |

### GET /api/assistant/status（v0.2.1 补充 `state`）

```json
{"available": true, "state": "configured_unverified",
 "provider": "ark", "model": "doubao-seed-2-1-lite-260915",
 "vision": false, "streaming": false, "verified": false,
 "note": "已配置语言模型，但尚未完成真实调用验证"}
```

| `state` | 含义 | 前端行为 |
| --- | --- | --- |
| `not_configured` | 未选择 LLM | 入口可见，点击显示"暂不可用，可直接手动生成" |
| `misconfigured` | 选了 `ark` 但缺 `ASSISTANT_MODEL`/Key | 提示"配置不完整"（运维问题） |
| `configured_unverified` | 已配置型号，**尚未真实调用验证** | 可试用，但结果区需标注"未经真实验证" |
| `stub` | 测试替身（仅自动化测试） | **不得**出现在正式页面 |
| `connected_verified` | V1–V4 真实调用全部通过后才允许 | 目前**未达到**，不要硬编码期待此值 |

`verified` 在完成真实调用验证前**恒为 false**；前端不得自行推断。

## 2. 对话

### POST /api/assistant/chat

```json
{
  "session_id": null,
  "project_id": "draft_ab12",
  "message": "帮我润色这句：白瓶 大理石 2K 方图",
  "intent": "optimize_only",
  "brief": {"subject": "单瓶精华液"},
  "context": {"selected_asset_id": "asset_d73231ab405540b68eb6", "kind": "image"}
}
```

- `intent` 传值 = **用户显式选择模式**（会更新会话意图并留痕）。省略则沿用会话既有意图。
- `brief` 传入即合并保存（只存用户确认过的信息）。

响应（结构化，前端直接渲染）：

```json
{
  "session_id": "asst_9f1c…",
  "reply": "优化后：以参考图中的商品为准，保留外形与标签……",
  "reply_type": "optimize_result",
  "options": [],
  "optimized_prompt": "以参考图中的商品为准，保留外形与标签，将背景替换为浅灰白大理石台面……",
  "missing_fields": [],
  "brief": {"subject": "单瓶精华液"},
  "quote": null,
  "manual_params": null,
  "submit_payload": null,
  "tool_calls": [],
  "awaiting_facts": null,
  "intent": "optimize_only",
  "session": {
    "session_id": "asst_9f1c…", "project_id": "draft_ab12",
    "intent": "optimize_only", "status": "active",
    "limits": {"turns_used": 1, "turns_max": 12,
               "questions_used": 0, "questions_max": 4,
               "tool_calls_used": 0, "tool_calls_per_turn_max": 3, "tool_rounds_max": 3},
    "usage": {"input_tokens": 0, "output_tokens": 0}
  },
  "provider": {"name": "fixed", "model": "fixed-test", "stub": true},
  "note": "当前为测试替身回复，不代表真实模型能力"
}
```

### `reply_type` 取值与前端行为

| reply_type | 含义 | 前端 |
| --- | --- | --- |
| `optimize_result` | 仅优化，已给成品 | 展示 `optimized_prompt` + 一键复制/套用到创作页；**不显示**确认生成按钮 |
| `clarify` | 需要用户回答 | 渲染 `options` 为按钮；`missing_fields` 高亮缺失项 |
| `template_recommendation` | 推荐模板 | 渲染模板卡（template_id/version 见 quote 或结构化字段） |
| `quote_ready` | 已报价 | 展示 `quote` + 费用，显示「确认生成」按钮 |
| `awaiting_facts` | 提问达上限、事实仍缺 | 展示 `awaiting_facts.missing_fields` 清单，**不给提交按钮** |
| `refusal` | 拒答（违规/越界） | 展示文案 + 合规替代方向 |
| `message` | 普通回复 | 纯文本 |

- `optimized_prompt` 仅 `optimize_result` 时保证有值（无结构化输出时回退为 `reply`）。
- `options` 元素：`{"id": "a", "label": "单瓶精华液"}`，点选后作为下一条 `message` 发送即可。
- `note` / `provider.stub=true` → 必须显著标注"测试替身"，不得当作已接通。

### 连续对话

- 服务端保存 `user` / `assistant` 消息（含 `reply_type` 与结构化字段），多轮上下文按
  `ASSISTANT_HISTORY_MAX_MESSAGES`（默认 8 条）/ `ASSISTANT_HISTORY_MAX_CHARS`（默认 4000）裁剪。
- 工具结果会**回传给模型**，最多 `ASSISTANT_MAX_TOOL_ROUNDS`（默认 3）轮"调用→观察→继续/停止"。
- 前端**不需要**自己拼历史；只需持有 `session_id`。

             "limits": {"turns_used": 3, "turns_max": 12, "questions_used": 2, "questions_max": 4,
                        "tool_calls_used": 4, "tool_calls_per_turn_max": 3, "tool_rounds_max": 3},

 "history": [
   {"role": "user", "content": "帮我做个视频", "reply_type": null, "structured": null},

## 3. 意图切换（仅优化 ↔ 生成）

```
PUT /api/assistant/intent
{"session_id": "asst_9f1c…", "intent": "generate", "reason": "用户要求生成"}
```

- 权限判断**只读服务端会话意图**：`quote` / `confirm` 请求里传或省略 `intent` 都不影响权限。
- `intent=optimize_only` 的会话：**不能报价、不能确认、不能取消任务**（分别返回
  `QUOTE_NOT_ALLOWED` / `CONFIRM_NOT_ALLOWED` / `TOOL_FORBIDDEN`）。
- 用户明确点"要生成" → 前端先调本接口，再报价。
- 切换会写一条 `assistant_usage(kind="intent_change")` 留痕。

## 4. 报价 → 确认 → 提交

### ① 报价（冻结方案）

```json
POST /api/assistant/quote
{"session_id": "asst_9f1c…", "project_id": "draft_ab12",
 "payload": {"kind": "video", "model_id": "doubao-seedance-1-0-pro-fast-251015",
             "input_asset_id": "asset_cd91e2f9dda14123a622",
             "template_id": "tpl_product_motion_5s",
             "template_fields": {"motion": "推近特写", "duration": 5, "ratio": "9:16"}}}
```

> `payload` 可省略 `template_version`；服务端按**当前最新版本**解析并**立即冻结**。
> 之后模板升版，本次报价与提交仍用冻结版本。

响应：

```json
{
  "quote_id": "q_5b0e…", "plan_hash": "sha256:70658e…",
  "expires_at": 1792690000.0, "cost_cny": 0.4536, "estimated_cost_cny": 0.4536,
  "kind": "video", "model_id": "doubao-seedance-1-0-pro-fast-251015",
  "template_id": "tpl_product_motion_5s",
  "template_version": 2,
  "template_name": "5 秒商品动态展示",
  "concept_mode": false,
  "effective": {"duration": 5, "ratio": "9:16", "resolution": "720p", "generate_audio": false},
  "warnings": [],
  "model_lifecycle": {"status": "eos_scheduled", "eos_at": "2026-11-24T14:00:00+08:00",
                      "migrate_to": "doubao-seedance-2-0-mini-260615",
                      "migrate_to_activation": "not_opened"},
  "submit_payload": {"kind": "video", "model_id": "…", "input_asset_id": "asset_…",
                     "template_id": "tpl_product_motion_5s", "template_version": 2,
                     "template_fields": {"motion": "推近特写", "duration": 5, "ratio": "9:16"},
                     "params": {}},
  "resolved_params": {"prompt": "以首帧图中的商品为准，…", "generation_mode": "image_to_video",
                      "duration": 5, "ratio": "9:16", "resolution": "720p", "generate_audio": false},
  "manual_params": {"…": "= submit_payload + effective + template_name + concept_mode"},
  "side_effects": {"task_created": false, "queued": false, "model_called": false, "budget_deducted": false},
  "next_step": "用户确认后调用 PUT /api/assistant/confirm，再用 approval_id 提交"
}
```

**前端规则**
- 展示用：`template_name` + `effective` + `cost_cny`（标注"估算，非账单"）+ `model_lifecycle` 提示。
- 提交用：**原样使用 `submit_payload`**（不要改 `params`、不要自己拼 prompt、不要用最新模板覆盖）。
- 报价默认 **600 秒**有效；过期需重新报价。

### ② 用户确认

```
POST /api/assistant/confirm
{"session_id": "asst_9f1c…", "quote_id": "q_5b0e…",
 "project_id": "draft_ab12", "user_action": "confirm_generate"}
```

```json
{"approval_id": "ap_3c08…", "quote_id": "q_5b0e…", "plan_hash": "sha256:70658e…",
 "expires_at": 1792690000.0, "max_uses": 1,
 "session_id": "asst_9f1c…", "project_id": "draft_ab12",
 "template_id": "tpl_product_motion_5s", "template_version": 2,
 "effective": {"duration": 5, "ratio": "9:16", "resolution": "720p", "generate_audio": false},
 "cost_cny": 0.4536,
 "submit_payload": {"…": "与报价一致，可直接提交"},
 "next_step": "POST /api/tasks 携带 approval_id 与 submit_payload"}
```

- 只能由用户点击触发；`user_action` 固定 `confirm_generate`；一次性、默认 600 秒有效。

### ③ 提交

```json
POST /api/tasks
{"kind": "video", "model_id": "doubao-seedance-1-0-pro-fast-251015",
 "input_asset_id": "asset_cd91e2f9dda14123a622",
 "template_id": "tpl_product_motion_5s", "template_version": 2,
 "template_fields": {"motion": "推近特写", "duration": 5, "ratio": "9:16"},
 "approval_id": "ap_3c08…"}
```

```json
{"task_id": "task_9a2f…", "status": "queued", "queue_position": 1,
 "estimated_cost_cny": 0.4536, "origin": "assistant", "caller_id": "assistant",
 "approval_id": "ap_3c08…", "idempotent_replay": false}
```

| 情况 | 结果 |
| --- | --- |
| 相同批准 + **相同方案** | 返回原任务，`idempotent_replay=true`，不重复生成 |
| 相同批准 + **方案改变**（改 params/提示词/模板版本/素材） | 409 `APPROVAL_PLAN_MISMATCH` → 重新报价 + 重新确认 |
| 省略 `template_version` | 用**报价冻结的版本**补全，不算改变方案 |
| 显式传不同 `template_version` | 409 `APPROVAL_PLAN_MISMATCH` |
| 批准过期 | 409 `APPROVAL_EXPIRED` |
| 模型已到 EOS | 409 `MODEL_EOS`（即使方案已冻结也不执行） |

- `origin` / `caller_id` 由后端确定，前端传 `caller_id` 无效。

## 5. 「转为手动操作」参数映射

用户放弃助手流程、改为自己在创作页操作时，按下表填充（**不要重新询问、不要重建提示词**）：

| 创作页字段 | 取值 |
| --- | --- |
| 生成类型 | `manual_params.kind` |
| 模板 + 版本 | `manual_params.template_id` + `manual_params.template_version` |
| 模板字段（含 `*_custom`） | `manual_params.template_fields` |
| 参考图 / 首帧图 | `manual_params.input_asset_id` |
| 模型 | `manual_params.model_id` |
| 比例 / 尺寸 / 时长 | `manual_params.effective` |
| **提示词** | `resolved_params.prompt`（后端已组装好，直接展示为只读或可编辑） |
| 概念图标注 | `manual_params.concept_mode === true` → 显示「创意概念图，不代表真实商品外观」 |
| brief | `GET /api/assistant/session?project_id=` 的 `brief` |

转入手动操作后**不再受助手批准约束**（属于手动路径，用户自己点生成）。

## 6. 错误码

| code | HTTP | 前端处理 |
| --- | --- | --- |
| `ASSISTANT_UNAVAILABLE` | 503 | 显示"助手暂不可用"；不重试、不伪造回复 |
| `ASSISTANT_SESSION_NOT_FOUND` | 404 | 清空本地 session_id，开新会话 |
| `ASSISTANT_TURN_LIMIT` | 429 | 提示新建会话 |
| `ASSISTANT_BUDGET_EXCEEDED` | 429 | 提示会话消耗达上限 |
| `QUOTE_NOT_ALLOWED` | 400 | 仅优化会话不可报价 → 先 `PUT /intent` 切到 `generate` |
| `CONFIRM_NOT_ALLOWED` | 400 | 仅优化会话不可确认 → 同上 |
| `QUOTE_NOT_FOUND` / `QUOTE_EXPIRED` | 404 / 409 | 重新报价 |
| `QUOTE_SESSION_MISMATCH` | 400 | 清空会话后重新报价 |
| `APPROVAL_NOT_FOUND` | 404 | 回到报价步骤 |
| `APPROVAL_INVALID` | 409 | 缺少冻结方案（旧数据）→ 重新报价 |
| `APPROVAL_EXPIRED` | 409 | 重新报价 + 重新确认 |
| `APPROVAL_PLAN_MISMATCH` | 409 | **参数已变**：重新报价 + 重新确认 |
| `APPROVAL_ALREADY_USED` | 409 | 重新报价 |
| `TOOL_FORBIDDEN` | 400 | 助手越权（不应出现）：记录日志；多因仅优化会话调副作用工具 |
| `MODEL_EOS` / `MODEL_CAPABILITY_MISMATCH` / `TEMPLATE_*` | 见契约 v5.1 | 沿用既有处理 |

## 7. 会话与限额

| 限制 | 默认 | 仅助手？ |
| --- | --- | --- |
| 提问上限 | 4（达到且仍追问 → `awaiting_facts`，不生成） | 是 |
| 轮次上限 | 12 → 429 | 是 |
| 单轮工具调用 | 3 | 是 |
| 工具观察轮次 | 3 | 是 |
| 会话消耗上限 | 不限（`ASSISTANT_MAX_SESSION_COST_CNY=0`） | 是 |
| 预算闸门 `BUDGET_CNY` | 现有值 | **否**（手动+助手都受） |

新会话只重置会话级计数，不清零工作区消耗与预算。

## 8. 用量展示

同 v0.1 §8：`assistant` 与 `generation` 分开展示，均标注"估算，非账单"；
**不得**显示虚构可消费余额（账本/支付未实现）。

## 9. 前端接入建议顺序

1. `status` → 入口可用态。
2. `session?project_id=` → 刷新恢复（会话+历史+brief）。
3. `chat`（先接"仅优化"，无费用）→ 按 `reply_type` 渲染。
4. `PUT /intent` → 用户改主意要生成时切换。
5. `quote` → 展示费用/生效参数/生命周期提示。
6. `confirm` → `POST /api/tasks` + `approval_id` + `submit_payload`。
7. 错误码映射（尤其 `APPROVAL_PLAN_MISMATCH` 必须引导重新报价）。
8. 「转为手动操作」按 §5 映射填充。

### 其他既知约束（非接口缺口，照现状处理）

| 编号 | 约束 | 前端处理 |
| --- | --- | --- |
| G2 | `GET /api/tasks` 不支持按会话过滤 | 客户端过滤：`/api/tasks?limit=200` 后按 `external_request_id === session_id` 筛 |
| G3 | `usage.generation` 是全局统计 | 会话级费用用 G2 筛出的任务自行累加；不要用全局值冒充"本会话花费" |

### 明确不允许的"绕过"

- 不得在前端拼提示词、自算价格、自行判断模型可用性或额度；
- 不得为补齐 G1 而把自然语言里的模板名映射成 `template_id`（会误伤，且违反"不解析自然语言"约定）；
- 不得为补齐 G5 而截断用户可见文本（只能提示，不能静默丢弃）；
- **不得**用"截取首段/首个空行前"等方式自行构造 `optimized_prompt`——纯度由后端判定，前端只消费结果。
