# S2 后端接口说明（项目 / brief / 脚本，2026-10-26）

对应 PRD **v0.10 定稿** §2.1–§2.3、§10-S2｜技术方案 **v6** §1.3｜接口契约 **v0.10 增量** §2–§3
状态：**已实现，免费验收 13/13**；S3 起（镜头/分镜/scope/成片/模板）**尚未实现**。

## 1. 接口清单（S2）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/projects` | 新建项目（含 brief） |
| GET | `/api/projects?limit=` | 项目列表（含 `script_count`） |
| GET | `/api/projects/{id}` | 项目详情（brief + latest_script + script_count）→ **刷新恢复入口** |
| PATCH | `/api/projects/{id}` | 改名 / 改 brief；返回 `stale` 标记 |
| POST | `/api/projects/{id}/scripts` | **AI 生成脚本**（用户主动触发） |
| POST | `/api/projects/{id}/scripts/manual` | **手工新增脚本版本**（助手不可用时兜底） |
| GET | `/api/projects/{id}/scripts` | 脚本版本列表（新→旧） |
| GET | `/api/scripts/{id}` | 取某版本全文 |
| PATCH | `/api/scripts/{id}` | 编辑 → **新建版本**（不覆盖） |
| POST | `/api/scripts/{id}/confirm` | 确认脚本（绑定版本） |

## 2. 关键语义

### brief 字段（白名单）

`subject`、`quantity`、`selling_points`、`forbidden_elements`、`target_platform`、
`target_duration_s`、`style`、`notes`。未知字段 → 400 `VALIDATION_FAILED`；
`quantity` 必须正整数（`1.5` 拒绝）。

### AI 生成脚本

```json
POST /api/projects/prj_…/scripts
{"instruction": "偏简洁", "target_duration_s": 20}
```

- **必须先有 `brief.subject`**，否则 400；
- 助手可用 → 返回 `{script_id, version, content, source:"assistant", llm_usage:{...}, assistant_unavailable:false}`，
  并**记录 LLM 用量**（`assistant_usage`，与生成用量分开）；
- 助手不可用 → **HTTP 200** + `{assistant_unavailable:true, hint:"…可先手工编写脚本…"}`，**不报 5xx**；
- 模型输出非结构化 → `content.parse_ok=false`、`summary` 存原文、`shots=[]`、
  `degraded_reason="model_output_not_structured"`，**不编造镜头**。

### 版本与确认

- 任何编辑（PATCH）或重新生成 → **新增版本**（`version` 递增），旧版本内容不变；
- `PATCH` 可带 `base_version`：**指"客户端所见的项目最新版本"**，
  与当前最新不一致 → **409 `SCRIPT_VERSION_CONFLICT`**（乐观并发）；
- `POST /confirm` 绑定 `script_id + version`；**新版本不继承确认**；
- 改 `brief` → 响应 `stale: ["script_confirm", ...]`（若有已确认版本还会包含 `shot_plan_confirm"`），
  **只标记、不删历史确认、不自动改状态**。

## 3. 前端接入要点

| # | 要做 |
| --- | --- |
| 1 | 项目 = 创作空间的最小上下文；进入创作空间先 `GET /api/projects/{id}` 恢复 brief 与最新脚本 |
| 2 | "生成脚本"按钮**必须用户点击**；请求期间显示 loading；失败/不可用时展示 `hint` 并允许手工输入 |
| 3 | 脚本编辑器保存走 `PATCH`（带 `base_version`），遇 409 提示"已有更新版本"并展示差异，**不静默覆盖** |
| 4 | 确认按钮明确写"确认脚本（v3）"，避免误确认旧版本 |
| 5 | 收到 `stale` 时提示"brief 已变更，脚本/分镜确认需重新进行"，**不要自动清除历史版本** |
| 6 | 助手脚本生成本身消耗 LLM 用量（不是图片/视频费用），前端应如实提示 |
