# 接口契约 v5.1（v0.7.2：生命周期元数据修正）

> 2026-10-24｜后端 `http://127.0.0.1:8100`（前端同源提供）
> v5.1 修正两项元数据：`/api/models.lifecycle` 改为**实时计算**（不再写死 `eos_scheduled`）；
> 删除恒为真的 `migration_available`，改由 `migrate_to_activation` 转述目标模型的真实调用结果。
> v5 内容（预估接口/参数优先级/到期保护）继续有效。
> v4 未单独归档；v3 归档于 `docs/接口/history/接口契约-v3-图生图（历史）.md`。
> **鉴权未实现**：所有接口当前无身份校验，仅本机绑定；`X-API-Key` 与 `caller_id` 为**预留**，不代表已可对外接入。

## 0. v0.7.1 变更速览

| 项 | 变化 |
| --- | --- |
| `POST /api/tasks/estimate` | **新增**：无副作用费用预估（不建任务/不入队/不调模型/不扣预算） |
| 参数优先级 | 明确为：**显式 `params` > 模板字段映射（`field_params`）> 模板默认值** |

## 1. 模型能力发现

### GET /api/models

```json
{"items":[{
  "id":"doubao-seedream-5-0-pro-260628",
  "name":"Seedream 5.0 pro（云端）",
  "kind":"image","provider":"ark","activation":"not_opened",
  "downloaded":true,"loaded":false,
  "capabilities":{
    "input_modes":["text_to_image","image_to_image"],
    "ratios":["1:1","3:4","4:3","9:16","16:9"],
    "sizes":["1024x1024","2048x2048","1728x2304","2304x1728","1536x2688","2688x1536"],
    "resolutions":[],"duration_s":[],"duration_range_s":null,
    "max_reference_images":10,"supports":["单图生成","文生图","单张图生图","多参考图生图"],"fps":null,"limits":null
  },
  "pricing":{"kind":"per_pixel_tier","tiers":[{"max_mp":2.61,"cny":0.30},{"max_mp":null,"cny":0.60}],
             "input_image":{"first_free":true,"from_second_cny":0.02}},
  "lifecycle":{"status":"active"}
}]}
```

`lifecycle.status` 取值：`active` | `eos_scheduled`（带 `eos_at`/`eom_at`/`migrate_to`/`migrate_to_activation`/`action`/`announce_url`/`seconds_remaining`/`eom_passed`）| `eos_expired`。

**v0.7.2 元数据修正（重要）**

- `lifecycle` 由 `config.model_lifecycle_state()` **按服务器时间实时计算**；`/api/models` 与提交/预估校验**共用同一函数**，不会出现“列表未到期、提交却拒绝”。
- 已**删除** `migration_available`（原表达式含 `or True`，恒为真且易被误读为“迁移目标已可用”）。
- 新增 `migrate_to_activation`：仅**转述** `MODEL_ACTIVATION` 中目标模型的真实调用结果（`verified`/`not_opened`/`unknown`），**不表示迁移目标已开通或可用**。目标是否可用请只看目标模型自身的 `activation`。
- 新增 `eom_passed`：仅表示是否已过“停止新购”时间，与能否调用无关。

**服务端时间比较规则**：`now >= eos_at` 即视为到期（到期时刻当秒即拒）。
`activation` 取值：`verified`（真实调用成功）| `not_opened`（真实调用返回 `ModelNotOpen`）| `unknown`。

> **不可用不等于不能用**：`not_opened` 模型仍出现在列表中，便于前端置灰并提示开通；提交会返回 `MODEL_NOT_OPENED`，**实测不计费**。

### GET /api/templates/{template_id}?version=

额外返回：

```json
{"requested_version":1,
 "versions":[{"version":1,"status":"active","created_at":1792663342.5}],
 "template_snapshot":{ "...该版本完整不可变快照..." }}
```

- 不传 `version` → 返回最新激活版本，并回显 `requested_version`。

## 3. 任务（增量）

### POST /api/tasks（带模板）

```json
{
  "kind": "image",
  "model_id": "doubao-seedream-5-0-flash-260915",
  "input_asset_id": "asset_d73231ab405540b68eb6",
  "template_id": "tpl_scene_bg",
  "template_version": 1,
  "template_fields": {
    "product_name": "焕亮精华液",
    "scene": "大理石台面",
    "keep_features": "瓶盖金色、标签文字不可改",
    "forbidden_elements": "不要出现人物"
  },
  "client_request_id": "req-0001",
  "external_request_id": "OPS-2026-0001",
  "caller_id": "ops-workbench-test"
}
```

响应：

```json
{"task_id":"task_…","status":"queued","queue_position":1,
 "estimated_cost_cny":0.12,
 "template_id":"tpl_scene_bg","template_version":1,
 "external_request_id":"OPS-2026-0001","concept_mode":false}
```

规则：

1. **不传 `params` 时的优先级**：模板字段映射（`field_params`）> 模板默认值；传了 `params` 则显式值最高。
   例：模板字段 `duration=10` + `params.duration=5` → 最终 **5**。
2. 字段值原文随任务落库（`params.fields`），并用于组装提示词（`params.prompt`）。
   关联自定义字段（`scene_custom`/`motion_custom`/`theme_custom`）**会被保留**；选「自定义」但为空 → 400 `TEMPLATE_FIELD_REQUIRED`（`detail.field` 指向自定义字段）；未选「自定义」时无关值不写入。
3. `concept_mode=true` 仅出现在「季节主题 + 无参考图」路径：此时 **`generation_mode` 派生为 `text_to_image`**，提示词含“创意概念图”声明。
4. 模板与模型不兼容 → 400 `MODEL_TEMPLATE_INCOMPATIBLE`。
5. 最终生效参数不满足模型能力 → 400 `MODEL_CAPABILITY_MISMATCH`。
6. 模型已到 EOS → 409 `MODEL_EOS`（**入队前**拒绝，不自动替换模型）。
7. `client_request_id` 幂等：重复提交返回**原任务**，不新建。
8. 响应中的 `estimated_cost_cny` 是**提交后**的任务级估算；提交前确认请用 `POST /api/tasks/estimate`。

### 最终生效参数（`effective`）与一致性

| kind | 字段 |
| --- | --- |
| image | `generation_mode`、`size` |
| video | `duration`、`ratio`、`resolution`、`generate_audio` |

预估响应、任务 `params`、供应商请求三者由同一解析函数产出，必须一致。

### 批量原子性（本版修正）

`POST /api/batches` 改为**先全批解析（纯函数）再入库**：任一项非法（含 `MODEL_EOS`）→ **整批拒绝**，不产生部分任务，也不留下空的批次行。

### GET /api/tasks/{id}

新增字段：`template_id`、`template_version`、`external_request_id`、`caller_id`、`concept_mode`；
`params.fields` 保存模板字段原文；`params.prompt` 为最终提示词。

### POST /api/tasks/{id}/retry

重试**保留** `template_id`/`template_version`/`template_fields`；仍从头重新生成（再次计费）。

## 4. 计价口径（客户端必须按此估算）

### 图片

| 模型 | 口径 |
| --- | --- |
| flash | 0.12 元/张（不分像素档）；参考图输入免费 |
| pro | 单图生成按输出像素档：**≤261 万像素 0.30**、**>261 万像素 0.60**；参考图首张免费、第 2 张起 0.02 元/张 |

换算：2048×2048 = 419 万像素 → **0.60**；1024×1024 = 105 万 → 0.30。本项目默认 2K，预算按 0.60。

### 视频

```
tokens ≈ (输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 帧率 ÷ 1024
费用  = tokens ÷ 1,000,000 × 单价(元/百万 token)
```

| 模型 | 单价 |
| --- | --- |
| 1.0 pro fast | 4.20 |
| 2.0 mini | 23.00（输入含视频 14.00） |

**实测校准**：704×1248 / 5.041667s / 24fps → `completion_tokens = 103,818`，费用估算 ¥0.436（与公式一致）。
服务端 `estimated_cost_cny` 按 720×1280 档宽高估算（¥0.4536，略保守），成功后按真实 usage 重算。

> **不得承诺固定输出尺寸**：请求 `9:16 + 720p` 实测输出 704×1248，不是 720×1280。

**费用口径（严格）**：`cost_cny` 是**应用侧估算**（单价 × 用量），**不是**已核对的供应商账单；
失败任务的 `cost_cny = null` 仅表示**未产生应用侧估算记录**，**不能**据此声称“供应商账单为零”。

## 5. 错误码（本版新增）

| code | HTTP | 可重试 | 说明 |
| --- | --- | --- | --- |
| `TEMPLATE_NOT_FOUND` | 404 | 否 | 模板不存在 |
| `TEMPLATE_VERSION_NOT_FOUND` | 404 | 否 | 指定版本不存在 |
| `TEMPLATE_FIELD_REQUIRED` | 400 | 否 | 必填字段缺失（含概念图路径缺商品名） |
| `TEMPLATE_FIELD_INVALID` | 400 | 否 | 字段值非法（下拉越界/自定义未填） |
| `TEMPLATE_DEPRECATED` | 409 | 否 | 模板版本已停用 |
| `MODEL_TEMPLATE_INCOMPATIBLE` | 400 | 否 | 模型与模板不兼容 |
| `MODEL_CAPABILITY_MISMATCH` | 400 | 否 | 最终生效参数超出模型能力（`detail.problems[]`） |
| `MODEL_EOS` | 409 | 否 | 模型已到 EOS，不可新建任务（不自动替换） |

已有错误码（`MODEL_NOT_OPENED`、`CREATE_RESULT_UNKNOWN`、`BUDGET_*` 等）行为不变。

## 6. 跨项目调用方须知（重要）

1. **当前无鉴权**：不要把它当作可对外安全的接口。正式对外接入前必须补齐鉴权与数据隔离。
2. **`caller_id` 已落库但不校验**：仅用于日后归因，不能作为权限依据。
3. **素材引用**：只传 `asset_id`，**不要传本机绝对路径**。
4. **长任务不阻塞**：视频为异步，先 `POST /api/tasks` 取 `task_id`，再 `GET /api/tasks/{id}` 轮询。首版不做 Webhook。
5. **幂等键**：`client_request_id`（重试安全）；`external_request_id`（调用方业务号，仅关联不查重）。
6. **能力发现优先**：先读 `/api/models` + `/api/templates`，不要硬编码比例/时长/价格。
