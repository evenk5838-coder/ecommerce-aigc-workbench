## 4. 前端需遵循的规则

**参数优先级**

```
调用方显式 params  >  模板字段映射 field_params  >  模板默认值 default_params
```

例外：`tpl_season_theme` 的 `generation_mode` 由参考图存在性派生（有图→`image_to_image`；无图→`text_to_image`），不一致的显式值会被覆盖并在 `warnings` 返回 `GENERATION_MODE_DERIVED`。

**最终参数字段（`effective`）**

| kind | 字段 |
| --- | --- |
| image | `generation_mode`、`size` |
| video | `duration`、`ratio`、`resolution`、`generate_audio` |

**模型生命周期状态**

| `lifecycle.status` | 前端行为 |
| --- | --- |
| `active` | 正常可选 |
| `eos_scheduled` | 可选，显示 `eos_at` 与 `migrate_to`；**不要**自动切换模型 |
| `eos_expired` | 禁用；提交会 409 `MODEL_EOS` |

生成流程必须为：`estimate`（报价）→ 用户确认 → `tasks`（入队）。
