## 1. 打开工作台

当前服务已运行时，直接打开正式入口。日常启动可在项目根目录双击 **start.command**，或执行：

```bash
cd /Users/niannian/Documents/VScode/电商工作平台
./start.command
```

脚本会构建前端，并在没有现有 8100 服务时启动后端。已运行的服务不会被脚本自动终止。仅更新前端并完成构建后，刷新页面即可；更改后端或 .env 后需要在确认活动任务状态后重启后端。

当前 Python 环境仍可能位于临时目录；临时环境被清理后，需要重建后端环境或通过 APP_PYTHON 指向有效的 Python 环境。启动失败时保留终端报错，不要重复启动多个服务。

| 入口 | 用途 |
| --- | --- |
| http://127.0.0.1:8100/ | 当前正式统一工作台，日常使用此入口 |
| http://127.0.0.1:5173/ | 前端开发预览，仅在开发服务运行时可用 |
| http://127.0.0.1:8100/legacy | 历史最小验收页，按钮与参数布局不同 |

Key 保存在项目根目录的 .env 中，由后端读取；不要把 Key 粘贴到提示词、聊天或文档。APP_BUDGET_CNY 沿用当前批准值，调整预算需单独决定。

## 2. 页面怎么用

主导航只有「工作台」「素材库」「任务中心」。工作台内直接完成描述、设置参数、生成与查看结果，无需再次进入另一个创作页面。

- **工作台左侧**：选择「生图」或「生视频」，设置输入和参数，提交任务。
- **工作台右侧**：显示当前类型的生成成果；任务完成后自动更新。
- **素材库**：查看上传原图与生成结果，搜索、选择素材并打包导出。
- **任务中心**：查看进行中、已完成和失败任务，执行允许的取消或从头重试。
- **排版编辑**：独立的固定尺寸排版工具。可从顶部「排版编辑」、侧栏「继续排版」或图片成果的「排版」进入。

「白底商品图」「氛围场景图」「自定义」是生图下面的图片用途。它们切换提示词预设，不是三种独立生成能力。SKU 是商品管理分组，和白底、氛围等呈现方式无关。

## 3. 文生图

1. 在工作台选择 **生图 → 文生图**。
2. 选择 **白底商品图、氛围场景图或自定义**。选中预设后，补充具体商品、外观、背景、光线和构图要求。若已有自写描述，切换到另一个预设用途时会先提示是否替换。
3. 选择画面比例与生成数量。图片模型为 **Seedream 5.0 Flash**，输出规格为 **2K 图片**。
4. 点击 **生成 N 张图片**，在费用确认框中确认后提交。单纯输入、切换用途、上传或选择素材不会发起模型生成。
5. 在右侧等待成果出现，或打开任务中心查看状态。点击成果可预览大图与下载原文件。

示例描述：

> 生成一个白色保湿面霜罐的商品展示图，罐身矮圆、白色盖子，纯白背景，柔和棚拍光线，自然接触阴影，商品完整清晰，主体靠左，右侧留白。

正式页面的图片规格：

| 画面比例 | 请求尺寸 |
| --- | --- |
| 1:1 | 2048 × 2048 |
| 3:4 | 1728 × 2304 |
| 4:3 | 2304 × 1728 |
| 9:16 | 1536 × 2688 |
| 16:9 | 2688 × 1536 |

每批可提交 **1–6 张**。数量表示独立生成任务，不保证内容一致，也不代表同时执行。切换回文生图后，本次图片请求不携带图生图参考素材。

## 4. 图生图

1. 选择 **生图 → 图生图**。
2. 点 **上传或选择商品图**。可以选择素材库已有图片，也可以上传一张新图。生成参考图限 **单张、最大 10MB**；上传格式为 JPG、PNG、WebP。超出上限的素材不能选作生成参考图。
3. 检查参考图缩略图。需要更换时点击 **更换图片**；点击移除按钮可清空当前参考图。
4. 选择图片用途，在 **你想修改什么？** 中明确写出保留与修改范围。
5. 设置比例和数量，点击 **生成 N 张图片**。确认后，参考图和描述会发往火山方舟。
6. 查看生成结果，逐项核对商品数量、外形、颜色、包装、文字与背景，再决定是否采用。

示例描述应与真实参考图一致：

> 保留参考图中实际出现的单个白色瓶子，保持瓶身形状、瓶盖比例、液滴图标与空白标签区域；仅将背景替换为浅灰白大理石台面，柔和自然光，不增加其他商品。

缺少参考图、文件无效或超过限制时，页面会提示修正。本轮已接通参考图真实传参；图生图仍可能改变商品细节，不能理解为商品一致性保证。

图片成果卡的 **参考生图**，或预览窗口的 **用作图生图参考**，会将该图带回工作台，自动切换到图生图。描述、比例和生成按钮都在同一页面。

## 5. 用首帧生成视频

1. 选择 **生视频**。
2. 上传或选择一张商品图作为首帧，限制同样为 **单张、最大 10MB**。也可在图片成果卡点 **生视频**，或在预览窗口点 **用作视频首帧**。
3. 填写 **镜头与动作描述**，例如：  
   > 镜头缓慢推近，商品保持静止，柔和光线掠过瓶身，保持商品形状和包装稳定。
4. 选择比例、生成数量和 **5 秒或 10 秒**时长。当前模型为 **Seedance 1.0 Pro Fast**；请求规格为 720p、关闭音频，页面暂不提供音频或分辨率切换。
5. 点击 **生成 N 条视频** 并确认费用提示。
6. 在右侧成果区或任务中心打开视频，播放检查，下载原文件。

视频请求支持页面中的 1:1、3:4、4:3、9:16、16:9。最终像素与时长以实际文件为准；例如已有 9:16 实测输出为 **704 × 1248、5.041667 秒**，不应按请求标签假定文件恰好是 720 × 1280、5.000 秒。

当前生视频入口为**首帧图生视频**。选择图片或切换到生视频只准备参数，确认提交才会调用模型。任务成功后，系统将结果下载到本地素材库。

## 6. 查看成果与继续创作

| 操作 | 结果 |
| --- | --- |
| 点击图片或视频缩略图 | 打开真实文件预览；视频可播放 |
| 下载原文件 | 下载本地保存的图片或 MP4 |
| 参考生图／用作图生图参考 | 回到工作台，以该图片作为图生图输入 |
| 生视频／用作视频首帧 | 回到工作台，以该图片作为视频首帧 |
| 排版／加入排版 | 将图片加入固定尺寸排版编辑器 |
| 在预览中填写 SKU 分组 | 保存项目内管理标签，不改变模型输入或保证商品一致性 |
| 素材库勾选后「打包导出」 | 生成 ZIP，包含选中真实文件与素材记录 JSON |

工作台成果区根据当前生图／生视频类型显示最近生成的素材；上传原图在素材库和参考图选择器中查找。服务暂时断开时会显示连接提示，已有素材记录保留；恢复后继续刷新。不要把连接失败当成素材已被删除。

旧黑图、混乱测试图与模拟图已按此前授权清理，正常商品图、上传原图与视频保留。清理备份位于 data/trash/20261022-废测试素材/；当前日常操作不需要再次清理该目录。

## 7. 排版编辑

排版编辑用于把商品图、文字和色块组合成一张固定尺寸图片。

1. 从图片成果点 **排版**，或在预览中点 **加入排版**。
2. 用左侧工具添加文字、色块或图片；拖动图层改变位置，拖动选框右下角调整尺寸。
3. 桌面右侧可以调整位置、尺寸、旋转、透明度，或修改文字、字号与颜色。图层可复制、移除、上移；可使用撤销。
4. 未选图层时，可以修改画布比例与背景颜色。当前画布预设包括 1080 × 1080、1080 × 1440、1080 × 1920、1920 × 1080。
5. 点击 **导出画布** 导出实际排版 PNG。素材生成与排版编辑互相独立，生成结果不会覆盖正在编辑的画布。

排版素材上传上限为单张 **20MB**；用于生成的参考图仍遵循 **10MB** 上限。当前排版是固定尺寸图片编辑器，**无限节点创作画布、节点连线与节点自动执行尚未实现**。视频只能预览和下载，不能在此编辑时间线或合成多段视频。

## 8. 保存、刷新与版本冲突

工作台与排版共用项目草稿，保存在本机数据库，并保留浏览器恢复副本。

- 自动保存包括项目名称、排版图层、SKU 分组以及生成设置：生图／视频类型、文生图／图生图、图片用途、图片与视频各自的描述、比例、参考图、生成数量和视频时长。
- 也可以点击顶部 **保存草稿**。输入后查看保存状态，确认显示 **已保存到本机**。
- 刷新页面会恢复上次保存内容；浏览器中有未保存恢复副本时，会优先恢复这些编辑。当前只提供自动恢复流程，没有完整的多项目草稿列表界面。
- 多页面同时编辑同一草稿时，可能出现版本冲突。系统暂停覆盖，保留当前浏览器副本，并显示 **另存为新草稿**。点该按钮将当前内容保存成独立草稿，保留另一个页面的版本。
- 生成过程中可以继续编辑和保存草稿。保存草稿不会启动生成，也不会重新提交之前的任务。

清除浏览器存储可能删除未同步的恢复副本；本机素材和后端草稿保存在项目 data 目录，不能把删除该目录当成普通刷新操作。

## 9. 任务、取消与重试

任务中心显示真实后端状态，包含本地排队、云端排队、云端生成、保存结果、已完成、生成失败、已取消和已中断等。成功任务可以预览结果；错误详情可以展开查看。

| 场景 | 操作与边界 |
| --- | --- |
| 本地排队、尚未发送云端 | 请求取消后不再执行该本地任务 |
| 云端仍处于可取消的排队阶段 | 后端尝试云端取消，并显示实际返回结果；历史验证尚无该阶段成功取消样本 |
| 云端视频已经生成中 | 请求取消可能只停止本地等待与下载，云端仍可能继续生成并计费 |
| 失败、已中断或已取消 | 页面可提供「从头重试」；会创建新任务，云端重试可能产生新费用 |
| 创建结果未知 | 不提供直接重试；先核对云端任务，避免重复生成 |
| 已完成 | 不再取消；可复用结果发起新的创作 |

常见错误：

- **MODEL_NOT_OPENED**：账号没有对应模型权限。
- **AUTH_MISSING／AUTH_FAILED**：后端 Key 配置缺失或鉴权失败。
- **BUDGET_NOT_APPROVED／BUDGET_EXCEEDED**：预算未批准或预算检查未通过。
- **REFERENCE_IMAGE_REQUIRED／ASSET_NOT_IMAGE／INVALID_REFERENCE_IMAGE**：检查参考图是否存在、是否为图片、文件是否有效。
- **CONTENT_REJECTED**：内容未通过服务方审核。
- **CREATE_RESULT_UNKNOWN**：创建请求结果不明确，应先核对再决定如何处理。

服务重启时，后端对有已保存云端任务 ID 的未完成视频继续查询原任务；不等于从中间帧继续生成。无法恢复的本地执行状态会按实际情况标记中断，需要手动处理。后端恢复的既有验证详见《多任务并发说明》，不要为了普通页面刷新去终止后端进程。

## 10. 费用与预算

页面中的 **今日估算**、任务卡的 **估算费用** 和 /api/usage 都是系统记录的估算，**不是火山实际账单**。当前批准预算沿用 .env 配置；系统会在发起模型调用前进行预算检查，预算错误需要先核对用量。

当前代码使用的估算口径为：

- Seedream 5.0 Flash：**0.12 元／张**。
- Seedance 1.0 Pro Fast：按任务返回用量，使用 **4.20 元／百万 token** 的当前配置估算。每条费用随分辨率、时长和实际返回用量变化，不使用固定「每条 1.56 元」口径。
- 部分历史视频任务曾按 **15.00 元／百万 token** 估算，记录约 1.56／1.63 元；这些是**旧口径历史记录**，保留未重算。历史合计因此不能当成按当前口径计算的总额，更不能当作实际扣费。
- 上传、选择参考图、修改描述、排版与保存草稿不产生模型生成费用。提交生成、从头重试以及云端仍在执行的已请求取消任务，可能产生费用。

最新金额以页面和任务明细查看，最终对账以服务方账单为准。本手册不固定写入会持续变化的“当日已用”总额。

## 12. 当前功能边界与简短验收路线

已实现：统一生图／生视频工作台、文生图、单参考图图生图、首帧图生视频、批量任务提交、素材预览与复用、固定尺寸图片排版、PNG 导出、选中素材 ZIP 导出、草稿自动保存与冲突另存。

尚未实现或不保证：

- 无限节点画布、节点依赖调度、视频时间线编辑。
- 多参考图输入、局部重绘、扩图、多 SKU 生成一致性保证。
- 模型从中间步骤或中间帧断点续跑。
- 对云端已经生成中的视频实现确定取消并免除费用。
- 账号没有开通的其他模型；正式页面仅保留本轮已开通的两个模型。

建议验收顺序：

1. 打开 8100，直接看到生图／生视频与右侧成果区。
2. 在生图下面切换文生图、图生图及图片用途，确认不会跳到另一个创作页面。
3. 图生图选择单张真实商品图，检查参考图与描述后提交；预览结果时分别检查生成成功和商品保持情况。
4. 复用图片作为视频首帧，检查 5／10 秒参数；已有视频可直接播放回归，不必每次验收都重新生成。
5. 修改描述与参考图，等待保存完成后刷新，检查设置恢复。
6. 把成果加入排版，添加文字后导出 PNG；在素材库勾选文件打包 ZIP。
7. 查看任务状态、估算费用和当前限制，按真实完成情况记录。
