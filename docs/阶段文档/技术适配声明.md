以下为原适配记录；与本补充冲突时以本补充为准。

## 1. 产品形态判断
- **形态**：单机本地 Web 工作台（后端 FastAPI + 前端由 Codex 用 Vite/React 开发）＋ **火山方舟云端推理**（Seedream 图片、Seedance 视频）。
- **开发路径**：纵向切片（已有最小验收页与真实链路，继续按切片扩展）。
- **覆盖声明**：原先「全部本地推理、无云端兜底」的限制**已被本轮需求变更覆盖**；界面与文档必须写「本地工作台 + 云端推理」。

## 2. 采用的默认方案
| 层 | 方案 |
| --- | --- |
| 后端 | Python 3.12 + FastAPI + Uvicorn + Pydantic（沿用现有实现，不重建） |
| 持久化 | SQLite（沿用；新增云端字段以迁移方式兼容旧库） |
| 任务 | 现有持久化队列 + 单 worker；新增云端异步任务轮询 |
| 推理 | 火山方舟 Ark HTTP API（图片同步 / 视频异步） |
| 文件 | 内容寻址素材库（沿用），云端结果下载后入库 |
| 前端 | Codex：`frontend/`（Vite + React + TS） |
| 测试 | pytest + 假 provider（余额不足/无 Key 时不发真实请求） |

## 5. 强制底线检查
| # | 底线 | 落实 |
| --- | --- | --- |
| 1 | 密钥不进仓库/前端/日志 | `.env` 读取；`.gitignore` 已含 `.env`；错误信息不含 Key |
| 2 | 长任务与确认点持久化 | 任务表 + `remote_task_id` + 草稿版本 |
| 3 | 统一错误结构 / SSE 收尾 | 已实现（本期未用 SSE，轮询为主） |
| 4 | 超时/失败/有限重试 | 创建超时→`CREATE_RESULT_UNKNOWN` 不重发；网络类有限重试 |
| 5 | 付费动作需人工确认 | **预算闸门默认 0=禁止**（已实测拦截） |
| 6 | 上传校验 | 魔数 + 大小 + sha256 命名（沿用） |
| 7 | 权限在后端 | 单机单用户，仅 127.0.0.1 |
| 8 | 计费先告知 | PRD §5 已给估算，等你批准 |
| 9 | 不删既有成果 | 数据、代码、文档全部保留，旧方案归档 |
| 10 | 不把模拟当真实 | 无 Key → `AUTH_MISSING`；`fake-image` 仅测试环境 |
