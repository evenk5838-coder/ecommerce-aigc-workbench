| --- | --- | --- |

| 合成来源识别 | 合成卡依次显示原来源节点名称，编号独立保留；缺失标题／只有素材时显示可播放预览，有 node_id 时仍可定位 | 来源顺序遵守已保存 sources，标题映射顺序不影响拼接顺序 |

| 原请求恢复 | 请求号、原消息、会话、选择范围和修订先持久化；受理未知先 GET 查询；确认结果同样按原动作与请求号恢复 | 停止等待不等于取消任务。仅明确请求不存在时，用户可点“用原消息重试”，再次核对后使用完全相同请求号和载荷 |
| 缓存与已保存结果 | 保存确认回执后再刷新画布；局部读取失败保留已确认内容；缓存只缩减可重新读取的展示历史，保留草稿和待核对写入身份 | QuotaExceededError 降级有自动回归；真实浏览器存储极限、禁用存储等环境仍需单独验，不清空旧缓存或用户草稿 |
| 刷新恢复项目 | `#/director/<projectId>` 恢复指定项目画布；`#/director` 为导演台项目入口；保留快捷工作台已有锚点 | 已观察刷新后仍为原项目、6 个节点；不新增另一套项目数据或清理 localStorage |
| 局部结果和失败 | 显示 failed／partial、原有成功结果与实际素材可用性；只有文件可用才给可用媒体预览 | 不把任务历史 succeeded 当作当前文件可读取，也不把缺镜头的 film 写为完整成功 |

多节点选择会进入对话上下文。后续引导携带可见的本组范围，用户主动改变选择后改用新选择；恢复始终使用已经提交的原始范围。浏览器已验证：当前只选一图时整组建议仍包含两图，刷新后保持；用户主动选择第二图后改用该节点，草稿文字保留。

本轮涉及的主要前端文件为 `DirectorChat`、`WorkflowActionCard`、`director-workflow-api`、`workflow-conversation-state`、`director-action-view`、`workflow-draft-scope`，以及 `CreativeSpace`、`FreeCreationCanvas`、引用连接、进度同步、旧分镜投影和项目 hash 路由辅助模块。预览脚本新增 workflow 固定供应商模式；本批不通过重启或覆盖正式服务来证明联调成功。
