# 无水印与完整构图 · 后端收尾

用户要求：修复图片水印和视频近景裁切，继续后端收尾；本批不得调用付费模型。沿用现有 FastAPI / SQLite / worker / 画布确认，不修改正式前端、不启用新型号、不改历史媒体。按既有 agent-builder / ai-product-starter-kit 的项目适配流程交付。

## 本次变更

1. 无水印为产品固定规则。AiHubMix 图片通过 `extra.watermark=false` 传给上游；AiHubMix 视频同样明确传 false；Ark 图片/视频在顶层明确传 false。网关文档的 `extra` 为供应商扩展字段，图片模型原生接口的 watermark 默认 true 是本次漏传后出现标识的原因。
2. 所有云端提交校验拒绝 watermark=true 或其他非布尔 false 值。直接供应商封装及历史排队执行也检查；提示词中的 `--wm true` / `--watermark=1` 等开水印参数在付费前拒绝。不向调用方提供一个“可以打开水印”的分支。
3. 图生视频首帧在本地处理：先应用 EXIF 方向，再等比 contain 缩放，四边至少10%留白，以边角采样的纯色补足目标比例，不拉伸、不居中裁切原图。方形→横版、竖版→横版等统一处理，参考图原文件和素材不变。图生图仍使用原图，不作视频画幅变换。
4. 文生视频和图生视频都附加完整商品构图要求：保留边缘、限制推进幅度；运镜和完整主体冲突时优先完整展示。原用户提示词保留在任务/报价中，实际供应商提示词附加约束。
5. 输出策略有版本 `no-watermark-contain-v1`；模型 API 与冻结报价显示相同策略。旧的打开报价须重新确认。已排队但尚未提交的旧策略也在发送前拒绝；已有远程编号的任务只继续查询下载，不重新收费创建。
6. AiHubMix 保存准备前后参考图哈希、方向校正后的尺寸、目标尺寸和内容框到任务 usage，重启后保留；不落原图 Base64、不将参考图片当成新业务素材写库。历史已有结果与旧验证码样例不修改。

## 依据和边界

- [Seedream 原生图片 API](https://docs.volcengine.com/docs/ark/image-generation-api)：watermark 默认 true，false 为不添加水印。
- [AiHubMix 媒体协议](https://docs.aihubmix.com/cn/api/async-tasks)：extra 为供应商扩展参数。[Flash Schema](https://aihubmix.com/call/schema/models/doubao-seedream-5-0-flash/endpoints) 中原生图片 extra 支持扩展对象。
- [Seedance 原生视频 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api)：支持明确关闭视频水印。没有为2.0系列虚构 camera_fixed 字段。

无付费调用条件下，本批只能验证请求关闭参数和本地几何处理，不能证明供应商实际遵守了关闭水印及构图要求。无水印是强制产品验收条件，AiHubMix 型号继续 pending_validation，不能以“请求提交 false”代替实际画面验收。旧的带标识参考图如果继续作为输入，关闭新水印参数不会擦掉图中已有标识；本批不做擦除、遮盖或裁掉标识的处理，也不能从已裁切的视频中恢复不存在的边缘。

10%安全边距确保本地送出的参考画面完整，不保证生成模型绝不推进或裁切。真实去水印与完整商品视频的复验在用户另行批准后执行，本批新增模型请求0、费用0。
