## 当前目标

## 规则

- 服务端AIHUBMIX_ENABLED_MODELS显式允许列表，默认空。只有Flash/Fast有可用真实合同样例；Mini/未知条目使整份清单关闭且不回显原值，避免误贴敏感内容。手动改MODEL_ACTIVATION字典不能绕过运营配置。
- Flash首批许可文生图/图生图1024×1024、每请求1张；Fast首批文生视频/图生视频5秒480p16:9无声。供应商更宽能力单独返回vendor_capabilities，不缩历史时长策略和费率估价，旧无quote远程10秒720p仍可按原任务恢复。
- Key为空返回AUTH_MISSING；换算上界缺失/无效保持MODEL_PRICE_UNCONFIRMED。实际.env本批未改，不把隔离测试8当作生产配置已经完成；持续启用与估价配置在交接前确认。
- public API暴露逐型号validation/operational_profiles/启用/价格状态。旧all-model generation_verified保留兼容，新增sample_verified_models/enabled_models/available_models/any_submittable，菜单按单型号状态。
- 应用入口、画布、导演台的新请求缺省值按首批操作规格补齐，显式未支持值拒绝不替换；原Ark默认不变。低层纯body构造不会把真实缺省9:16/720p伪装480p；实际付费create及worker再次校验许可/费用状态。
- 未发送新任务必须遵守当前许可；已有远程编号只查询/下载，保留创建时策略，不以新许可/规格阻断旧任务恢复或重新收费创建。
- 新直建任务保存与模型、参数、参考图绑定的费用预留，画布已消费报价仍优先。已有远程任务在费用配置关闭时也可取回原结果；历史费用无法确认时标记待核对，费用保持未知，不记零，不重新生成。该未知费用继续阻断新增付费请求，恢复换算配置也不会偷偷重估。
