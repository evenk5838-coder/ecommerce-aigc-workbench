# 模型规格组合前端 · 2026-10-29

用户已切好前端模型并授权继续。沿用 agent-builder、ai-product-starter-kit 的既有适配；保留 React/Vite、C版视觉与导演台，Web优先，手机及排版编辑延期。规则卡已对账，既有项目技术选择与本批范围无冲突，不迁移或新建项目。

## 范围与交互

- 同一组合解析器供快捷工作台、模板、画布节点、旧分镜入口使用。后端组合白名单是唯一来源；缺失保留旧行为，显式空／非法规则不开放生成。
- 上游选项先决定下游：模式→比例→清晰度／尺寸→时长。过期下游值不反向锁死上游，修改前保留原草稿并提示调整。
- 组合是行内 AND、行间 OR；不把不同合法行拆散拼成非法组合。最终请求、已打开报价的确认以及节点配置均校验原值。
- 图片优先显示比例和1K/2K等档位，同档多尺寸可展开查看。未添加任何厂商、价格或真实能力；未放宽原预算及确认。

## 实现与边界

新增 frontend/src/model-specs.ts、组合类型与回归测试；公共 capabilities 增加选项投影和冻结报价校验。原账号开通／生命周期判定仍由服务端提供。

旧 ProductionFlow 的独立分镜接口只接收 size，不接收 ratio；若未来组合强制 ratio，此入口会保守拦截，需后端接口扩展后开放。旧整组视频 scope 的预校验尚未带完整逐镜参数，未来启用有时长／模式组合约束的型号前需补齐；本批不修改后端或声称该旧入口已通过新组合真实提交。画布视频节点保存还缺少把根层 generation_mode 合并到最终校验参数的处理；节点执行器禁止在 params 内重复携带 generation_mode，因此前端遵守现有格式，不以非法字段绕过保存校验。需下一批后端补齐后，才能宣称按模式组合约束的画布节点完整通过。
