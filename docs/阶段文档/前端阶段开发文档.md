# 前端阶段开发文档

2026-10-22。当前已完成 v0.6 统一工作台联调；前半部分为首版历史，最新增量见文末。

## 本轮闭环

上传真实素材 → 加入画布 → 移动、缩放、叠加文字/形状 → 自动保存本地后端草稿 → 刷新恢复 → 导出 PNG。

生成面板 → 提交单条或批次 → 显示真实任务状态 → 查看结果、加入画布或下载；生成过程中可继续编辑。

## 页面和状态

- 工作台：三栏，生成/素材、画布、图层属性；任务抽屉和素材库独立入口。
- 首次加载、无素材、接口失败、模型未就绪、排队、加载、生成、取消中、成功、失败、中断均分别显示。
- 画布草稿遵循后端版本号，冲突明确提示，不静默覆盖。浏览器只保存草稿 ID 及异常恢复副本。
- 本次重试是从头重试；本地运行中取消是协作式请求；云端取消显示后端返回的真实语义，费用以服务方账单为准。
- 不展示未接入的局部重绘/扩图为可用，不把静态素材合成叫模型视频。

## 接口

沿用 `docs/接口/接口契约.md`：health、system/status、models、assets、tasks、batches、drafts。新增前端包装集中于 api.ts。

本轮图片为文生图，视频通过 input_asset_id 使用首帧图；没有将参考图重绘或局部重绘包装为已实现。

## 验证

类型检查、ESLint、业务辅助函数测试、生产构建；Tabbit 真实浏览器检查桌面/小屏、真实素材加载、画布编辑、保存/刷新恢复、PNG 下载、读取 Pi 的真实生成任务及结果；本轮前端验证不重复提交付费任务。

证据存入 `docs/evidence/前端/`。模拟页面状态与真实后端测试分别记录，未完成项如实保留。
# v0.6 增量：统一工作台与图生图（2026-10-22）
