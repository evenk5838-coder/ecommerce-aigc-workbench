# C 版视觉、自由画布与对话导演

日期：2026-10-26。前端分支：codex/assistant-frontend-v1。正常预览：http://127.0.0.1:5184/。

## 本轮目标

用户要求 C 版 UI，画布交互参考 A 及用户提供的 OiiOii/LibTV 截图。快捷工作台保留四模式快捷生成、模板及可选提示词润色。导演台以对话推进需求，右侧逐步留下脚本、分镜及视频成果；每次生成仍由用户确认。

## 已落地

| 用户反馈 | 当前结果 |
| --- | --- |
| 项目名重复 | 导演编辑区仅保留一个项目标题，移除对话区重复名称 |
| 首页不能下滑 | 修复容器高度和 overflow，1025×684 实测能滚动 |
| 首页四个模式卡片过多 | 换为快捷工作台与导演台两个主入口，四模式保留在工作台 |
| 两入口定位不清 | 首页分别介绍快速单次生成与多镜头对话创作 |
| 版本说明、版本历史和开发字段 | 移除主流程展示及原始 JSON 编辑区；必要错误恢复用简短操作提示 |
| 脚本需先保存又确认 | 单次“确认脚本并继续”，内部按需保存后确认准确新版本；失败不盲目重复保存 |
| 分镜尺寸数字难读 | 按模型真实能力展示比例图形与 1K/2K 等清晰度，详细像素收起 |
| 无限画布不能自由拖动 | 节点自由拖动、背景平移、缩放、适配、键盘移动；刷新恢复本地布局 |
| 单个素材调整 | 点击节点后在其下方显示设置；分镜图模型、提示词、参考图与规格可独立调整 |
| 需要逐步出现成果 | 从实际项目、镜头、任务与成片读取节点，未到达阶段不创建假结果 |

深浅主题沿用 C 版苔绿视觉。旧文生视频全局提交阻断已移除，当前按真实模型 input_modes 与 submittability 等限制提交；主仓 B0–B6 已核对修复，不重复列入后端待办。

## 仍未完成的真实产品能力

现有 DeepSeek chat 只支持现有工具和建议，不返回已保存脚本/镜头提案。当前左侧是真实对话入口，但脚本起草仍需使用折叠的“创作资料与操作”。前端没有把 reply 文本伪造成项目产物，也没有自动发起第二次 LLM 调用冒充保存。

后端需补：项目范围的导演编排；结构化提案自动保存、真实对象 ID/版本；消息与操作的幂等和恢复；每次 LLM 调用的预算检查；节点生成配置服务端持久化。现有视频模型仍按组设置，单个视频节点的独立模型范围需要后端契约配合。布局和未提交节点设置目前仅在本浏览器保存。

前端后续消费后端冻结响应，把对话中的提案、修改、确认与实际项目产物贯通，并统一验证真实模型、异常恢复、成片与导出。当前不能宣布完整产品内测就绪。

## 前后端分工

- 前端：自由画布和设置、对话呈现、提案/确认操作、真实结果回看、错误恢复、主题与响应式。当前代码已完成上述可独立实现部分，新增导演提案动作待契约。
- 后端：复用 assistant、DeepSeek 官方 API、projects/shots/scope/assembly；负责导演工具编排、保存回执、版本和批准状态、节点配置持久化、预算闸门。只移动节点不得使生成确认失效。
- 双方：先固定最小响应 fixture，前端并行接入；免费隔离检查完成后在已批准用例及预算内验证真实流程。新范围不能借用旧预算。

[后端可复制指令](../接口/对话导演与自由画布-后端指令-20261026.md)中的新端点是建议设计，尚未实现，可以复用等价现有端点，不能声称已可调用。

## 验收

22 个测试文件、481 项测试、类型、Lint、生产构建通过。隔离浏览器验证首页滚动、节点拖动及恢复、脚本一次确认、独立分镜规格、深浅主题与窄屏；所有 API 使用 fixture。本轮没有真实 LLM/图片/视频调用，也没有业务库写入。
