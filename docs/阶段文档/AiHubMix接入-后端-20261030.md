# AiHubMix 接入 · 后端批次

日期：2026-10-30。沿用用户确认的 FastAPI / SQLite / React 架构、本机 .env 和现有任务队列；不迁移项目、不改正式前端。按 agent-builder 与 ai-product-starter-kit 的现有项目适配约定推进。

## 目标和范围

用户希望以同一 AiHubMix 账号余额调用多种媒体模型。新增独立供应商适配层，并接入现有确认、预算预留、worker、素材和导演节点。Ark 型号和历史数据保留，默认模型不变；LLM 仍使用原文本通道。

本批适配应用内的四种方式：Flash 文生图、单张图生图；Fast/Mini 文生视频、首帧图生视频。每个图片节点只生成一张，每个视频节点只生成一条。不开放未经适配的任意参数、参考视频/音频、多图、首尾帧或自动时长。

内部型号使用 `aihubmix:` 前缀，上游请求使用目录中的原始型号，防止与 Ark 的开通状态、日期快照和价格混用。

## 外部依据与发现

- [Flash 参数 Schema](https://aihubmix.com/call/schema/models/doubao-seedream-5-0-flash/endpoints)：优先原生端点。图片 `size` 与 `aspect_ratio` 二选一；本批发送像素尺寸，参考图走 `image`。
- [Fast 参数 Schema](https://aihubmix.com/call/schema/models/doubao-seedance-2-0-fast-260128/endpoints) 和 [Mini 参数 Schema](https://aihubmix.com/call/schema/models/doubao-seedance-2-0-mini-260615/endpoints)：4–15 整数秒、480p/720p、比例及音轨开关。首帧走 `frame_images`，水印走 `extra.watermark`；Schema 未暴露 seed，本批拒绝显式随机种子。
- [Flash 价格](https://aihubmix.com/model/doubao-seedream-5-0-flash)：USD 0.0186/张。[Fast 价格](https://aihubmix.com/model/doubao-seedance-2-0-fast-260128)：无输入视频 480p USD 0.055/秒、720p USD 0.113/秒。
- [Mini 价格](https://aihubmix.com/model/doubao-seedance-2-0-mini-260615) 的正文与表格不同，价格保持未确认，不沿用 Ark 单价。
- Pro 目录可见但本次公开 Schema 获取未成功，Nano Banana 使用图片清晰度档而非现有像素尺寸；均保留候选资料，不冒充本批已适配。更完整目录及 Schema 留在前一天的 `docs/evidence/v0.11-AiHubMix接入-后端-20261029/`。

## 配置、接口与费用

后端 `.env` 使用 `AIHUBMIX_API_KEY`、`AIHUBMIX_BASE_URL=https://aihubmix.com`、`AIHUBMIX_TIMEOUT`。密钥不返回前端、不保存到业务表、不进入证据或日志。

新增 `GET /api/providers/aihubmix` 仅返回 configured、generation_verified、async_enabled（尚未实测为 null）及三个型号的可提交性。此接口不对外请求、不调用生成；密钥模型目录查询封装为只读 `list_models()`。

USD 价格使用独立计价规则，向上取整到人民币四位小数。`AIHUBMIX_USD_TO_CNY` 是人工核对的预算换算上界，不是实时汇率，默认 0 时禁止报价。未知价格不按 0 或 Ark 价格兜底。Mini 保持价格未核实。

所有新型号 `activation=pending_validation`，普通提交与 worker 均不允许生成；密钥鉴权通过不自动改为 verified。离线测试只在隔离进程模拟 verified 和换算上界 8，不能转述为用户付费授权或实际价格。真实验证需要另行确认预算，之前各批额度不复用。

## 任务、错误与恢复

图片与视频都按异步方式创建，收到远程 ID 立即落库，随后轮询和下载。重启、下载失败后恢复沿用同一 ID；报价确认和素材链保持原关联。`POST /api/tasks/{id}/retry` 对尚未结束的 AiHubMix 远程任务恢复同一任务，只查询/下载，不重新创建。

网络或响应丢失导致创建结果未知时不重发，保留预算预留，要求核对原请求。任务未结束、成功但下载失败等情况继续保留费用，防止重复扣费。供应商没有已核实的取消端点，本地取消只停止等待，明确保留云端计费可能。

错误区分：未配置密钥、鉴权/权限、异步未开启、余额/密钥额度不足、限流、参数、创建结果未知、本地等待超时及下载错误。供应商原始错误信息不进入用户响应或任务表。下载只接受该任务的官方代理路径，禁止把密钥发送到返回的外部 URL 或重定向。

## 验收和交接

复现命令：`APP_PYTHON=backend/.venv/bin/python bash verify.sh aihubmix-backend`。涵盖完整后端回归、保留导演回归、凭据扫描、两种隔离 HTTP/worker/FFmpeg/重启流程以及正式前端产物指纹检查。供应商网络被阻断，固定图片/视频仅验证代码和协议映射，不代表模型效果。

本批自动检查、发布状态及待验内容见同名证据目录的是否表。真实模型生成仍待验，不宣称完整接入验收通过。下一步先核对异步开关、价格和预算，再真实验证图片/视频契约；进入前端模型选择接入前按用户要求通知切换模型。手机端、排版编辑继续暂缓；不修改外部评测文档。
