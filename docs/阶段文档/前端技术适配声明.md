# 前端技术适配声明

2026-10-22，Codex；依据用户本轮“前后端同时开发、现在开始前端”的授权执行。

- 目标：本地电商素材工作台。桌面优先，兼顾小屏；直接接现有 8100 后端。
- 输入：PRD v0.4.1、接口契约、交接包和真实接口已读取；后端已改为本地工作台 + 火山云端模型；图片已有真实云端成功记录，视频权限仍待验证。
- 前端位于独立 `frontend/`；React + TypeScript strict + Vite；原生 CSS 变量、Lucide 图标；不修改 Pi 管理的后端实现。
- 采用 Vite 替代手册默认 Next.js：单机工作台无 SSR 需求，现有 FastAPI 已负责持久化和推理，Vite 代理 `/api` 避免跨域。依赖版本锁定于 package-lock。
- 后端是任务状态和草稿的事实来源；2.5 秒轮询；模拟测试任务默认不作为真实生成结果展示。创建任务使用幂等请求 ID。
- 正式画布：素材图层、文字、形状、拖动与尺寸调整、顺序、背景、撤销、草稿自动保存及 PNG 导出。生成结果不自动覆盖编辑。
- 素材、任务、批量提交、取消、从头重试、错误恢复和下载均接真实接口。模型列表由后端提供；图片默认优先 Flash，模型显示就绪不等于账号已开通。
- 沿用单机单用户，无登录；本机监听。页面不使用外部字体；模型请求仅由本地后端代理至火山引擎，Key 不进入浏览器。
- 视觉采用浅灰工作区、白色编辑面板和靛蓝操作色，保持素材为视觉中心。
- 不新增必须确认的业务决策。商品保真、SKU 一致性与视频实测以后端证据为准，画布编辑不能替代这些模型能力。
