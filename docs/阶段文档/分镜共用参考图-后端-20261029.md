## 本批行为

`prepare_storyboards` 新增顶层可选 `input_asset_id`，表示本次分镜组的共用参考图片。每一镜省略该字段时继承；指定另一张图只覆盖该镜；显式 `null` 则该镜为文生图。没有本组参考图时保持原有文生图行为，旧调用兼容。

参考图写入各节点的真实 config，并由原有报价／确认／队列执行传入图片供应商请求，不只是给提示词附一条名称。节点刷新、重启或重新生成继续沿用已保存配置。共用关系仅作用于本次新建组，后续节点调整不会批量改写其他镜头或已有项目。

本组及单镜图片 ID、类型、可读取文件及 SHA 均校验；无效默认图即使被所有单镜覆盖也不静默忽略。所选模型必须支持图生图。任一镜头失败，分镜／镜头记录／操作回执整体回滚。报价之后图片改变、单镜换图或参数变化使原报价失效；只对用户指定镜头重新准备确认，不扩大生成范围。

Agent 工具 schema 明确继承／覆盖／取消语义；提示词要求使用用户指定的真实商品参考图和已知商品特征，不猜图中内容，不拿无关图片替代。不新增前端表单、不改变 C 版 UI、不扩大预算或自动重试。
