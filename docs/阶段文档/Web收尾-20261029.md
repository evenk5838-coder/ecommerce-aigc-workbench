# Web 收尾：暂缓排版编辑，保留核心创作及下载

状态：代码、免费完整检查、桌面浏览器操作与 8100 静态发布完成；排版 PNG、手机端、新模型画质按本轮边界处理。

## 本轮范围调整

用户明确要求排版编辑先隐藏，因其非核心功能且仍有问题，本次不上线。因此本轮停止 PNG 排版图层、字体、尺寸的修复与验收；相关缺口延后，不能宣称已解决。保留实现、已有图层和本机草稿，不删除功能数据。既有两个 Skill 的阶段流程沿用当前项目，按用户最新范围处理，不引入额外技术栈。

隐藏顶栏入口、快捷工作台入口、生成结果“继续创作”中的排版按钮、素材库“加入画布”、预览“加入排版”、任务结果“加入画布”。内部视图统一把暂缓的排版页映射至快捷工作台；旧 `#/canvas` 路径按原有路由回到项目首页，不能打开排版页。导演台的无限画布继续可用。

## 下载收尾

素材打包原先把 WebP 扩展名写成 PNG，现按真实 MIME 保留 PNG／JPEG／WebP／MP4，文件字节保持原样。图片和视频的原生原文件下载入口保留。打包中某项下载失败、格式不符或为空时整包失败；不生成不完整 ZIP 或仅有清单的 ZIP。提示仅表述“已开始下载”，不假定用户已经保存到磁盘。下载 Blob 的锚点附入 DOM 并在触发后移除，保留原有延迟 URL 释放。

素材库常驻“上传素材”按钮，隐藏排版后仍能直接通过文件选择器添加图片。原有排版实现和图层数据均保留，未修复或删除其内部逻辑。
