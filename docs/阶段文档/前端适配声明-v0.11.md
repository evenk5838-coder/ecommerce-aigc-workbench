## 4. Agent 与恢复状态

| 服务端／网络状态 | 用户界面及处理 |
| --- | --- |
| 未提交 | 显示当前职责和输入，允许组织想法或明确起稿 |
| 提交中 | 即刻锁住相同动作；显示“正在创作”，不预报脚本成功 |
| `outcome=clarify/message` | 显示真实回复；没有已保存产物时不造空脚本节点 |
| `outcome=saved` | 从 artifacts／node_ids 找到真实节点，刷新后端内容并定位；完整脚本从绑定的 script_id 读取 |
| `outcome=partial` | 保留已成功内容，明确剩余项失败，不把整个动作标为全成功 |
| `outcome=failed` | 说明未完成原因，保留输入／已知结果；修正后由用户发起新动作 |
| HTTP 已处理 | `request_status=completed` 只代表响应结束，不能替代 outcome 判断 |
| 网络中断／停止等待 | 保留原 client_request_id，回查持久化回执；不自动用新 ID 再发一次 |
| 回执 pending／未知 | 显示仍待核对；不能自动宣称取消、失败或成功 |
| 配置版本冲突 | 保留未提交编辑，读取最新状态后明确处理；不得以旧整图覆盖新节点 |
| 项目不存在／已删除 | 清楚提示并提供返回导演台，不自动打开旧项目或伪造恢复 |

脚本确认仍绑定具体版本，编辑后一次操作完成保存及确认。确认脚本不会授权后续媒体费用。完整专业职责链保留编剧→导演→摄影师→剪辑师的产品方向，本批只验收脚本真实工具链与既有动作，不把职责名称当成后续媒体执行已完成。

## 5. 页面与产物

核心页面包括项目首页、导演台项目创建／选择、项目画布、对话面板、节点下方设置、结构模板入口。项目名只在紧凑位置出现一次；删除独立项目大标题条、隐藏资料表单与指定开发说明。画布占主导航下方工作区，对话可收起，收起保留会话、草稿和请求恢复信息。

切片 1 的可验闭环：进入导演台→新建／打开项目→对话起稿→后端保存脚本及稳定 script 节点→显示与编辑正文→一次确认→刷新恢复；并可手动建文本、图片、视频节点，导入真实图片／视频，保存独立配置并恢复。图片／视频节点本批作为可配置基础，不宣称新自由节点已经接通付费生成或合成。

实际浏览器已检查 390、704、768、1280、1440px，五档均无水平溢出且画布铺满；390px 对话收起重开保留输入草稿。已截图验证 1440px 浅色画布、1280px 深色节点设置和 390px 深色聊天。窄屏采用可收起面板与可触达工具，避免把大表单和画布纵向叠成长页。媒体预览带加载／失败状态，视频使用真实控件，设置项按当前模型能力显示，比例与清晰度分别表达。
