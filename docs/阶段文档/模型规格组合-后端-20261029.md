# 模型规格组合后端基础

用户明确外部模型评测与本地开发并行，评测作为补充选型证据，不阻塞整体开发。复用现有Ark、FastAPI与本地数据，不建立平行工程；沿用两个既定Skill流程，技术方案与现有权限/确认边界无冲突。

本批只补统一能力输出与参数组合后端，不切换模型、不自动开通账号、不新增报价或供应商、不调整前端。现有生成方式、尺寸、清晰度、时长校验继续执行，在此基础上增加可选parameter_combinations白名单。

每行规则为各字段约束的交集，多行之间取并集。字段可包含generation_mode、ratio、resolution、size、duration、generate_audio。字符串/布尔/时长枚举用非空数组；时长也可用min/max/step整数范围；省略字段表示不额外限制该字段，原基础校验仍生效。未配置组合时保留旧行为；空、未知字段或非法类型的组合配置拒绝提交，不静默当成无限支持。

API与导演Agent均经public_model_capabilities序列化读取同一能力快照；复制返回值，调用方不能修改服务端规则。估价/提交使用同一resolve_task，节点保存与报价也沿原验证路径执行组合规则；不因有能力描述而授予模型账号权限。非法配置额外返回MODEL_SPEC_POLICY_UNAVAILABLE。

新增7项聚焦回归验证方式与规格绑定、时长类型/步长、错误配置关闭许可、输出副本、非法组合的估价/提交/节点保存/历史草稿报价拒绝，以及API与Agent一致性。测试全部在隔离数据库，禁止模型与worker。

例子：可以表达“文生图允许某尺寸、图生图仅另一尺寸”或“720p可5秒而1080p仅10秒”，这些仅为规则测试，不代表任何正式候选真实能力。未把候选能力直接启用到MODEL_CAPABILITIES；前端动态组合筛选、新供应商适配、实际规格验收分别在后续批次推进。

验证：APP_PYTHON=backend/.venv/bin/python bash verify.sh model-specs。证据目录docs/evidence/v0.11-模型规格组合-后端-20261029/。
