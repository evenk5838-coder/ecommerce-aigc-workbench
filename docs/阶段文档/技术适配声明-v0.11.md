# v0.11 技术适配声明

日期：2026-10-27，Asia/Shanghai。依据：已确认 [PRD v0.11](../PRD/PRD.md)。适用于现有工程增量，既有声明未被本版修改的部分继续有效。

## 1. 形态与最小任务

本地 Web 工作台，沿用 FastAPI、SQLite、现有队列和内容寻址素材库；前端沿用 React／TypeScript／Vite。当前优先实现“对话生成实际脚本并保存到画布＋自由节点配置和导入”，再接图片、视频与合成。

用户已确认一个主控 Agent 加分阶段专业能力的方向。编剧／导演／摄影师／剪辑师是任务职责，不按四个名称强行创建四个常驻 Agent 或服务。

## 2. 采用与保留

| 层 | 本次选择 |
| --- | --- |
| 工程 | 原目录、原服务和既有四模式，不另建产品 |
| 模型 | 沿用已有文本、图片、视频适配；不因 Pixelle 引入供应商或模型 |
| 对话 | 服务端有限工具循环；结构化 schema 与执行校验同源；保存回执决定是否完成 |
| 数据 | 复用 script_versions／director_proposals／canvas_nodes／director_requests；脚本正文唯一存于脚本版本 |
| 原子性 | 现有事务连接写脚本、提案、节点；模型请求不占 SQLite 写事务 |
| 任务 | 复用持久化 worker；本批无新增媒体执行工具；节点连线暂为组织数据 |
| 上传 | 真实内容识别、图片解码、视频完整解码、大小限制、内容寻址及并发去重 |

## 3. 新增模块与版本规则

画布新增 `text` 类型，媒体节点可独立保存模式、提示词、模型和参数。用户导入素材复用全局本地素材库，再由节点绑定；不得伪造素材的项目所有权。

脚本成功保存后同事务更新稳定的 `node_id=script`，保留位置、配置、视口及连线。新增版本保留历史正文；人工确认继续绑定具体脚本版本。节点布局变化只增加布局修订，生成输入变化增加配置修订并使旧范围确认失效。

对话新增 `outcome`，与旧 `request_status` 区分：请求处理完毕不代表脚本已保存。失败和部分完成的实际结果写入持久化历史；不靠模型一句“已保存”认定成功。

## 4. 限制与暂缓

- 当前后端先行。用户要求切换前后端前提前告知以便切换模型；前端开始前提醒并等待其切好模型。
- 本批不实现对话里的付费图片／视频执行、独立节点媒体任务、剪辑器、通用 DAG／条件／循环或多 Agent 团队；后续按切片扩展，不宣称连线已经可执行。
- 不新增 CloudBase、公开部署、多租户、RAG、向量库或新的基础设施。保留原生时长和纯拼接约束。
- 本次无需表迁移。不会因测试清理用户素材、草稿、历史或 localStorage。

## 5. 底线对账与验证

已对账，两份 Skill 在本次采用条款上无冲突。工具包目录规则按已有项目例外映射到本工程，默认部署方案不触发本轮范围。

每次 LLM 请求前保留单次／会话预算检查；本批导演输出上限独立设为 1600 token，普通助手配置不变，预算预检使用此上限。工具循环默认最多 4 轮／4 次工具调用，相同错误最多 2 次；输出截断或参数 JSON 错误不得执行保存。

隔离测试对业务库和外部模型设置守卫，重启验证在随机本机端口起真实 HTTP 服务，停止原进程并确认退出后重启，读取同一临时数据库；服务及目录在结束后清理。根目录 `verify.sh v0.11-backend` 保留五类检查含义；前端未改，构建／浏览器为本批 N/A，不能借此宣称整切片通过。真实模型质量与真实调用费用仍待验。

## 6. 已确认决策及后续验收

需求、主控方向与切片顺序已随用户“我看了，可以开始了”确认。本声明没有新增付费资源、平台或产品范围，不重复请求相同授权。实际面板样式、尺寸和引用控件在前端代表页中验收。

本次前端尚未实施。文本真实工具往返需在具体用例及费用范围核对后验证；图片／视频及成片按后续切片单独验收。不得把固定回复、真实文件解码或旧版本实测当作本版模型验收。
