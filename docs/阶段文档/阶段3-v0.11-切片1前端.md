## 1. 本阶段目标

用户在 C 版自由画布内通过对话得到真实保存的脚本，也可以主动建立文本／图片／视频节点、导入素材并调整独立参数；关闭对话后仍能工作，刷新后内容和布局完整恢复。

## 2. 范围与分工

本批包含：全工作区画布、紧凑唯一项目名称、可收起对话、新建／删除自由节点、真实上传导入、节点设置随缩放、文本与配置持久化、脚本 outcome 及回执恢复、完整正文与一次确认、结构模板入口迁移；回归首页、导演台列表、项目删除、四模式及深浅主题。

后端本批契约已具备脚本／节点原子保存、独立配置和上传。本前端通过已冻结接口接入，不把核心业务规则重写进页面。新的对话媒体执行、自由节点真实图片／视频生成、局部重做及导入视频直接合成仍按后续切片推进；保留现有媒体底座和已有入口，但不能把配置面板可用写成新执行闭环已完成。

先分模块并行，再由当前对话统一集成、启动测试服务、浏览器验收和记录；不并发改正式数据库或重启正式服务。所有既有用户素材、草稿、历史与 localStorage 均保留。

## 3. 用户流程

1. 导演台进入项目列表，创建或选择项目后进入画布；返回按钮回到此列表。
2. 主导航下方成为画布，项目名称及工具紧凑显示。对话面板可收起，再打开时草稿和会话仍在。
3. 用户说明想法并要求起稿；Agent 根据真实响应澄清、保存、失败或部分完成。
4. 脚本保存后刷新真实节点，显示完整正文；节点下方可编辑并一次确认对应版本。
5. 用户可随时创建文本／图片／视频节点，上传或从素材库引用已有图片／视频；只创建与用户当前动作有关的节点。
6. 各节点配置独立；拖动、平移、缩放和刷新后恢复同一份内容，输入框操作不触发画布拖动。
7. 通过可发现的结构模板入口保存／查看／套用节奏结构，套用后继续绑定本项目素材。

## 5. 接口与数据约束

- 对话：`POST /api/projects/{id}/director/chat`，保持 client_request_id／session_id／workflow revision；明确起稿时可用 `intent=script`。普通澄清不能强行视为起稿。
- 结果：解释 `outcome=saved|clarify|message|failed|partial`；不要解析回复中的“已保存”或仅看 HTTP 200 判断成功；历史 structured 和恢复回执都要采用同一映射。
- 恢复：通过 `GET .../director/requests/{client_request_id}` 查询原请求；网络未知和停止等待不自动换 ID 重发。脚本全文由真实 script_id 读取，保留版本。
- 画布：GET／PATCH `/api/projects/{id}/canvas`；增量节点更新，拖动只送位置。禁止把只读 `asset`／`last_execution` 整包回传。`script` 是保留节点 ID。
- 配置：传入 `config` 会整体替换，单字段编辑需合并当前完整配置；保留 expected_layout_revision／expected_config_revision，冲突不能悄悄覆盖。
- 删除：`delete_node_ids` 只移除节点；省略 edges 由后端清理连线。不能借此删除原素材、脚本、任务或历史。
- 导入：POST `/api/assets`，文件字段 file；根据后端真实 kind／mime／尺寸／时长建立 asset 节点。上传成功而绑定失败时保留素材并允许重绑。
- 媒体参数与四模式复用当前能力配置；已选模型不可用时提示，不静默改第一项。新节点保存配置不提交付费任务。
- 错误沿用统一 error.code／message，经前端映射产品文案；request_id／SQL／内部版本不出现在默认产品界面。

## 6. 实现与集成结果

- 保留 CStudioShell 和 StudioTheme，将主导航下方铺为画布，移除独立项目大标题条；窄屏对话采用收起／展开，避免旧的聊天与画布纵向大块堆叠。
- 删除隐藏“创作资料与手动调整”表单。创作要求进入对话，脚本／文本编辑进入节点；结构模板移至可发现入口，保留创建、查看与套用实现。
- DirectorChat 统一即时响应、历史和恢复回执的 outcome；保存脚本后读取真实节点。停止等待保留原请求号并回查，慢请求测试只发出一次 POST。
- FreeCreationCanvas 接入自由节点、上传／引用、增量位置与视口同步；节点设置与节点使用相同画布 transform。三方布局合并避免远端更新覆盖本地正在进行的拖动。
- CanvasNodeSettings 保存独立正文和配置，推进返回的 revision；配置比较采用语义相等，避免因对象键序或陈旧版本造成误判。脚本编辑后一次确认至新版本。
- 输入与媒体控件不触发画布拖动；补充窄屏高度、按钮名称和弹层可访问属性。未把这些代码检查当作完整辅助技术验收。
- 项目、模板和素材使用真实隔离 API；节点删除仅移除节点，源素材保留。没有清空正式 localStorage、用户草稿或素材。
