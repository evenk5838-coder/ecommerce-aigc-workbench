## 本批实现

- 单／批量删除与快照同事务记录；持久化撤销恢复原身份、位置、参数、绑定与连线，保留其他节点后续编辑、视口、源素材和任务。恢复冲突明确拒绝，不覆盖新内容。
- 独立媒体节点的报价、一次明确确认、普通任务入队和 execution 关联；不要求脚本／镜头前置，四种输入模式复用已有模型校验。
- 冻结实际生成输入和引用摘要；生成参数变更须重新报价，布局和标题变更不影响有效生成输入；保留幂等、同节点在途限制、预算预留和历史查询。
- 画布从真实任务读取状态与产物，失败或重生时保留旧成功结果。旧 task retry 对节点执行任务封口，不能绕过节点报价；项目删除保护远端未终结任务；worker 首次提交前校验排队期间引用内容是否改变，远端续查不重新提交。
- 新增 `canvas_deletions`、`canvas_node_quotes`、`canvas_node_executions` 三张表；沿用旧表数据，不迁移或清理用户内容。新表受已删除项目的 SQL 保护。

主要实现为 `canvas_history.py`、`node_execution.py` 及相关路由、存储、worker／引用守卫。接口详见 [节点执行与删除撤销契约](../接口/节点执行与删除撤销-后端契约-v0.11.md)。本批没有将生成确认开放给不受约束的 LLM。
