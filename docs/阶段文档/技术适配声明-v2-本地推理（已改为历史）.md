# 技术适配声明（v2 · 本地推理）

> 2026-10-22｜对应 PRD v0.4｜项目：电商 AIGC 工作平台
> v1（火山云端）已撤回，归档于 `docs/阶段文档/技术适配声明-v1-云端（已撤回）.md`

## 1. 产品形态判断

- **形态**：单机本地 Web 工作台。后端（Python）+ 本机模型推理（PyTorch MPS）+ 本地存储（SQLite + 文件）；画布前端由 Codex 开发，本阶段我提供后端接口与最小验收页。
- **开发路径**：**纵向切片**（手册路径 B）。理由：画布交互与图片/视频产出必须「用眼睛看、亲手点」才能判断质量，纯接口无法验收。
- **运行形态硬约束**：运行时**全部推理在本机**；不接入任何远程模型（含火山、DeepSeek）；DeepSeek 仅用于开发期 Pi Agent。

## 2. 采用的默认方案

| 层 | 方案 | 说明 |
| --- | --- | --- |
| 后端 | Python 3.12 + FastAPI + Uvicorn + Pydantic v2 | 复用 Codex 已建探针环境（3.12.15），不重复安装 |
| 推理 | PyTorch 2.5.1 + diffusers 0.35.1（MPS 后端） | 已实测 `mps_available=True` |
| 持久化 | SQLite + SQLAlchemy（Alembic 视时间启用） | 多实体 + 状态机 + 重启恢复 |
| 文件 | 本地内容寻址目录 `data/assets/` | 大文件不进库 |
| 任务 | 进程内持久化队列 + 单 worker（并发度可配，默认 1） | 16GB 单机，多并发会超 MPS 预算 |
| 视频编码 | `imageio-ffmpeg`（已装，自带二进制） | 系统 FFmpeg 未安装；`ffprobe` 如需另装 |
| 前端（本阶段） | Codex 负责正式画布；我提供单 HTML 最小验收页 | 手册 §五默认实现 |
| 测试 | pytest（假 pipeline 流程测试 + 失败注入） | 真实模型单独冒烟 |

## 3. 触发的按需模块

| 触发条件 | 模块 | 是否引入 |
| --- | --- | --- |
| 多实体/状态机/事务/恢复 | SQLite + SQLAlchemy | ✅ |
| 长耗时任务、需排队与取消 | 持久化队列 + worker + CancelToken | ✅ |
| 大文件产物 | 内容寻址存储 + 校验 | ✅ |
| 内存受限（11.45GB MPS 预算） | ModelManager（加载/卸载/互斥）+ MemoryGuard + 采样器 | ✅（本机特有，必需） |
| RAG / Word / PDF / 登录 / Redis / 多进程 | — | ❌ 无需 |

## 4. 偏离或暂缓的默认方案

| 项 | 默认 | 本次 | 说明 |
| --- | --- | --- | --- |
| Python 版本 | 3.12 | 复用 `/private/tmp/ecom-local-probe-20261022/venv` | 该环境在 `/private/tmp`，**系统重启可能被清理**；阶段 2 会在项目目录内建同名环境或迁移，避免交付物依赖临时目录 |
| 模型 | 手册不固定 | SDXL base（≈6.95GB fp16）+ i2vgen-xl（≈4.98GB fp16） | 许可证 openrail++ / MIT；**下载前需你确认磁盘预算** |
| Alembic 迁移 | 默认启用 | 时间允许则启用，否则用建表脚本 + schema_version 表 | 单机单用户，权衡时间 |
| 断点续跑 | — | **不实现**，只做「从头重试」 | 扩散中间态序列化成本高，不承诺 |
| 画布 | — | 由 Codex 实现，我在 16:30 前完成接口与最小页 | 不把画布排到后续版本 |

## 5. 强制底线检查

| # | 底线 | 落实方式 |
| --- | --- | --- |
| 1 | 密钥不进仓库/前端/日志 | 本项目**无需任何模型密钥**；`.env` 只放路径与参数；`.gitignore` 排除 `data/`、`.env`、`__pycache__` |
| 2 | 长任务与人工确认点持久化 | SQLite 任务表 + 草稿版本 + 产物落盘校验 |
| 3 | 接口定义请求/响应/错误；错误统一结构；SSE 以 done/error 收尾 | 架构方案 §11、§12 |
| 4 | 模型输出结构校验；失败有分类 | 元数据 Pydantic 校验；错误码分类（含可重试语义） |
| 5 | 高风险动作由确定性代码 + 人工确认 | 提交即占算力需显式点击；删除/覆盖需确认；不自动重跑 |
| 6 | 上传校验真实类型/大小/文件名；日志不记内容 | magic bytes + 大小上限 + sha256 命名 |
| 7 | 权限判断在后端 | 单机单用户，仅监听 127.0.0.1 |
| 8 | 计费资源 | 无云端费用；但**耗时与算力**需可见（每任务记录耗时与内存） |
| 9 | 不删已有成果 | 历史版本全部归档保留 |
| 10 | 不用 mock 冒充真实验证 | 证据分「模拟/真实本地模型/人工」；低规格探针标注实际规格 |
