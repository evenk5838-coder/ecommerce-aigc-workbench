## 完成判定

实现完成、隔离通过、真实模型通过、人工验看通过分别记录。当前尚不可宣布“所有功能完成”或“可内测”。

统一测试覆盖：
1. 原快捷工作台与既有素材/草稿回归；模板真实字段与参数。
2. 项目→需求→AI脚本→编辑→确认→镜头→分镜→审核→整组报价→确认→两种交付路径→导出/结构模板。
3. 修改上游后的过期保护、报价与输入冻结、费用未知/过期/重复点击/幂等、未开通模型与EOS边界。
4. 单镜失败、只重试失败镜、取消、断线、重启续查、成功片段保留；完整/部分成片命名真实。
5. 多页面版本冲突、状态持久化、旧素材/版本不覆盖，刷新与未保存编辑保护。
6. 手机/平板/桌面、键盘与弹窗、媒体预览下载、控制台和失败请求。

真实测试前集中列用例与预算，获得明确批准后执行；运行时存在Key不等于付费测试授权。模型尚未开通、额度不足或后端接口未完成属于实际阻塞，必须写清，不能由Mock覆盖。

内测候选版保留可回退Git版本、真实证据、已知限制与启动方式。所有阻塞清理和整体验收通过后，再交产品经理做内测评审。
