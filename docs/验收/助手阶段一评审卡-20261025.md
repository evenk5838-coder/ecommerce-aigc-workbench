## 真正上手时的验看清单

1. 只要求润色提示词：给出可用描述，停在此处，不擅自生成。
2. 需求不清楚：只问必要的问题，第二轮记得第一轮已确认的内容。
3. 改时长或方案：显示更新后的方案与费用，等我重新确认。
4. 确认一次：只产生一个对应任务，能看到实际成果与用量。
5. 关闭助手：仍能直接使用原工作台。

涉及真实调用的步骤须按当时明确批准的测试预算执行；本次阶段一评审不需要新增模型费用。
