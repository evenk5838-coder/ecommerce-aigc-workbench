# S1 前端增量交付说明

日期：2026-10-25。分支：`codex/assistant-frontend-v1`。本轮在既有 React/Vite 前端上增量开发。

## 已实现

- 平级入口「快捷工作台」「引导创作」；后者如实展示待接入流程，尚不能创建脚本、分镜或成片。
- 工作台保留生图/生视频、参考图、素材库、任务中心与既有排版。助手只润色，用户主动触发，结果可编辑并明确采用。首次保存后助手项目身份保持稳定。
- 模型能力驱动比例、图片像素尺寸、清晰度、原生时长。Pro Fast 2–12 秒整数选项；未开通、能力缺失和失效模型不可选，不静默换模型或修改用户时长。
- 手动生成前调用后端免费逐项估算，显示规格、数量和合计；确认提交使用同一冻结请求与 request ID。估算失败不提交，不自动重试。
- 保留原有草稿、本地存储键与素材。旧草稿缺少尺寸时按当前比例匹配默认尺寸，编辑描述不注入固定方形尺寸。

## 本地验看

当前预览：<http://127.0.0.1:5184/>，代理现有 8100 后端；8100 所提供的旧前端尚未被替换。

启动命令（在本工作树 frontend 目录中）：

```sh
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5184 --strictPort
```

建议验看：两个入口 → 图像比例/尺寸 → 生视频的 2–12 秒与清晰度 → 提示词润色及明确采用 → 生成费用确认。真实润色会使用 DeepSeek 额度，点击确认生成会创建付费任务。

## 证据与边界

`npm run build`（含 TypeScript 检查）、`npm run lint`、107 项离线测试、diff 空白检查通过。浏览器检查了 390/768/1280/1440 宽度，无横向溢出；真实免费估算请求通过。润色回复、空优化字段和估算异常由隔离浏览器模拟，未调用付费模型、未创建生成任务，模拟结果不作为真实模型能力证据。
